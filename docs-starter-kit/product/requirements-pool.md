## 优先级定义

| 优先级 | 含义 |
|--------|------|
| P0 | 阻塞发布，必须立即做 |
| P1 | 近期版本必须包含 |
| P2 | 排期做 |
| P3 | 观察/待定 |

## 状态流转

待评估 → 已立项（关联 prd-template 产出 PRD）→ 已排期（进入 versions/vX.Y.Z.md）→ 已实现（验收后关闭）

## 维护规则

- 新需求从 [prd-template.md](../templates/prd-template.md) 补充详情
- 已实现需求标记关闭并注明版本，保留一行记录（追溯）
- 需求变更走评审：变更影响范围、优先级、排期
