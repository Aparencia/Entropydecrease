# 产品文档

> 按需裁剪目录。个人项目可整体删除；有产品形态时按下列结构维护。

## 建议文件

| 文档 | 何时需要 |
|------|---------|
| requirements-pool.md | 有需求池/待办规划时（需求 → 版本 → 实现追踪） |
| brand-story.md | 有对外品牌叙事时 |
| pricing.md | 有定价/商业模式时 |
| user-research.md | 有用户访谈/反馈分析时 |

## 与 Foresight/ 的分工

- `product/`：已立项、需持续维护的产品文档（需求池、品牌、定价）
- `Foresight/`：未排期的构想、头脑风暴、竞品分析（立项后移入 product/ 或 versions/ 跟踪）

## 维护规则

- 新文档从 [prd-template.md](../templates/prd-template.md) / [brainstorm-template.md](../templates/brainstorm-template.md) 复制
- 每个产品文档在 docs/README.md 总导航中登记
