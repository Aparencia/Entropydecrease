## 一、阶段目标

1. **视频文件导入可用**：ffmpeg 提取音轨 + 关键帧，文件路径作为实时捕获之后的第二入口
2. **字幕优先转写可用**：外挂字幕文件（.srt/.ass/.vtt）探测与内嵌字幕轨解析（L1/L2），命中则零成本 100% 准确，免 ASR
3. **融合停止体验优化**：停止按钮秒回（REQ-031：融合异步化 + 无字幕短路）
4. **采集链路质量优化**（REQ-034）：时间戳统一、句起时间戳、引擎池并行、分窗转写、多帧投票、OCR 输入缩小、语音/画面互斥调度

> 本阶段**不做**：闪卡（REQ-019/020，用户决策顺延至 v0.4.0）；会话段派生视图（REQ-032，V1.0）；AI 问答与精修（REQ-024/025，V1.0）。

## 三、技术方案

### M1 视频文件导入（REQ-015）

- **ffmpeg 解析**：`ENTROPY_FFMPEG_DIR`（测试注入）→ 捆绑 `src-tauri/ffmpeg/`（`scripts/download-ffmpeg.ps1` 下载，gitignore）→ PATH；全缺失返回可操作错误
- **管线**（`import_video` command，spawn_blocking + 进度事件）：
  1. 建会话（title=文件名，source_window=None）
  2. ffmpeg 提取 16kHz 单声道 WAV → `data_dir/import/<id>/`
  3. 字幕决策（M2）：L1 命中 → 字幕直出（免 ASR）；否则 L2；再否则分窗 ASR
  4. 分窗转写（无字幕路径）：WAV 按 30s 窗切分 → `transcribe_pcm` 逐窗 → 真实时间戳段
  5. 关键帧：`fps=1/10` 封顶 60 帧 → 逐帧 OCR 落 OCR 块（单帧失败跳过不阻断）
  6. finish 会话 + 清理中间文件
- **安全**：Command 参数数组（防注入）、子进程有界等待（超时 kill）、路径限定数据目录

### M2 字幕探测与优先（REQ-016/017/018）

- **L1 外挂**（`subtitle.rs` 纯文本解析，零新依赖）：同名探测 `.srt/.ass/.vtt`；编码探测 UTF-8 严格 → GBK（CP936，windows crate Win32_Globalization）；SRT/VTT/ASS 三格式解析为 `SubtitleSegment`
- **L2 内嵌**：`ffprobe -select_streams s` → `ffmpeg -map 0:s:0 -f srt -` 解出 → 复用 L1 解析器；ffmpeg 缺失报可操作错误
- **策略**：L1 → L2 → ASR 三级降级；关键帧 OCR 始终执行（独立于转写路径）

### M3 融合停止异步化 + 无字幕短路（REQ-031）

```
用户点停止
  ├─ 1. finish_session（毫秒级）
  ├─ 2. emit "live:stopped"（秒回）
  └─ 3. 后台线程（std::thread::spawn）：
         ├─ 无字幕段 → 直接 return（短路：融合=ASR 原样拷贝）
         ├─ 否则 → merge_transcript + replace_segments（沿用 ADR-005 原子事务）
         └─ 完成 → emit "session:fused"（失败 "session:fusion-failed"，原段保留）
```

- **状态标记**：内存方案——`LiveSessionManager` 持 `fusing: HashSet<i64>`（不迁移表，ADR-006 派生表 V1.0 取代）
- **细节**：融合线程持有 Db/AppHandle 克隆与字幕/ASR 段所有权；详情页融合完成前显示原始轴，`session:fused` 到达后刷新

## 四、验收标准

- [ ] 视频导入：选文件 → 会话生成 → 转写段 + OCR 块落库；进度事件推送
- [ ] 有字幕视频：免 ASR 直出（source=subtitle）；无字幕视频：分窗 ASR 段真实时间戳
- [ ] 停止会话：UI 立即（<100ms）显示已停止；融合在后台完成
- [ ] 无字幕会话：停止后不执行融合（日志验证短路），段数据完整
- [ ] 有字幕会话：停止后详情页短暂显示原始轴，`session:fused` 到达后刷新为融合轴
- [ ] 大会话（模拟 ≥2000 段）：停止响应不随段数恶化
- [ ] 融合失败（模拟 DB 错误）：原始段不丢，前端可提示
- [ ] 实时会话时间轴：音频/屏幕/flush 同基准（新会话）；句起时间戳非近似
- [ ] 引擎池并行：导入长转写不阻塞实时 OCR（日志/耗时验证）
- [ ] 字幕投票：同字幕多帧错字被校正（单测 + 集成验证）
- [ ] `cargo test` 新增：字幕解析/编码、投票、调度自适应、命令构建、分窗规划、无字幕短路、融合状态流转
