## 沉淀规则（30 秒速记）

1. **什么时候写**：解决了值得再犯的错误 / 做了值得复用的方案 → 立即花 5 分钟记录
2. **命名**：`YYYY-MM-DD-kebab-case-标题.md`
3. **模板**：从 [knowledge-card-template.md](../templates/knowledge-card-template.md) 复制
4. **索引**：登记本表 + 补充标签（标签用于检索与关联）
5. **归档**：知识卡被取代或项目完结后，按归档机制移入 `archive/YYYY-MM-DD/`
