# ADR-024: 知识体系层（方案 B）——有界体系通过、自由双链/图谱仍出局

## 状态

已接受（2026-08-23 用户裁决：B 模块新增型＋全局/领域双层＋保持技能自学者定位、理念局部修订；落位 v0.13 系列）

## 日期

2026-08-23

## 背景

用户提供《个人知识体系搭建指南 v2.0》（问题树/概念三问一用/模型交叉验证/决策日志/季度审计五环），要求整合进熵减。经范式判断（[整合分析](../Foresight/personal-knowledge-system-layer-integration.md)）：指南是 KM 范式＋获取隐喻，熵减是学习科学＋成为隐喻；两者**闭环互补**（指南缺记忆发动机与证据层，熵减缺"为什么学"与"应用闭环"），但指南的"知识资产/双链/多领域体系"要素与熵减现有裁决直接冲突：

- 原则 4 克制清单：知识图谱/双链不做（[P13 出局](../product/pain-points-v4.md)）；不做 Notion 式通用工作区。
- 契约一：组粒度对齐领域、拒绝大类；组是唯一容器。
- 竞品调研（[赛道全景](../Foresight/competitive-analysis-knowledge-system-layer.md)＋[品类深化](../Foresight/competitive-analysis-knowledge-system-software.md)）：「提取→记忆→应用→决策」完整闭环无人做；整合型「概念/模型↔决策日志↔审计」为零竞品带（独立决策日志 App 存在但孤立）；方法论空白在"**检验**"（知识是否被用、决策是否变好）而非"组织"——卡片盒/PARA/MOC 全部只回答"怎么存、怎么找"。

## 决策

- **新增体系层（L2 飞轮层延伸枝，季/决策时钟）**：全局体系（唯一核心问题域＋领域入口＋场景问题）→ 领域体系（问题树/概念库/模型库）；**组仍是唯一容器**，体系只引用、不收纳（`knowledge_links`，引用不复制）。
- **P13 重裁决**：自由双链/图谱（任意连接＋图可视化＋图漫游）**仍出局**；**有界体系**（体系树＋概念库＋模型库＋决策日志；引用限体系内及对证据的单向引用）**通过**。论证：P13 裁决的是优先序（骨折层＞连接层）与"连接作为增长机制"；体系层解决"围绕什么决策组织学习"（组织机制）＋"为动手闭环提供记账本"（N12），不承担增长机制。
- **双面体单向升格**：组内 `flashcards.kind='model'`（记忆面，REQ-199 预埋接口）↔ 体系概念（思辨面，三问一用），卡→概念单向升格；概念→卡不反向。
- **决策/应用一表两面**：`knowledge_decisions.kind ∈ {decision, application}`（四行法字段＋`used_refs` 引用必填）；只记"我的决策"——产物层 `ArtifactKind::Decision` 禁止自动升格。
- **审计＝体系级结算**：季度触发（`settlement_due` 同范式）；产出**建议**、用户确认后生效；无 streak、无惩罚（弹性承诺纪律延续）。
- **门控**：REQ-146 真机验收总清（组级学习循环通过）为发布前置；开发可先行（v0.13.1 起），发布不放行。
- **开关**：体系默认开（叙事层主枝）；交叉点派生提示默认关（v0.13.4）；AI 增强（卡→概念回填）默认关。
- **零破坏**：既有表结构不动；`flashcards.kind` 补值 `model`；`metrics_events.kind` 新增 4 值。
- **不做清单**：体系图谱可视化（力导向图，REQ-029 维持 P3）；跨体系自由引用；全局概念库收纳内容；AI 自动生成决策/概念（AI 只建议不生成——假燃料红线）；决策质量评级；领域体系嵌套；承接 REQ-030 学习计划系统。

## 备选方案

### 方案 A：机制提取型（原始建议，未采纳为终局）
- 优点：零定位张力；全部落在预埋接口。
- 缺点：只有"功能补丁"，不承载"为什么学/怎么用"的叙事层职责；指南的体系化价值被降级为卡片增强。

### 方案 C：内容资产型（伴生保留）
- 优点：最轻。
- 缺点：指南只是内容，不是产品机制——"模板自律"仍是用户负担（PKM 高放弃率根因）。

### 方案 D：自由知识图谱（不做）
- 优点：—。
- 缺点：P13 出局（失败发生在人没回来的地方）；Heptabase/Obsidian Graph/思源图谱已占位（品类深化调研）；与"学习工具"定位冲突。

## 选择理由

用户裁决方案 B（模块新增型＋双层），竞品调研验证：整合型「应用/决策」是唯一无人占据的闭环段，且"检验"是方法论级空白——这既是差异化，也是"AI 测量，人类见证"原则（人类判断领地）的产品化承载。有界体系在守住 P13 本意（不建图、不收内容、有审计、挂证据）的同时，把"模板自律"产品化（向导＋四行模板＋审计触发）——针对 PKM 品类的结构性痛点（搭建/维护成本高、放弃率高）。

## 影响

### 正面影响
- 补齐 L1 缺失节点（动手闭环 N12 机制化）与 L2"为什么学"枝；学习链扩展为"…→自我叙事→决策判断"。
- 首次把"应用率/决策引用"变成可测数据（metrics_events 新事件）——Phase 4 显影的差异化维度。
- 零竞品带的先手：决策日志＋审计＋概念引用的整合闭环。

### 负面影响 / 代价
- 双界面成本（体系页＋学习面）——以三时钟纪律（体系不进每日视图）与单屏"树＋审计"控制。
- 体系沼泽化/假燃料放大器风险（体系漂亮、学习不动）——以门控＋审计建议＋思辨/学习动作并列报告防御。
- 理念文档需同步修订（原则 4 表格/原则 5/pain-points §7.6/REQ-029）——本 ADR 为修订依据。

### 风险
- Ramifly 类"AI 生成问题树"抢"问题树"心智——熵减差异＝树长在学习证据上，AI 只建议不生成。
- 记账负担（组结算＋审计＋决策＋应用两本账）——一表两面＋引用必填防膨胀。
- 真机验收未过先建上层触发"假燃料"——门控条款保留至发布。

## 合规性验证

- `flashcards.kind='model'` 卡面契约（front=概念名/back=三问＋锚点回链）落库生效；卡→概念升格单向且幂等。
- `knowledge_decisions` 仅当 `used_refs` 引用体系实体非空时可入账（校验在 command 层＋纯函数）。
- 体系无内容入口（碎片/笔记只能先落组再被引用）；审计建议须用户确认后变更状态。
- 测试：pure 函数 TDD（audit_due/concept_stale/promote_rules golden）＋ command 参数校验用例＋真机走查（建体系→挂组→升格→用一次→审计→交叉点提示）。
