## 编号规则

按创建顺序递增，三位数字（ADR-001、ADR-002…），编号一经分配不再复用。
文件名格式：`ADR-XXX-kebab-case-title.md`。

| 提议 | 尚在讨论，未开始实施 |

| 已废弃 | 不再适用，但保留供历史追溯 |
