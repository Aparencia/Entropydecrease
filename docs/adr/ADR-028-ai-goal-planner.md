# ADR-028：AI 目标规划师——建议制规划 + 体系深度联动

> 状态：已接受（2026-09-02，随 v0.18.2 设计批准；实施于 v0.18.1 之后）
> 关联：[v0.18.2 设计规格（[ ] 已归档）](../archive/2026-09-02/2026-09-02-v0.18.2-ai-goal-planning-design.md) · [ADR-027 目标层建模](./ADR-027-goal-layer-modeling.md)（本 ADR **局部修订**其 §决策 5 与所引"不做 AI 自动拆解里程碑"条款）· [v0.18 设计（[ ] 已归档）](../archive/2026-09-02/2026-09-02-v0.18-learning-goals-design.md) · REQ-251~254

## 背景

v0.18 目标层（M1）已交付纯规则设定/进度/判据（**零 AI**——M1/M2 零 AI 铁律保持）；v0.18 设计曾裁决"不做 AI 自动拆解里程碑（人类判断领地）"。2026-09-02 用户重裁决：目标层要接入 AI 规划，且规划内容需与知识体系层深度联动（含"AI 提供初步体系"）。用户采纳项：双入口、建议制确认落库、四项联动、默认关+授权确认。

## 决策

1. **规划师角色＝顾问，非执行者（建议制）**：AI 产出 `GoalPlanProposal`（里程碑草案/建议绑定组/体系建议/周契约建议/一句话说明）——全部草案，用户逐项确认/删改后**事务写入**；AI 失败/校验失败 → 回退 M1 规则草案（`suggest_milestones` 为永远可用的降级基线），目标创建/规划永不被 AI 阻断。
2. **双入口同一协议**：访谈第 5 步「✨ 用 AI 规划」＋ 详情页「💡 AI 规划」（intent_json 现取现拼）；共用 `GoalPlanApprovalDialog` 确认流与协议校验（优化评审 #4 同哲学：双轨制是入口不是两套组件）。
3. **体系联动＝只加引用通道**：`knowledge_links.target_type` 白名单 **+1（'goal'）**（TEXT 无 CHECK，命令层白名单与 group 先例同款，零迁移零破坏）；体系页「服务于目标 X」反标；**AI 初步体系**＝骨架建议（名称+核心问题+≥1 领域入口+初始概念 3-5 个），**门槛校验**（缺一即整条丢弃并诚实提示），确认后经既有体系命令逐项创建（一项一事务，骨架部分失败不污染目标层）。
4. **概念弱项 M3 真实化**：目标绑定组→组卡→概念（跨 knowledge_links）的**低激活信号**（90 天无引用/未应用，concept_stale 判据理念）=规则信号现算；「最弱概念」块+AI 解读（可选）作为 `/goal` 与规划的输入。
5. **预算与治理（硬约束延续）**：`budget_allocator` 档位化（轻量 4K/标准 10K/深度 30K，默认标准）+ 单次调用 ≤ 档位硬顶 + 超限按相关性截断且**诚实提示不静默**；content_gate 双闸门（目标 AI 开关默认关 + 授权弹窗）；token/成本入 ai_usage、提示词/回答入 ai_tasks.trajectory（AI 任务视图可见）；复用 v0.16 首次云端提示。
6. **红线**：不接 agent 框架/记忆模块/自主规划/每日推送（维持）；AI 不直接执行任何写入；上传仅授权后的最小检索片段（L4.5 目标摘要现算 <1K token + L3 FTS top-K）。

## 备选（否决）

- **直接制（AI 建好后改）**：产出即落库——AI 输出质量不可完全契约化，撤回/半态治理成本高；建议制保住"人类判断领地"（用户裁决）。
- **规划入知识体系架构（目标=体系节点）**：意图轴与结构轴重新混层——v0.18 已裁决分离建模，本设计用"引用通道"联动而非合并。
- **流式规划**：一次性 JSON 输出（10K 量级 10-30s），任务化轮询足够；流式价值低，交互等待可接受。
- **AI 主动推送每日任务**：用户未诉求；红线维持（人类判断领地）。

## 影响

- 正向：意图层获得 AI 顾问（规划/复盘的上下文来源）；目标↔体系↔概念闭环（"服务目标 X"可见/可问）；无 AI 时功能完整（规则基线）。
- 代价：knowledge_links 白名单 +1（命令层回归）；新增 4 命令 + 1 确认流组件；设置页新增「目标 AI」段；M2 毕业仪式先行（排期 v0.18.1 → v0.18.2）。
- 兼容：既有 goals/goal_milestones/goal_groups/contracts/knowledge_* 零 schema 变更（仅 knowledge_links 白名单+1 与新增辅助表无）；old goals 数据（无 intent 填空）走规则基线。

## 合规性验证

- Protocol 校验矩阵 golden（合法/缺门槛/超长/非法枚举→整条丢弃/整次降级）；预算 O(1) 恒定输出测试；双闸门路径测试（未开/未授权拒绝）；确认流落库事务测试（部分失败不污染）；cargo test/clippy/vitest/tsc 全绿（v0.18.2 验收 ①~⑧）
