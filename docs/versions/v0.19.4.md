## 设计要点

### §1 REQ-274 全局 AI 对话面板（AiConversationDock）

定位：非侵入的跟随工作区，**与 ChatPage 同源同数据**（不建第二套会话/消息模型）。

```
┌──────────── 主窗（任意页保持挂载）── 右停靠 560px 面板 ─────────┐
│                                                    ┌ AI 任务对话 ───────┐ │
│ 编辑器/列表原样                                    │ 线程：来源笔记《…》    │ │
│（上下文不丢，关闭=隐藏非销毁）                        │ 🧑 提示词全文（策略摘要）│ │
│   🤖 [以对话处理]（各入口同钮）                     │ 🤖 片级流式正文…        │ │
│                                                    │  [采纳][查看来源][追问] │ │
│                                                    └──────────────────────┘ │
└───────────────────────────────────────────────────────────────────────────┘
```

- **唤起三通道**：① 任意 AI 任务入口的「以对话处理」（笔记编辑态 🤖 AI、会话精修、知识补充、任务中心重试、选中文本等）→ 自动开面板并新建/复用线程；② 全局快捷键（拟定 Ctrl+Shift+A）；③ 手动呼出回看/继续旧线程
- **内容保活**：面板关闭 = 隐藏不销毁；进行中的任务照跑，完成时面板未开 → toast 通知 + 任务落入 ChatPage 会话列表可查可继续（回答用户 Q1：面板内任务=chat_sessions 真实线程，**AI 对话页天然可见可查**，ChatPage 维持全屏管理视图：会话 CRUD/模型切换/任务段/轨迹审计；面板是轻量发起与跟随视图）
- **组件复用**：面板内容复用 ChatMessageList/ChatComposer/TaskThreadCard 等既有组件与既有发起协议（ai_refine_* / enrich / chat send），**零新 IPC 协议**；后续 ChatPage 可收敛为面板全屏态（本批不做）
- **完成操作条按来源渲染**：精修=采纳到工作台 / 查看来源（回跳笔记并恢复编辑上下文——记录来源锚点 noteId+编辑器位置）/ 追问（10 分钟窗口沿用）
- **断点补齐**：ChatPage 发起的 enrich 无就地采纳、完成卡无「查看笔记」（TaskThreadCard 显式排除）→ 与其它入口同操作条

### §2 REQ-275 响应速度治理（方法先行）

实施第一步为**链路耗时拆解**建立基线，再针对性优化，候选手段（拆解后定）：
- chat/任务首 token 延迟（Provider 网络/请求组装/检索前置于生成链）
- 流式帧节奏与前端渲染节流（片级解析流帧间隔；既有 1500ms ai_refine_status 轮询与 ai:task-update/ai:refine-stream 双通道的延迟观感）
- 任务发起前置链路（estimate 成本门是否可并行/预取，授权已过时可否跳过）
- 排除项：不换 Provider、不改云端协议、不动 content_gate 授权语义

### §3 REQ-276 挂体系浮层/弹层残缺修复

- 复现面：笔记行/阅读态「挂到体系」浮层（NoteLinkToSystem 悬浮弹层群：色板/归组/挂体系，无右缘钳制）在右缘窗口/窄窗场景下右缘裁切或布局错位
- 修复：浮层右缘钳制（挂起时按可视区域重定位/翻转）+ 边距统一 + 同类阅读头浮层群统查；补窄窗与贴边场景验证

### §4 REQ-277 ID 治理（显示治理 + uid 基建）

**裸号清单（6 处，现行文案 → 目标语义标识）**：

| 位置 | 现行 | 目标 |
|------|------|------|
| ChatSidebar.tsx:124 / ChatPage.tsx:162 | 来源标题缺失兜底「会话 #N」 | 「会话 · 09-04 09:41」（有标题显标题），来源已删=「（来源已删除）」 |
| TaskConversationView.tsx:82 | 「📌 来源会话 #N」 | 标题/日期语义标签，链接语义不变 |
| AiTaskPanel.tsx:177 | 「任务 #N 结果」 | 「<类型>任务 · <发起时间>」 |
| NotePreviewView.tsx:261 | 「✨ AI 精修版 · 笔记 #N」 | 《笔记标题》/日期 |
| ClassroomRightPane.tsx:93 | 「#N · 来源 · 时间」 | 《笔记标题》/来源会话标签 |

治理原则：裸 `#数字` 全站绝迹（v0.12.7 治理延续至 AI 任务域）；内部机制（DB 外键、命令入参、localStorage 键）保持数字不动。

**uid 基建**（notes/sessions 两表）：
- `uid TEXT` 列 + 唯一索引（NULL 兼容，保证存量未回填期可插入）；生成 = `<kind>-YYYYMMDD-<6位随机>`（kind: n/s；示例 `n-20260904-x7f2k9`），应用侧创建时生成，碰撞重试
- 迁移：幂等 ensure_column 加列 + 存量一次回填（`UPDATE … WHERE uid IS NULL`，重复执行安全）；**无表重建、无 FK/影子表联动、无前端契约破坏**（契约仅增可选 uid 字段）
- 性质：不可变、时间可读、跨删除重建稳定；消费端=未来导出元数据/深链/跨设备合并判重/错误日志可辨识；本批仅基建+显示治理，不铺消费端

### §5 REQ-278 通用变更事件总线

- Rust：统一轻量 emit 辅助 `data:*` 域事件族——`data:notes-changed` / `data:sessions-changed` / `data:note-groups-changed` / `data:goals-changed` / `data:knowledge-changed` / `data:ai-tasks-changed`；对盘点中**零广播写命令模块**（笔记 CRUD commands.rs、会话 CRUD commands_session.rs、会话→笔记转化、组/碎片/闪卡/目标/结算/契约/颜色/版本/体系/画布/决策/图文会话、精修采纳落库、AI 对话转笔记等）按域挂载；既有领域事件（ai:task-update、knowledge:links-changed、live:* 等）保留不重复造轮子
- 前端：订阅工具（useDomainRefresh：域集合订阅 + 300ms 防抖 + 路由活跃门控）；首批订阅页=NotesPage（notes/note-groups/ai-tasks）、KnowledgePage（knowledge）、SessionsPage（sessions）、GoalPage（goals）、AiTaskPanel/任务中心（ai-tasks）、LearningLibrary（ai-tasks 采纳后建议区/索引角标联动评估）
- 根治场景：AI 任务完成/采纳后发起页即时可见，无需切页

### §6 REQ-279 程度「自定义」+ 标准恒纯净

- **新增自定义档**：RefineStrategyPicker 档位+「自定义」→ 展开自由文本（自然语言程度描述，如「更口语、多举一个例子」），文本随提示词组装并实时预览（所见即所发，沿 v0.17.0 预览同路径）
- **污染三通道修复（标准恒纯净）**：
  1. 换档=替换语义：applyPreset 按档位基准重置（standard 基准=空 dims），不再并集合并残留（refineStrategy.ts:53-55）
  2. 记忆重审：localStorage 记忆仅当存在「显式非默认调整」时生效；选档位本身不得把残留带入（RefineLaunchDialog.tsx:62-64）
  3. 偏好派生修复：prefsFromDraft 意图基准不再把全 6 旋钮写进 dimOverrides 且 defaultLadder 置空（refineStrategy.ts:108-122）；后端 resolve 遇 preset=standard 且无显式 override → 恒空策略不叠加（ai_strategy.rs:129-137，标准=现状零变化语义回归）
