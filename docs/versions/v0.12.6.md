## 一句话

ADR-025）；浮窗**窗口级 CSS 重置**（body 8px margin + 100vh 溢出 → 左右透明条 + 滚条）。

## 根因（M1：启动自动显示）

- `precreate_float` 调用 `build_float_window(app, false)`——参数 `precreated=false` 使
  `.visible(true)` + `.focused(true)`：setup 预创建本意是**隐藏**常驻（P2-10 秒开），
  v0.12.3 交付时参数传反，浮窗启动即显示且抢焦点（症状与用户"自动启动"完全对应）。

## 根因（M2：两侧透明区 + 滚条）

- 浮窗与其他窗口共用 index.html，但全项目无全局 CSS（`App.css` 无引用）；body 浏览器默认
  margin 8px + 面板 `height: 100vh` → 内容溢出视口 → **右侧滚动条**；
  透明窗口看不到 body 背景 → 左右各 8px 透明条（面板宽 = 视口 − 16px）。
- 修复：浮窗组件挂载注入 `html,body{margin:0;padding:0;width:100%;height:100%;overflow:hidden}`。

## 决策（M3：锁定自解锁——ADR-025）

- **约束**：点击穿透是窗口级能力（`set_ignore_cursor_events` → WS_EX_TRANSPARENT），
  锁定态浮窗收不到任何鼠标事件；tauri 2.11.5 / wry 0.55.1 **无 `set_cursor_hit_test`**（分区
  点击穿透，源码检索确认缺失）；解锁把手窗方案额外 40-80MB WebView2 + 位置同步复杂度。
- **选定：全局快捷键 Ctrl+Shift+F**（`tauri-plugin-global-shortcut`）：浮窗打开期间注册、
  收起期间注销（冲突面最小化）；任意焦点（浮窗/主窗/视频播放器/第三方应用）下可解锁/切换；
  解锁后 `set_focus` 浮窗（Esc 等恢复）。
- **语义收拢**：新增 `float_toggle` 命令 + `float_toggle_core`（三态纯状态机 `next_action`
  可单测）；主窗按钮与全局快捷键共用——原主窗 keydown 三态分支删除，仅保留浮窗关闭态的
  打开快捷键（`!floatSnap.open` 门控），防主窗键 + 全局键双触发双翻转。

## 交付内容

### M4 · 显隐链路（P0+P1）

- 预创建修复（隐藏/不抢焦点，失败仍回落懒创建）；
- 打开：显示浮窗（应用 stored topmost）→ **隐藏主窗** → 聚焦浮窗；
- 收起（toggle/停止采集/自动收起）：隐藏浮窗 → **主窗回显**（show+unminimize+focus）；
- ⏹ 停止 + ⌂ 主窗 路径不变（回主窗浮窗保留）。

### M5 · 锁定态 UI

- 锁定后面板头部/字幕条显示"🔒 已锁定"提示（tooltip：Ctrl+Shift+F 解锁）；
- 主窗按钮语义不变（浮窗化 ⇄ 收起 ⇄ 解锁浮窗——经 float_toggle 单一语义）。
- 收起面板后主窗按钮/快捷键重新可开（全局快捷键已注销，无冲突）。

## 已知问题与后续

- **全局快捷键冲突**：Ctrl+Shift+F 已被宿主系统占用时注册失败——仅日志降级（浮窗可用，
  锁定后经 ⌂ 主窗 → 按钮解锁路径保留）；未做热键冲突提示（记需求池）。
- **快捷键占用全程**：浮窗打开期间 Ctrl+Shift+F 为进程级热键（不区分焦点窗口）——语义即
  "浮窗切换键"，界面已明示；若用户反馈冲突面大，可改为仅采集中注册（记需求池）。
- **主窗隐藏无独立指示**：主窗随浮窗打开而隐藏——浮窗内已有 ⌂ 主窗出口；若用户误关浮窗
  期望"回到主窗"则主窗已回显（close 必回显，无死角）。
