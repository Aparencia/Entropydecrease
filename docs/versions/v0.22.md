## 版本归属说明（为何是 v0.22 而非 v0.21）

**v0.21 已由「执行型智能体（目标执行层）」预留**，且预留写得很实 —— [2026-09-05-goal-execution-agent-design.md](../superpowers/specs/2026-09-05-goal-execution-agent-design.md) 内有 v0.21.0（P0 执行数据层）/ v0.21.1（P1 AI 增强层）/ v0.21.2（P2 闭环增强）三档明确映射，并记录「裁决点：执行层走 v0.21 系列顺延，**建议顺延不插队**」；`v0.20.md` 的 D6 亦载明「v0.21 系列留给执行型智能体」。

本系列为**不同主题**（前端重设计 ≠ 目标执行层），故取 **v0.22**：不插队、不改动既有预留、不要求任何已记录决策回退。若将来执行型智能体顺延，其 v0.21 归属不受本系列影响。

## 红线与两处经批准的例外

**红线**：本地优先不破 · 不引入路由库 · 不砍任何已接线功能 · 每批 `tsc`/`vitest`/`cargo test` 全绿 · 行数红线（不往 4 个超限文件里加代码）· **后端数据模型零改动，除下列两处**。

| # | 例外 | 原因 | 回滚 |
|---|---|---|---|
| E1 | `MemoryEntry` 增加 `tier` 字段 | 档案记忆库根本没有 tier 轴 → 「画面档位选完不生效、也不跨会话记住」 | 旧 JSON 无该字段时按 `None` 读取（向后兼容读，无需迁移） |
| E2 | `tag_colors` 补种子/迁移写入 | 表建了但永远没有数据 → 前端色板第三档恒不生效 | 迁移可空跑；标签色本身是可逆 UI 状态 |

> 新增例外须**再次裁决**；不得由这两处推而广之为先例。

## 验收门槛（11 条，全文见规格 §11）

1. 4 个 >600 行文件 → **0**；>300 行 100% 在豁免表内且数值与实测一致
2. 手写弹层 20 → 全走 `Modal`；z-index 不同值 17 → **≤6 档**；`role="dialog"` + 焦点陷阱 **20/20**
3. 空态 / 加载 / 错误行 / 弱化文本 / 卡片边框 五类重复 → 各自 **1 个原语**
4. CSS 变量 0 → 覆盖全部语义色/字阶/间距/圆角/时长/缓动；hex 88 → **≤ token 数**
5. `prefers-reduced-motion` 覆盖率 **100%**，系统优先于强度档位
6. 会话与笔记各 **≥2 种**展示形式可用，原文形态不丢
7. **47 条未接线命令逐个有结论**，无「不知道」
8. **标签能写进去**且标签过滤面板有内容；**画面档位选完真的生效**且跨会话记住
9. JS 包首屏 gzip 达标或给出瓶颈清单；GSAP 只在独立 chunk 懒加载
10. 6 个签名动效各自**可中断、可反向**，reduced-motion 下正确降级
11. `npx tsc --noEmit` 0 错 · `npx vitest run` 全绿 · `cargo test` 全绿（每批）

## 边界（红线延续，全文见规格 §3）

- 不写「自动替你决定」的能力；AI 一律默认关、可降级、须授权
- 不为了动效牺牲可及性：三档强度 + 系统 reduced-motion 优先 + 环境层幅度上限 2%
- 不为「活」而活：每个动效必须能归入四层纲领之一（响应 / 环境 / 编排 / 生长）
