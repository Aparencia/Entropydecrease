## 一句话

体系概念详情出现「📎 相关素材建议」：以概念名+essence 全库检索 top-K（≤10，**排除已链接**）→ 逐条勾选 → 确认后仅经既有 `link_knowledge_target` 落库（白名单 note/fragment 零迁移，幂等，**建议零双写**）；跨体系相似概念只提示不合并（人工处置）。feature flag `kb_discovery` 默认关——设置 → 学习库可开启（后端 command 同步把关）。

- Rust：kb_discovery 6 用例（overlap 双向/单字拒绝/全角归一化、证据排除已链 note 与 fragment、跨体系相似仅跨体系、概念不存在 None）+ feature_flags kb_discovery roundtrip/legacy——`kb_discovery feature_flags` 过滤全绿

- Rust 全量：**2052 通过 / 2 失败（note_filter 预存 TD-30-B）**；clippy 零告警

## 治理落地

- 默认关：kb_discovery=false（UI 零渲染 + command 报错双保险）；命中检索恒可用不受开关约束
- 铁律：建议不落库、零双写——确认路径唯一 = link_knowledge_target（幂等语义既有）；相似概念为提示型（不自动合并——无合并命令且语义归人，YAGNI）
- 性能：按实体现算（个人量级 <100ms），无后台批处理/无自动聚类任务（设计 §八 一致）
