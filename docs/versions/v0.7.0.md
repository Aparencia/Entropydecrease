## 三、核心技术架构决策

### 决策 1：FEAT-013 账户体系完善方案

**现状**：Supabase 客户端、Auth Context/Provider、Login/Register 页面、AuthGuard、API token 注入、双后端 JWT 验证均已实现。缺失：用户 Profile 管理、密码重置、邮件验证回调 UI、Token 过期全局提示。

**方案**：
- 新增 `client/src/pages/settings/ProfileSettings.tsx` — 用户头像/昵称/邮箱展示与编辑
- 新增密码重置流程：`supabase.auth.resetPasswordForEmail()` + 回调页面
- 增强 AuthContext：添加 `sessionExpired` 事件，全局 Toast 提示重新登录
- 新增 `client/src/pages/ResetPassword.tsx` 路由 — 处理重置回调
- 新增 `client/src/pages/VerifyEmail.tsx` 路由 — 处理邮件验证回调
- Dexie 新增 `userProfile` 表（Schema v8）缓存用户信息，支持离线展示

**关键文件**：新建 `client/src/pages/settings/ProfileSettings.tsx`、`client/src/pages/ResetPassword.tsx`、`client/src/pages/VerifyEmail.tsx`、修改 `client/src/lib/auth/AuthContext.tsx`

### 决策 2：FEAT-014 自定义标题栏

**现状**：BrowserWindow 使用默认系统标题栏（`frame: true`），无自定义标题栏组件。

**方案**：
- `main.ts` BrowserWindow 配置改为 `frame: false`
- 新增 `client/src/components/layout/CustomTitlebar.tsx` — React 组件实现标题栏
- 标题栏高度 32px，包含：左侧 Logo+标题、右侧最小化/最大化/关闭按钮
- 使用 `-webkit-app-region: drag` 实现拖拽，按钮区域 `no-drag`
- IPC 新增 `window:minimize`、`window:maximize`、`window:close`、`window:isMaximized` channel
- 兼容 Windows 贴边最大化（`win.setBounds` 监听 `will-resize` 事件）
- AppLayout 结构调整：标题栏固定在顶部，Sidebar + 主内容区在标题栏下方

**关键文件**：新建 `client/src/components/layout/CustomTitlebar.tsx`、修改 `client/electron/main.ts`、`client/electron/preload.ts`、`client/src/components/layout/AppLayout.tsx`

### 决策 3：FEAT-047 灵感空间 AI 整理

**现状**：灵感空间已实现录入+AI 打标（未连通）+筛选。后端 `tag-content` 端点已实现但前端 `RemoteAIPlugin` 和 `ElectronAIPlugin` 均未实现 `tagContent` 方法。AI 分拣/归类功能完全缺失。数据存储在 localStorage（非 Dexie）。

**方案**：
- **Phase 1（打通打标链路）**：在 `RemoteAIPlugin` 和 `ElectronAIPlugin` 中实现 `tagContent()` 方法，连接后端 `/api/v1/ai/tag-content`
- **Phase 2（新增分拣 Chain）**：后端新增 `SortInspirationChain`，分析灵感内容并建议归类目标（费曼笔记/闪卡/普通笔记/待办）
- **Phase 3（前端分拣 UI）**：灵感卡片上新增"AI 整理"按钮，展示归类建议 + 一键转化
- **Phase 4（数据迁移）**：灵感数据从 localStorage 迁移到 Dexie（Schema v8 新增 `inspirations` 表）

**关键文件**：修改 `client/src/lib/ai/RemoteAIPlugin.ts`、`client/src/lib/ai/ElectronAIPlugin.ts`、新建 `server/ai-gateway/chains/sort_inspiration_chain.py`、`server/ai-gateway/routers/inspiration_router.py`

### 决策 4：版本更新系统增强

**现状**：updater.ts 已实现自动检测+下载+安装流程，UI 有 UpdateNotification + AboutSettings。但 publish 配置被注释、无 releaseNotes 展示、无自动更新开关。

**方案**：
- 激活 `electron-builder.yml` publish 配置
- UpdateNotification 增加 releaseNotes 渲染（Markdown 渲染 changelog）
- 设置页新增"自动检查更新"开关（默认开启）
- 新增下载失败重试机制（最多 3 次，间隔递增）
- AboutSettings 增加"当前已是最新版本"状态展示

**关键文件**：修改 `client/electron/updater.ts`、`client/src/components/ui/UpdateNotification.tsx`、`client/src/pages/settings/AboutSettings.tsx`、`client/electron-builder.yml`

### 决策 5：BUG-004 修复方案

**根因**：`main.ts` 的 `close` 事件使用 `win.hide()` 隐藏窗口（非最小化）。`second-instance` 事件只检查 `win.isMinimized()` 并调用 `restore()`，但隐藏窗口的 `isMinimized()` 返回 false，`focus()` 对隐藏窗口无效。

**修复**：在 `second-instance` handler 中添加 `!win.isVisible()` 检查，调用 `win.show()` + `win.focus()`。

**关键文件**：`client/electron/main.ts`

## 八、被拒绝的替代方案

| 替代方案 | 拒绝理由 |
|---------|---------|
| 自定义标题栏使用 Electron `titleBarStyle: 'custom'` | 仅 macOS 支持，Windows 需 `frame: false` + 手动实现；统一方案更可控 |
| 灵感空间 AI 分拣使用本地 LLM | 桌面端本地模型能力不足，分类准确率低；后端 Chain 方案可复用云端模型能力 |
| 账户体系自建后端（非 Supabase） | Supabase 已集成 Auth，自建后端增加维护成本且安全性更低 |
| 笔记导入使用 Pandoc 外部工具 | 引入外部依赖增加安装包体积和安装复杂度；纯 JS 实现 Markdown 转换足够 |
| 自适应番茄钟使用机器学习模型 | 数据量不足以训练有效模型；加权平均+规则方案更简单可靠 |
| 关闭窗口确认使用系统原生对话框 | 原生对话框样式不统一且无法自定义选项；React 组件方案更灵活 |

## 十三、代码审查检查清单

每个 v0.7.0 PR 合并前需通过以下审查项：

### 通用审查项

- [ ] **编译通过**：`npm run build` 无错误
- [ ] **测试通过**：新增/修改代码附带对应测试，`vitest run` 全部 pass
- [ ] **无新增 TODO**：除非 TODO 关联了本版本后续步骤编号（如 `// TODO [v0.7.0-B2.3]`）
- [ ] **无 console.log**：生产代码中不允许 `console.log` 调试输出（logger 除外）
- [ ] **类型安全**：无新增 `any` 类型（除非有注释说明理由）；TypeScript strict 模式无新增 error

### 窗口架构审查项（Alpha.1 / Beta.1 步骤强制）

- [ ] **IPC 安全**：所有新增 IPC channel 使用 `safeHandle` 模式注册
- [ ] **frameless 兼容**：自定义标题栏拖拽区域正确设置 `app-region`；按钮区域为 `no-drag`
- [ ] **布局完整性**：AppLayout 调整后所有页面布局无遮挡、无溢出
- [ ] **贴边测试**：多分辨率（1080p / 1440p / 4K）下贴边行为正常

### 账户体系审查项（Alpha.2 步骤强制）

- [ ] **Token 安全**：Token 过期事件有全局监听；401 响应不泄露敏感信息
- [ ] **Dexie 迁移**：Schema v8 迁移有备份机制；迁移失败可回滚
- [ ] **离线兼容**：Profile 数据有本地缓存；离线时展示缓存数据

### AI 能力审查项（Beta.2 步骤强制）

- [ ] **错误处理**：AI 请求失败时 UI 有明确提示；不阻塞主流程
- [ ] **confidence 展示**：分拣建议展示置信度；低置信度标注"仅供参考"
- [ ] **数据迁移**：localStorage → Dexie 迁移使用事务；迁移完成后清除旧键

### 数据审查项（Beta.3 / Beta.4 步骤强制）

- [ ] **导入安全**：Markdown 导入做文件类型+大小校验；防止恶意文件
- [ ] **重置确认**：学习进度重置有二次确认弹窗；操作记录到 operationLog
- [ ] **算法冷启动**：自适应算法在无历史数据时使用默认值；不抛异常
