## 一、阶段目标

1. **信任收尾**（REQ-098~107）：ASR 置信度体系真实化（融合/过滤/质量报告三处消费假数据的根治）；"已交付未接线"悬空机制治理；质量报告指标从"恒 0"变真实；音频预处理链 CER 基准闭环；讲者诚实降级；剪贴板/音频事件信号；日志脱敏与数据备份
2. **存储使能 M-存储**（REQ-108~110）：统一信号事件表（一次 schema、消费端分批接线）；段级元数据列扩展；档案级存储策略档位（文本优先/均衡/图像优先）+ 图像流存储层（时间轴帧序列）
3. **类型扩展（三通道）**（REQ-121~124）：编程实战（示例代码提取，OCR+ASR 通道）；播客/有声书（ASR-only 短路）；跟练型（图像流通道首个档案）+ 顺带图像流档案组（直播/白板/游戏教程/题目讲解）
4. **注意力信号**（REQ-125~129）：播放器行为信号（含倍速感知采样）；分应用音频路由（环回污染根治）；抢话/打断（代理版）；前台时间线（落库+消费，纯规则）；样式信号暴露面核查
5. **平台与图像**（REQ-130~134 + REQ-088）：无音/无图短路；模型版本管理；剪贴板图片直贴；图内文字检索入口；图片裁剪去白边；图注生成（影子层第一步）

> 本阶段**不做**（2026-08-19 用户裁决）：定制轴全部（C1–C18，留 V1.0）；闭环轴全部（K/X/V/A/D/E，含 E1 导出/A4 周报/D1 速览，留 V1.0）；M2 光标锚点/M4 书写重建/M9 双语对齐/M15 提问绑定（远期）；M3 弹幕（关闭）；T5 语言/T6 纪录/T7 圆桌/T10 纯字幕/T12 表达（远期或不做）；P3 多语言/P9 其余导入源（V1.0）；P1/P2/P7/P8/P10/P12/P14（远期）。

## 三、技术方案

### M0 前置（未通过不启动开发）

- **v0.6.0 M7 端到端真机验收**（用户执行）：M1–M6 各机制真机生效 + 3 节课对比 + **P6 高 DPI/缩放核查**（150%/200% 缩放下 OCR 输入分辨率与区域坐标换算）并入验收清单
- **X-O5 行数红线拆分**：live_session.rs（798 行）/streaming_asr.rs（378 行）超限硬拆（M7 承诺强制兑现）
- 范围冻结确认：本版 37 项 REQ（098–134 + 088 提前），spike 项结论可裁剪

### M1 信任收尾（REQ-098~107）

1. **置信度体系真实化（REQ-098，最高优先）**：`live_session.rs`/`import.rs` 硬编码 0.9/0.8 替换——重打分一致性（asr_rescore 已有相似度计算）作为代理置信度；无法产出时落 None（诚实表达未知）；`subtitle_ocr.rs` 投票置信度落库（CORE-D4 修复）。前置校准：重打分一致性 vs 真实识别错误率相关性（合成样本矩阵）
2. **悬空机制治理（REQ-099）**：四处（PRE-D1 预处理链/POST-D1 讲者/POST-D2 音量/CORE-D5 DTW）逐个决策，写决策记录；讲者走 REQ-102 诚实降级、音量走 REQ-103 接线、预处理链走 REQ-101 闭环、DTW 保持机制先行（CORE-O4 实测留验收后）
3. **质量报告指标修正（REQ-100）**：`quality_report.rs` 低分统计改双源（engine `ocr_failures` AtomicU64 + 落库低分块）；加重打分超时率
4. **预处理链闭环（REQ-101）**：`audio_preprocess.rs` CER 微基准脚本（S4 落盘音频）→ 默认值 → 设置 UI 开关（与 X-O3 配置 UI 化衔接，配置面板随 V1.0 全面化，本版先出开关）
5. **讲者诚实降级（REQ-102）**：产物模板移除"讲者"占位/显式不可用标注；sherpa SpeakerEmbeddingExtractor 接线时机=V1.0 模型分发波
6. **段级 volume 接线（REQ-103）**：`analysis.rs` SegmentInput.volume 从恒 None 改为段聚合 RMS；segments 新列 ensure_column 幂等迁移
7. **剪贴板信号（REQ-104）**：会话期间剪贴板监听（仅课中+仅信号不持久化原始内容）；产物/热词候选接入；与 REQ-132 剪贴板图片共用监听
8. **音频事件过滤（REQ-105）**：固定音模式库（微信/邮件提示音）→ VAD 门控联动；M10（REQ-126）实装后降为兜底
9. **日志脱敏（REQ-106）**：诊断日志过滤层（OCR 文本/会话标题）
10. **备份/恢复（REQ-107）**：数据目录打包+恢复入口；与 E1 导出解耦独立实现

### M1.5 M-存储 使能层（REQ-108~110）

1. **统一信号事件表（REQ-108）**：事件类型（frame_switch/long_silence/volume_surge/vad_segment/clipboard/foreground_switch/player_behavior）+ 容量设计（分级落库防写放大）；`analysis.rs` 章节检测消费真实信号（POST-D3 修复）；为 V1.0 K1 备输入
2. **段级元数据列（REQ-109）**：volume/语速/停顿 + speaker 影子列预留
3. **档案级存储策略档位 + 图像流存储层（REQ-110）**：`image_store.rs` 档位参数化（文本优先=现状 50 张预算/均衡/图像优先=时间轴帧序列全量+分级标记）；图像流存储=帧流+时间戳+步骤边界；真机磁盘占用实测定阈值；C1 档案工厂滑块预留

### M2 类型与信号（REQ-121~129）
