# v0.17.0：AI 精修可到达度——策略化提示词 + 笔记级 AI 能力 + 流式会话化

> 状态：已交付（2026-09-01，代码建设完成）
> 依据：用户对话——①「AI 精修提示词可选项」（例子具体程度/概念学术通俗/原文保留程度等）②「笔记页编辑模式使用 AI 精修（手写刚需）+ 知识补充并入编辑模式入口」③「精修会话化：跳转 AI 对话、显示所发送提示词、流式返回、完成后回到会话/查看笔记」④观众视角价值体系分析（旋钮设计依据）
> 设计：[spec 2026-09-01](../superpowers/specs/2026-09-01-ai-refine-strategy-flow-design.md) · [ADR-026](../adr/ADR-026-ai-refine-strategy-flow.md) · REQ-245/246/247

## 一、目标

精修从「固定模板」升级为「用户可到达」：发起时选**目标/变化程度**（书面 chips + 四档阶梯 + 六旋钮），实时看到**提示词怎么变**（所见即所发），生成时**对话式流式呈现**（片级解析流），完成后**前后对比可溯源**（工作台溯源条）+ **回到会话/查看笔记双入口**；AI 能力从会话级扩展到**笔记级**（手写笔记刚需——编辑态 🤖 AI 统一入口）。
