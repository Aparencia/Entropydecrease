## 口径与决策记录（本档）

- **REQ-285（拖拽加速）**：根因=`ColumnResizer` 每次 move 传距起点累计位移（clientX-startX），而 `useColumnLayout.resizeBy` 为增量语义（cur+delta）→ 重复累加=「加速」。修复=lastX 相邻增量；补 `role=separator`+tabIndex：←/→ 步进 ±16px（Shift=±8px），双击复位保留（§2.9 矩阵）。
- **REQ-282（标题 A 层）**：`title_kind TEXT NOT NULL DEFAULT 'source'`（幂等加列零重建）；人工改名 `update_session_title` → kind='manual' 永久停覆写；同源去重=创建点（实时 start_live_session / 视频导入）对近 90 天非失败标题做 `dedupe_title`（先 normalize 剥平台尾缀白名单，纯函数）；首句升级=融合完成钩子（成功与失败路径都尝试；仅 kind=source 且 8–40 字可用句，纯音乐/全符号不升级）成功后广播 sessions 域。窗口标题净化只剥「- 抖音」式尾缀一次（浏览器「xxx - 抖音 - Edge」复合尾缀留待内容句升级兜底——诚实边界）。
- **REQ-290（埋点先行）**：每片每次 attempt 记录 ok/fail elapsed_ms（含片序/总数/重试次数）日志行；流式/首 delta 埋点随 v0.19.7 上线（§2.8 ③）。真机基线=3 条真实会话 A/B（本档登记）。
- **REQ-281（帧心跳/watchdog）**：`frame_liveness.rs` 纯状态机（采样新鲜度 1.5s gate；STALL_SECS=5s；重建节流 30s；心跳 2s）；判定仅 WGC 窗口捕获模式 + 目标可见（IsIconic/IsWindowVisible，业界口径失焦不停）；副作用在 `run_screen_worker` 采样拍后执行——stall_edge → `live:frame-stalled{silentSecs}`，恢复帧 → `live:frame-recovered`，心跳 `live:frame-heartbeat{backend,gotFrame,silentSecs,visible}`；`revive_wgc()` 重建失败降级 DXGI（不回切，沿用既有周期重建）。idle 探针/暂停不喂停更判定（探针 5s 拍被新鲜度 gate 兜底）。
