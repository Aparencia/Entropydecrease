## 沉淀规则

- **何时沉淀**：版本含重大架构变更、多模块协同发版、或值得事后回顾的决策时，为版本撰写深度文档
- **目录 vs 单文件**：单一文档用 `vX.Y.Z.md`；多文档合集建 `vX.Y.Z/` 目录，内部文档用 `NN-描述.md` 编号
- **命名**：文件名使用 kebab-case 或中文短描述，禁止带版本号之外的临时后缀（如 `重制2`）
