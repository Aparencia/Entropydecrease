# v0.18.2：AI 目标规划师——规划建议 + 体系深度联动（建议制 · 默认关）

> 状态：**M1 批已实施**（2026-09-02；真机验收待执行）
> 依据：用户 2026-09-02 重裁决（双入口/建议制确认落库/联动四项全选/AI 提供初步体系/默认关+授权确认）· [设计规格（已批准，[ ] 已归档）](../archive/2026-09-02/2026-09-02-v0.18.2-ai-goal-planning-design.md) · [ADR-028](../adr/ADR-028-ai-goal-planner.md) · REQ-251~254

## 一句话

AI 结果=**草案蓝图**（里程碑/组/体系/周契约），人类逐项确认后落库；AI 默认关（content_gate + 目标 AI 独立开关双闸门）；AI 失败/超限/未开启 → M1 规则草案永远可用（目标规划永不依赖 AI）。

## 本批已交付

| 层 | 内容 |
|---|---|
| 纯函数 | goal_plan_protocol（Proposal 强校验 golden：白名单/体系门槛/超限丢弃登记）· budget_allocator（4K/10K/30K 档位，O(1) 恒量截断+诚实信号）· goal_summary（L4.5 现算 <1K）· concept_weakness（90 天低激活）· goal_plan_prompt（prompts/goal_plan.json 声明式+兜底） |
| 数据层 | knowledge_links 白名单 +'goal'（零迁移）· link_goal_to_system（幂等查重先行）· goal_concept_activities（应用记录 Rust 解析防坏 JSON 中断）· goal_plan_context（库即记忆最小面）· apply_plan_core（替换/增量双语义事务，周契约落主组） |
| AI 层 | ai_goal_plan_estimate（先预估）· ai_goal_plan（双闸门/授权/余额硬拦/预算截断/ai_tasks 审计轨迹+成本；spawn_blocking 同步交互，任务化轮询登记观察项） |
| 确认流 | goal_apply_plan（存在性校验/体系骨架 create 逐条独立事务——部分失败不污染目标层；link 幂等） |
| 前端 | GoalPlanApprovalDialog（勾选/编辑/体系 create-vs-link/周契约可改/清洗登记/规则回退）· 双入口（InterviewDialog ✨ / GoalDetail 💡）· 最弱概念块 · 设置字段（goal_plan_enabled 默认关 + 档位）与 ai_set_goal_plan |

- **设置页「目标 AI」段 UI**（开关/档位选择器）——后端命令与字段已就绪，UI 下批（当前可从错误文案引导 + ai_set_goal_plan 直调）

## 测试与验收

- 纯函数 golden：协议校验矩阵/预算 O(1)/摘要边界/弱概念边界/模板捆绑（45 目标组用例）
- 数据/命令：apply_plan_core 事务（替换/增量/无绑定组拒绝）/link 幂等/概念弱信号链路（80 用例）
- 验证：vitest 509 全绿 · tsc 零错误 · clippy 零警告（预存 note_filter 2 例除外）
