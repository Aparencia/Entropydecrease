# v0.12.7：会话内部 ID 不外显

> 状态：代码已交付（2026-08-23）
> 依据：用户指令「会话不外显 ID」（2026-08-23）

## 一句话

界面所有用户可见文案不再出现会话内部 id（AUTOINCREMENT 主键），仅保留会话列表的显示序号
（display_no——v0.11.5 起与内部 id 解耦，按时间序 rank，删除会话后自动归位）。

## 背景

v0.11.5「会话编号显示序号化」已让列表/详情展示编号 = display_no，但采集/导入/融合等实时路径的
状态文案仍直接回显内部 id（如「会话 #12」）——「内部 id 用户不感知」的约定漏网。本次收口。

## 边界（不改）

- 会话列表 `#{display_no}`：显示序号（非内部 id），保留
- 内部引用（invoke 参数 / React key / 笔记↔会话跳转）：继续用内部 id，用户不感知
- 笔记 id（`笔记 #N` 等）不在本次范围
