## 一、阶段目标

1. **提取纯度**（REQ-059/060/061/082/083/084/085）：水印台标角标不进产物与术语统计；口语数字/符号规范化；术语候选精化（TF-IDF+缩略词）；**笔记废话出口过滤（UI 垃圾/重复/碎片）+ 字幕 UI 垃圾源头过滤（黑名单）+ 字幕 ROI 窗口切换检测 + AI 复核（边界段三态判定，SiliconFlow 付费默认档）**
2. **融合与时间戳**（REQ-062/063/064）：融合从硬规则升级概率加权；字幕 OCR 流与 ASR 流 DTW 对齐回校时间戳；章节边界时序平滑
3. **画面提取**（REQ-065/066/067）：OCR 多帧加权投票；帧新颖度采样（预算花在新内容上）；aHash+dHash 双指纹去重
4. **音频与信号**（REQ-068/069/070）：实时链路音频落盘（策略先行）；VAD 阈值自适应；练习段识别
5. **性能资源**（REQ-071~075）：采集链路低分配；长会话内存有界；空闲降频；OCR 区域批处理；图片编码线程核查
6. **会话体验**（REQ-076~081）：会话级质量报告；纯规则大纲视图；课程级分组；搜索增强；降级分级可见化；**笔记预览视图（过滤后只读预览 + 统计 + 被过滤对照 + 一键落库）**

> 本阶段**不做**：S1 课件直读、V4 课后全量两遍解码、P2 指代消解、Q3 校对反哺、P5 代码块结构化、F4 跨会话去重、S3 多窗口、S5 麦克风、UX7 Onboarding、UX10 无障碍、PF3 模型档位（gaps doc §9 第三批，V1.0/v0.7.0 再议）；P1 动画渐进合并、UX1 透明置顶迷你条（gaps doc §9 未选，待议）；C7 导出体系、X1–X10 会话域候选（gaps doc §10，待议）；闪卡（REQ-019/020 继续顺延，用户决策）。

### M1 提取纯度（REQ-059/060/061/082/083/084/085）

> 目标：产物与术语统计的"输入干净化"。三机制共用"原料层不动、产物层可逆"原则（沿用 B5 书面化先例）。
> **2026-08-19 追加**：笔记废话出口过滤（REQ-082）+ 字幕 UI 垃圾源头过滤（REQ-083/084）+ AI 复核过滤（REQ-085）——源头治本 + 出口兜底 + AI 增强三层净化。

1. **水印/台标/角标过滤（REQ-059）**：`watermark_filter.rs` 纯逻辑——区域稳定性（同坐标出现 ≥N 次）+ 文本不变性（内容不随版面变化）→ 水印候选集；OCR 产物过滤 + 术语统计排除（挂 REQ-061 前置）；误杀兜底：阈值校准 + 产物层可逆（原始 OCR 块保留，仅产物视图隐藏）
2. **数字/单位/符号规范化（REQ-060）**：`symbol_normalize.rs` 纯逻辑——发音→符号映射表（数字/希腊字母/运算符/快捷键组合）+ 上下文判定（"三点一四"数字上下文 vs "派别"非符号）；接入产物层书面化管线；映射表 JSON 可校准
3. **术语发现精化（REQ-061）**：`glossary.rs` 增强——现 OCR 高频×ASR 低频交叉之上：跨会话文档频率（TF-IDF 权重，降通用词）+ 缩略词模式（全大写序列/字母数字混合）+ 水印词排除表（REQ-059 输出）
4. **字幕 UI 垃圾源头过滤（REQ-083）**：`subtitle_ocr.rs`/`live_session_frame.rs` 入口加 `is_ui_junk()` 纯函数——水印（"学习资料"等下载站/平台水印特征）/播放器 UI（"选集/弹幕/倍速/1080P/高清/00:xx/ 时间码"）/编辑器 UI（"UTF-8/LF/行 \d+/已选择"）/应用 UI（"回到主界面"）特征命中 → 该帧文本不进字幕投票器（不落 OCR 块/不落段/不推事件）；黑名单 JSON 可校准；与 REQ-059 区域稳定性过滤互补（文本特征 vs 区域特征）
5. **字幕 ROI 窗口切换检测（REQ-084）**：`region_tracker.rs`/`live_session_frame.rs`——前台活动窗口变化（与录制目标窗口句柄不一致，复用 windows.rs 枚举能力）→ 强制 `reset_scan()` 重扫 ROI；切换期间 ROI 内文本不再延长空帧计数（防"新窗口恰好有文本"导致 ROI 继续抓错）；误触发阈值校准（前台探测失败静默跳过）
6. **废话出口过滤管线（REQ-082）**：`note_filter.rs` 纯逻辑——过滤链：① 相邻重复段合并（同文本连续段，含 asr/fused 混杂——融合重复 bug 修复后的兜底）；② 碎片段丢弃（≤2 字 / 时长 <500ms / 纯符号数字标点）；③ 低置信丢弃（confidence <0.6）；④ UI 垃圾特征兜底（复用 REQ-083 黑名单）；输出 `NoteFilterResult { markdown, stats: {ui_junk, duplicates, fragments, low_confidence}, filtered: Vec<FilteredItem{reason, text, time}> }`；`session_to_note` 与 `preview_session_note`（REQ-081）共用单一管线
7. **AI 复核过滤（REQ-085，2026-08-19 头脑风暴）**：规则层无法判定的边界段（口头禅/寒暄离题/ASR 破碎句/截断半句/语义重复/过渡句）→ 云端付费模型批量三态判定
   - **协议**：`ai_protocol.rs` 扩展 `AiRequestType::TextFilter` + `TextFilterResponse { action: keep|delete|merge, confidence, reason, merge_with: prev|next|null }`——schema 强校验，非法响应丢弃（回退规则结果）
   - **判定模型**：截断半句先判上下文衔接——与上一段/下一段拼接后语义完整 → `merge`（保留 + 标记衔接段）；前后都接不上 → `delete`（无效信息）；其余五类按标准删/留；**绝不改写文本、不纠正错词**（错词属书面化域，AI 不越界）
   - **模型接入**：`ai_text_filter.rs` 适配器（默认 SiliconFlow，OpenAI 兼容端点，模型名/端点/密钥全部环境变量注入——AGENTS.md 环境隔离铁律）；`temperature=0` + JSON 模式（`response_format: json_object`，推理模型若输出思考标签用 no_think 参数关闭）；批量上限 30 段/请求；超时 + 重试 + 失败降级
   - **默认模型（2026-08-19 硅基流动实测选型，可商用免费档）**：`deepseek-ai/DeepSeek-R1-0528-Qwen3-8B`——**¥0/M 免费 + MIT 许可商用无忧**（[HuggingFace 官方 LICENSE: mit](https://huggingface.co/deepseek-ai/DeepSeek-R1-0528-Qwen3-8B)），DeepSeek 官方轻量推理模型（Qwen3-8B 架构，128K 上下文），中文/指令遵循/逻辑强，单 GPU 可跑；**成本 ¥0/会话**；注意点：推理模式延迟略高（批量单请求可接受）、JSON 稳定性实现时实测（不达标可配置切回付费档）
   - **备选可切换**：`Qwen/Qwen3-30B-A3B-Instruct-2507`（付费质量档，in ¥0.7/M out ¥2.8/M ≈ 6 厘/会话，非思考模式低延迟，Apache-2.0 商用无忧）/ `GLM-4-32B-0414`（in/out ¥1.89/M，GLM 结构化输出口碑好，商用需智谱登记）；模型名走配置切换零代码改动
   - **提示词模板**：`prompts/text_filter.json` 独立可校准（项目"映射表 JSON 可校准"先例）——六类删除标准显式定义 + 保守原则（宁可保留不可误删：不确定 → keep 且 confidence ≤0.6；技术术语/数字/专名即使片段也保留）+ 真实样本 few-shot（口头禅删/技术保留/破碎句删/截断句 merge 两态）+ 严格 JSON 输出约束
   - **成本控制**：只送边界段（典型 20~30 段/会话，非全量）；批量判定降请求数；同文本 hash 缓存（`ai_guardrails.rs` `AiHashCache` 扩展文本 key——同句不重复送/计费）；每日配额（复用 `DailyQuota`）；审计（上传摘要 + 判定结果可见）
   - **安全红线**：AI 调用用户授权且默认关闭；上传前"将发送 N 段文本至 SiliconFlow"确认；审计可见可查；离线降级铁律——AI 不可用/超配额/无授权 → 纯规则结果原样输出（不丢不假）
   - **触发交互**：笔记预览视图内「✨ AI 复核」按钮按需触发（默认先展示纯规则结果秒出）；可重跑；判定结果就地更新预览，被过滤对照新增"AI 判定"来源 + 理由；merge 段在预览正文以拼接形态展示（仅展示层拼接，落库仍按原始段——原料不动原则）
8. **测试**：水印合成帧 golden；符号映射表语料单测；术语候选质量 golden（注入角标/通用词/缩略词混合语料）；is_ui_junk 特征矩阵单测（真实会话 8/11 垃圾字幕样本）；ROI 窗口切换合成样本；note_filter 过滤链单测（重复/碎片/低置信/UI 垃圾各场景 + 误杀保护：正常长句/数字内容不误删）；AI 复核——mock 适配器全链路（沿用 ai_mock.rs 模式）+ schema 校验（非法响应丢弃回退）+ 提示词模板回归（固定样本断言结构/判定不漂移）+ merge 判定两态样本 + 降级路径（无授权/超配额/网络失败/超时 → 纯规则输出）+ 预览与转笔记输出一致性

### M2 融合与时间戳（REQ-062/063/064）

> 目标：融合决策从"硬规则"到"概率+时序"，时间戳从"近似"到"对齐"。REQ-063/064 依赖 M4 的 S4 落盘（实测数据源）。

1. **融合置信度加权（REQ-062）**：`fusion.rs` 升级——编辑距离 ≤2 硬规则改为概率加权：`P(胜出) = f(字幕投票置信度, ASR 段置信度)`；双源低置信 → 低置信标记（B3 已有落库通道）；保留原硬规则为兜底开关
2. **DTW 时序对齐（REQ-063）**：spike 先行——采集真实会话字幕 OCR 流与 ASR 流（S4 落盘音频+现有段数据）实测漂移分布；有收益则 `dtw_align.rs` 纯逻辑（文本序列对齐 → 时间戳回校，字幕 end_ms 滞后修正）；无收益则裁剪并记录结论
3. **章节边界平滑（REQ-064）**：`chapter_detect.rs` 增强——三信号投票硬决策 → 时序状态机（章节内/边界候选/确认）+ 最短章节时长先验 + 边界抑制；输出仍为章节边界事件（下游零改动）
4. **测试**：合成双源置信度矩阵（REQ-062）；合成漂移样本对齐正确率（REQ-063）；合成会话状态序列（REQ-064）

### M3 画面提取（REQ-065/066/067）

1. **OCR 加权投票升级（REQ-065）**：`subtitle_ocr.rs` 升级——字符平权投票 → 清晰度（帧差分能量）× score 加权；字幕行帧间 tracking（同一字幕行的多帧组内时间平滑，翻页瞬间错帧不参与）；前置核查 oar-ocr score 暴露面，未暴露则启发式权重（尺寸/对比度）
2. **帧新颖度采样（REQ-066）**：`region_tracker.rs`/采样器升级——预算内选帧按"新颖度"排序：与 OCR 缓存（E5 已有 LRU）及上一帧文本重叠率低 → 优先；定位与变化检测的关系：变化检测=过滤无变化帧（布尔），新颖度=预算内排序（连续值），两级串联
3. **去重指纹混合（REQ-067）**：`frame_cluster.rs`/`image_store.rs` 升级——aHash 汉明 ≤6 判定改为 aHash+dHash 双指纹（任一显著变化即新簇，双稳定才合并）；帧聚类与图片去重共用同一判定函数
4. **测试**：模糊/翻页帧投票对比基准（REQ-065）；预算分配单测（REQ-066）；旋转/缩放样本去重 golden（REQ-067）

### M5 性能与资源（REQ-071~075）

> 原则：先测后优（诊断面板数据驱动）；全部可裁剪项——性能项收益不达标则裁剪不阻塞主线。
