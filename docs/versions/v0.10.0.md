## 一、阶段目标

1. **可用的笔记（③）**：Markdown 渲染（替换 `<pre>` 源码预览）+ 编辑保存（复用 versioned_save 版本链）+ 新建手动笔记
2. **好用的笔记（④）**：时间戳回链（笔记段落 ↔ 会话时间点，提级 P1）+ 标签/固定/排序 + 快速捕获 + 笔记健康度基础版
3. **离不开的笔记（⑤）**：结构钩子（回链制造回访、回顾流、AI 问答 P2）+ A 层特征（段落级操作、搜索高亮、版本可视化、回链预览、注意力跟踪）

> **笔记定位（头脑风暴定稿）**：**笔记 = 视频学习过程的「活沉淀」——会话产物的结构化文档，
> 以时间戳回链锚定视频证据，经编辑与 AI 持续演化，可被检索、回顾与再次出发。**
> 市场对照：听悟/妙记的笔记是「记事的终点」（产出即终态）；Obsidian/Notion 是「写作的起点」（无提取上游）；
> 我们的笔记是「**学习的枢纽**」（沉淀于会话、锚定于证据、反哺学习）。

### 克制哲学

v0.10.0 的**克制是范围纪律，不是质量妥协**。在笔记模块的边界内，
把该做的事情做到极致：

- **三层过滤**：产品定位过滤（不做 Notion 式工作区、不做 Obsidian 式知识库）
  × 技术架构过滤（与 Markdown 存储冲突的不做、与本地优先冲突的不做）
  × 范围纪律过滤（属多笔记组织体系的不做、属闪卡体系的不做）
- **克制结果**：13 项舍弃 + 5 项延后 = 18 项「不做或迟做」，14 项基础 + 5 项 A 层增强 = 19 项「做」
- **核心判断**：③可用完全覆盖，④好用基本覆盖，⑤离不开以 A 层增强补结构钩子缺口

## 三、数据模型设计（含迁移）

**notes 表新增三列**（向下兼容，旧数据零迁移成本）：
- `tags TEXT NOT NULL DEFAULT '[]'` — JSON 数组 `["编程","课程A"]`
- `properties TEXT` — JSON 对象，扩展位（NULL=无）
- `pin INTEGER NOT NULL DEFAULT 0` — 固定标记（0=未固定，1=固定）

后端命令增量（少量新增 + 修改）：
- `update_note_tags`（幂等合并 tags）
- `update_note_properties`（仅写入，不设前端编辑 UI）
- `list_notes` / `search_notes` 返回 tags/properties/pin（已有命令扩列）
- `list_notes` 支持排序模式：updated_desc / pin_first / created_desc
- 其余复用：get/update/delete/versioned_save 等已有命令

## 四、功能能力清单

### P0-1 阅读视图（替换 `<pre>`）
- Markdown 全渲染：标题/粗斜体/列表/有序列表/表格/LaTeX/代码块高亮/引用/图片/链接
- 任务列表 `- [ ]` 可勾选（勾选 → 重写该行回 content，**不建版本**）
- 大纲面板：按 `#` 标题生成 TOC，点击滚动

- 信息条：来源会话（已有双向跳转）+ 创建/更新时间 + 净化统计入口 + 当前版本号 + 标签列表
- **A2：笔记内搜索高亮定位** — `Ctrl+F` 唤起搜索条，正则匹配高亮，`Enter`/`Shift+Enter` 上下跳转

### P0-2 编辑视图
- 源码编辑（textarea 起手，零依赖）+ 顶部工具栏：B/I/标题 H1-H3/无序列表/有序列表/引用/代码块/表格/链接/LaTeX/图片

- 快捷键：Ctrl+B/I（包裹）、Ctrl+E（切换）、Ctrl+S（保存建版本）
- **A1：段落级操作** — `Ctrl+Shift+↑/↓` 提升/降低标题层级、`Ctrl+Shift+M` 合并选中连续段、`Ctrl+Shift+S` 拆分段落

- 标题行内编辑
- 编辑态下 EnrichPanel/VersionPanel 降级为「保存后刷新」

### P0-3 新建手动笔记
- 列表「新建」入口 → create_note → 直接进入编辑态 → 保存入列表

- **时间戳回链**（★提级）：会话→笔记落库时 Markdown 内嵌 `[[ts:start_ms]]` 标记；
  渲染为跳转链接 → 会话详情页定位对应转写段/关键帧

- 快速捕获（全局唤起新建/追加，与回链并列评估）

## 五、交互流程

```
列表 → 选中 → 阅读视图（渲染 + 大纲 + 标签 + 信息条）
              ├─ 点击任务列表 → 勾选回写（不建版本）
              ├─ Ctrl+F → 搜索条 → 高亮匹配 → 上下跳转（A2）
              ├─ 点击时间戳回链 → 会话详情页定位（P1）
              │        └─ 悬浮回链 → tooltip 转写预览（A5）
              ├─ Ctrl+E / 编辑按钮 → 编辑视图（源码 + 工具栏 + 即时预览）
              │        ├─ Ctrl+S → 保存建版本 → 回阅读视图
              │        ├─ 失焦/30s → 自动保存（不建版本）
              │        ├─ Ctrl+Shift+↑/↓ → 提升/降低标题（A1）
              │        ├─ Ctrl+Shift+M → 合并选中段（A1）
              │        ├─ Ctrl+Shift+S → 拆分当前段（A1）
              │        ├─ 标签编辑 → update_note_tags
              │        └─ 工具栏 → 插入 Markdown 语法片段
              └─ EnrichPanel/VersionPanel → diff 采纳/回滚 → 刷新阅读视图
新建 → create_note → 编辑视图（空笔记）→ 保存 → 列表出现 + 阅读视图
```

**状态一致性规则**：
- 版本快照只在显式保存/AI 采纳时建立；自动保存只刷新 updated_at
- AI 操作读取最新已保存版本，采纳后强制刷新视图
- 编辑中切走（切页/换笔记）→ 先自动保存再切换，防丢
- A6 注意力跟踪不阻塞主交互，纯统计记录

## 六、技术选型

| 项 | 选择 | 理由 |
|----|------|------|
| 渲染 | react-markdown + remark-gfm + rehype-katex + 代码高亮插件 | 生态成熟、离线纯本地、与 Markdown 存储零摩擦 |
| 编辑 MVP | textarea + 自研轻量工具栏（约 100 行内） | 零依赖、符合克制哲学 |
| 编辑升级位 | @uiw/react-md-editor（若体验不达标再引入） | 轻量首选（~180KB、MIT、双栏） |
| 任务勾选 | 渲染层拦截 click → 行级正则改写 content | 不引入编辑器即可实现 |
| 版本 | 复用 versioned_save（零新增） | v0.8.0 已交付 |
| 时间戳回链 | Markdown 内嵌 `[[ts:ms]]` 标记 + 渲染解析 + 会话页定位命令 | 复用 ArtifactView refs 模式 |
| A1 段落操作 | 编辑态选中文本 → 正则变换 → 单次 update_note | 纯前端 + 一次后端调用 |
| A2 搜索高亮 | 正则匹配 DOM 文本节点 → `<mark>` 包裹 | 纯前端，零依赖 |
| A4 版本卡片 | 版本列表 + diff 预览 → 结构化展示 | 增强 VersionPanel 渲染 |
| A5 回链预览 | 渲染层拦截回链链接 → tooltip 加载转写片段 | 轻量，复用现有回链数据 |
| A6 注意力跟踪 | sessionStorage 统计 + 组件生命周期 + session_event 落库 | 不污染 notes schema |
