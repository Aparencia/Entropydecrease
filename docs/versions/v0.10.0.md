# v0.10.0 — 第十阶段：笔记能力建设（单笔记）

> **状态**: 规划中（2026-08-21 头脑风暴定稿；依据：市场笔记软件调研 + 旧版「结礁」笔记设计参照 + 链条完整性评估「会话→笔记→可用→好用→离不开」）
> **目标**: 将「会话→笔记」生产管线的产物建设为**可查看、可编辑、可溯源、可回溯、可被 AI 增强**的笔记；以「活沉淀」定位——沉淀于会话、锚定于证据、演化为知识、反哺下一次学习
> **依据**: 市场调研（Notion/Obsidian/语雀/飞书/RemNote/通义听悟/妙记，2026-08 检索）· 旧版 theme.md「结礁」定位 · 旧版痛点图谱 P7/P12/P22/P38/P47 · [需求池](../product/requirements-pool.md) REQ-004（笔记基本功能，待评估）· REQ-079/081/082（搜索增强/笔记预览/过滤管线，已排期 v0.6.0）
> **关联**: 版本链/AI 精修/知识补充（v0.8.0）· 会话↔笔记双向关联（REQ-135/136）· 产物视图 refs 时间轴定位（REQ-052）

## 一、阶段目标

1. **可用的笔记（③）**：Markdown 渲染（替换 `<pre>` 源码预览）+ 编辑保存（复用 versioned_save 版本链）+ 新建手动笔记
2. **好用的笔记（④）**：时间戳回链（笔记段落 ↔ 会话时间点，提级 P1）+ 标签/固定/排序 + 快速捕获 + 笔记健康度基础版
3. **离不开的笔记（⑤）**：结构钩子（回链制造回访、回顾流、AI 问答 P2）+ 明确舍弃清单（见 §二.3）

> **笔记定位（头脑风暴定稿）**：**笔记 = 视频学习过程的「活沉淀」——会话产物的结构化文档，以时间戳回链锚定视频证据，经编辑与 AI 持续演化，可被检索、回顾与再次出发。** 市场对照：听悟/妙记的笔记是「记事的终点」（产出即终态）；Obsidian/Notion 是「写作的起点」（无提取上游）；我们的笔记是「**学习的枢纽**」（沉淀于会话、锚定于证据、反哺学习）。

## 三、数据模型设计（含迁移）

**notes 表新增两列**（向下兼容，旧数据零迁移成本）：

```sql
ALTER TABLE notes ADD COLUMN tags TEXT NOT NULL DEFAULT '[]';        -- JSON 数组 ["编程","课程A"]
ALTER TABLE notes ADD COLUMN properties TEXT;                        -- JSON 对象，扩展位（NULL=无）
```

- `tags`：详情页展示 + 列表过滤；标签编辑放编辑视图（简单输入，不做标签管理页）
- `properties`：只写入不编辑（session→note 时自动带：course/domain 等），为 V1.0 组织能力留位
- 内容仍为 `content TEXT`（Markdown 原文）——**不引入块模型**（舍弃清单 #21）

**后端命令增量**（极少量）：
- `update_note_tags`（幂等合并 tags）
- `update_note_properties`（可选，仅写入）
- 其余全部复用：list/search/get/create/delete/update_note（versioned_save）/版本命令/AI 命令

## 四、功能能力清单

### P0-1 阅读视图（替换 `<pre>`）
- Markdown 全渲染：标题/粗斜体/列表/有序列表/表格（复用 renderMarkdownTable）/LaTeX（katex 已有）/代码块高亮/引用/图片（convertFileSrc 本地路径）/链接
- 任务列表 `- [ ]` 可勾选（勾选 → 重写该行回 content，**不建版本**）
- 大纲面板：按 `#` 标题生成 TOC，点击滚动
- 标签展示（点击 → 列表过滤）
- 信息条：来源会话（已有双向跳转）+ 创建/更新时间 + 净化统计入口 + 当前版本号

### P0-2 编辑视图
- 源码编辑（textarea 起手，零依赖）+ 顶部工具栏：B/I/标题 H1-H3/无序列表/有序列表/引用/代码块/表格/链接/LaTeX/图片
- 即时预览（分栏或切换）
- 快捷键：Ctrl+B/I（包裹）、Ctrl+E（切换）、Ctrl+S（保存建版本）
- 自动保存：失焦 + 每 30s 有改动自动存（不建版本）；Ctrl+S 显式保存 → versioned_save 建新版本（「轻量存」与「版本存」两级）
- 标题行内编辑
- 编辑态下 EnrichPanel/VersionPanel 降级为「保存后刷新」（编辑中禁用采纳，防 diff 冲突——**合并语义：AI 操作基于已保存版本**）

### P0-3 新建手动笔记
- 列表「新建」入口 → create_note → 直接进入编辑态 → 保存入列表

### P1 增强
- **时间戳回链**（★提级）：会话→笔记落库时，Markdown 内嵌 `[[ts:start_ms]]` 标记（段落级）；渲染为跳转链接 → 会话详情页定位对应转写段/关键帧（复用 ArtifactView refs 模式，产物视图已实现同构能力）
- 标签编辑（编辑视图内 tags 输入）+ 标签过滤（列表筛选 + 点击标签直达）
- 固定（pin）+ 最近访问排序（Notion/语雀 ⑬ 融合）
- 快速捕获（全局唤起新建/追加，与 ⑩ 并列评估）

### P2 远期（V1.0 关联，本方案仅留接口）
- AI 问答「问我的笔记」（融合清单 #15）
- 轻量回顾流（#16）/ 笔记健康度基础版（#17）/ 导出（#18）
- 选中文本 AI 改写（#11，复用 AiRefine 信任基建）
- 图片/参考图上下文（REQ-093）

## 五、交互流程（功能逻辑层）

```
列表 → 选中 → 阅读视图（渲染 + 大纲 + 标签 + 信息条）
              ├─ 点击任务列表 → 勾选回写（不建版本）
              ├─ 点击时间戳回链 → 会话详情页定位（P1）
              ├─ Ctrl+E / 编辑按钮 → 编辑视图（源码 + 工具栏 + 即时预览）
              │        ├─ Ctrl+S → 保存建版本 → 回阅读视图
              │        ├─ 失焦/30s → 自动保存（不建版本）
              │        └─ 标签编辑 → update_note_tags
              └─ EnrichPanel/VersionPanel → diff 采纳/回滚 → 刷新阅读视图
新建 → create_note → 编辑视图（空笔记）→ 保存 → 列表出现 + 阅读视图
```

**状态一致性规则**：
- 版本快照只在显式保存/AI 采纳时建立；自动保存只刷新 updated_at
- AI 操作读取最新已保存版本，采纳后强制刷新视图
- 编辑中切走（切页/换笔记）→ 先自动保存再切换，防丢

## 六、技术选型（功能层决策）

| 项 | 选择 | 理由 |
|----|------|------|
| 渲染 | react-markdown + remark-gfm + rehype-katex + 代码高亮插件 | 生态成熟、离线纯本地（KaTeX 已本地化先例）、与 Markdown 存储零摩擦 |
| 编辑 MVP | textarea + 自研轻量工具栏（约 100 行内） | 零依赖、符合克制哲学；表格/LaTeX 用「插入语法片段」方式（Obsidian 用户实证偏好源码编辑表格） |
| 编辑升级位 | @uiw/react-md-editor（若体验不达标再引入） | 2026 市场轻量首选（~180KB、MIT、双栏） |
| 任务勾选 | 渲染层拦截 click → 行级正则改写 content | 不引入编辑器即可实现 |
| 版本 | 复用 versioned_save（零新增） | v0.8.0 已交付 |
| 时间戳回链 | Markdown 内嵌 `[[ts:ms]]` 标记 + 渲染解析 + 会话页定位命令 | 复用 ArtifactView refs 模式（产物视图已同构） |
