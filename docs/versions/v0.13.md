## 关键决策与纪律

- **体系只引用、不收纳**（引用不复制，与笔记引用原料同一条纪律）：体系无内容入口——碎片/笔记/卡只能先落组，再被体系引用（`knowledge_links`）。
- **双面体单向升格**：闪卡（组内，记忆面）→ 概念（体系，思辨面）单向；概念→卡不反向。杜绝"概念卡与闪卡重复记账"。
- **一表两面**：`knowledge_decisions` 用 kind 区分 decision/application——决策=思辨面，应用=学习面（动手闭环 N12 最小环），不双表双记。
- **只记"我的决策"**：产物层 `ArtifactKind::Decision`（内容里的决策）禁止自动升格（假证据）；`used_refs` 引用非空才计入指标（防记录膨胀）。
- **审计＝体系级结算**：与 `settlement_due` 同范式；审计产出**建议**、用户确认后生效——无 streak、无惩罚继承（弹性承诺纪律延续）。
- **门控**：REQ-146 真机验收总清（组级学习循环通过）为前提——引擎未验收不建上层（假燃料放大器死法）。
- **开关**：体系默认开（叙事层主枝）；交叉点派生提示默认关；AI 增强（卡→概念回填）默认关。
- **不做图可视化**：体系用树＋列表渲染；REQ-029（知识图谱可视化）维持 P3（Heptabase 已占"图谱"心智，且 P13 出局）。
- **无新北极星**：北极星＝组学习循环完成＋第二组启动率不变；新增观察指标：第一体系创建率/审计执行率/决策引用率/概念升格率。
- **AI 测量，人类见证**：ai 只做补缝与提示（三问回填建议、审计建议），**不做**自动写决策/自动建体系（假燃料）。
- **示例 ≠ 预填（v0.13.7 裁决）**：预填=把内容写进用户输入框（假燃料，禁止）；示例=用户可见的完整参照物（真燃料，允许）。浏览示例是被动的；复制示例是主动的（一键获得骨架，改不改由用户决定）——复制后体系处于"待改造"状态，不是"已完成"状态。

## 市场依据摘要（详见竞品调研）

- 五层竞品地图中"提取→记忆→应用→决策"完整闭环无人做；**整合型**「决策日志/审计＋概念引用」为**零竞品带**（孤立决策日志 App 存在，见[知识体系类软件调研](../Foresight/competitive-analysis-knowledge-system-software.md)）。
- 最像样对手：Ai好记（整理端，无 SRS/无组循环/云端）；NotebookLM（免费 AI 问答冲击，无 SRS/无本地/无应用闭环）；思源笔记（本地优先＋闪卡，无视频提取/无组循环）。
- 定价锚点：国内"免费核心＋年付会员 ¥100–300"；转写按量（本地优先的价值论据）；obsidian "免费核心＋增值"，Anki 免费开源——v0.13 只留定价桩不实现商业化。
- 应战定理：**不与之比"AI 问答多聪明"，比"被 AI 问"（成为隐喻）＋人类判断领地（体系层）**。

# v0.13.5 规划：书籍笔记组与知识树附加（方案 C，2026-08-23 用户决策立项）

> 状态：**已立项（规划 2026-08-23）**
> 来源：[个人电子图书馆调研](../Foresight/competitive-analysis-personal-library.md)（"管书"与"助学"断裂带）＋用户脑暴裁决：知识树附加书籍／书籍笔记组／体会模板"应用"字段／阅读状态生命周期／交叉点复用／生成效应升卡
> 定位：书籍 = "证据＋体会"——**不存书内容**（版权/存储负担/内容供给红线零触碰），只存用户体会（自己产出＝生成效应，记忆深 2-5 倍）；与 Readwise 的隐喻分界：它存高亮（书的内容片段），熵减存"**书对我的改变**"——"书→判断"贯通正是竞品空白带

## 一、范围（方案 C 组合：实体在组、展示在树）

### 1. 数据层
```sql
-- note_groups.kind 扩展 'book'（现有 kind 无 CHECK，command 层白名单+1 即可）
CREATE TABLE IF NOT EXISTS books (            -- 元数据壳，不存内容
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  group_id INTEGER NOT NULL UNIQUE REFERENCES note_groups(id) ON DELETE CASCADE,
  title TEXT NOT NULL,
  author TEXT, isbn TEXT,
  status TEXT NOT NULL DEFAULT 'reading',     -- toread/reading/finished/abandoned
  rating INTEGER,                             -- 1-5，可选
  lesson TEXT,                                -- 一句话"这本书对我的意义"
  created_at INTEGER NOT NULL, updated_at INTEGER NOT NULL
);
```

### 2. 命令（commands_books.rs）
- `create_book_group(title, author?, isbn?, status?)`——事务：建 `kind=book` 组（组名＝书名）＋ books 行
- `update_book_group(group_id, title?/author?/isbn?/status?/rating?/lesson?)`；`list_book_groups(status?)`
- 删除＝走既有组归档路径（不删数据）；体会＝组内**手动笔记**（复用既有笔记创建/编辑），零新命令

### 3. 体会模板与接线（复用优先）
- 前端"写体会"模板：`这本书改变了我哪个判断？/ 我打算怎么用？`（应用字段，可空）＋常规体会正文
- **应用字段 → "记一次使用"**：一键复用 v0.13.3 `knowledge_decisions(kind=application)`（content=应用字段，挂概念/问题）——"书→判断"贯通
- **升卡/复习**：复用 `generate_group_cards`（组→卡，v0.11.2 已就绪）＋复习面/周契约对书组天然生效——零新代码
- 元数据拉取（书名/ISBN→作者/封面）＝可选增强，默认关（纯元数据，无版权问题，v0.13.5 只留桩不做）

### 4. 知识树附加书籍（方案 C 展示层，树侧零 schema）
- 节点/概念详情面板新增"**附加书籍**"区：`list_knowledge_links(target_type=note_group)` ＋ 书籍元数据 JOIN 渲染书卡（书名/作者/状态徽标/体会计数）
- 添加＝复用 `link_knowledge_target`（选已有书组或现场新建书组）；交叉点：一本书挂多个问题→v0.13.4 交叉点提示**自动适用**（零新代码）

### 5. 阅读状态生命周期与审计联动
- 状态机：toread → reading → finished / abandoned（command 白名单校验）
- `book_stale` 纯函数（复用 `concept_stale` 范式）：finished 书组 90 天无访问 → 审计提示"**这本书还在影响你吗？**"（可写新体会、归档或标记"已不再影响"）；随 v0.13.4 审计清单展示（书版沼泽化防御）

## 二、边界（不做清单）

书籍内容导入/格式转换/阅读器 · 全文检索（没有内容可检）· 书评社交 · 周阅读目标（≈学习计划 REQ-030，另议）· 书库管理（Calibre 已占位）· AI 摘要书评（获取隐喻；AI 只做建议）· 移动端

- 接线：应用字段→application 记录（v0.13.3 复用）；书组→`generate_group_cards` 幂等；`link_knowledge_target` 挂书组校验
