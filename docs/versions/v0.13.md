## 一句话

结构在问题里的，成为体系——组回答"我在学什么"，体系回答"我为什么学、学了怎么用"；体系只引用、不收纳，组仍是唯一容器。

## 关键决策与纪律

- **体系只引用、不收纳**（引用不复制，与笔记引用原料同一条纪律）：体系无内容入口——碎片/笔记/卡只能先落组，再被体系引用（`knowledge_links`）。
- **双面体单向升格**：闪卡（组内，记忆面）→ 概念（体系，思辨面）单向；概念→卡不反向。杜绝"概念卡与闪卡重复记账"。
- **一表两面**：`knowledge_decisions` 用 kind 区分 decision/application——决策=思辨面，应用=学习面（动手闭环 N12 最小环），不双表双记。
- **只记"我的决策"**：产物层 `ArtifactKind::Decision`（内容里的决策）禁止自动升格（假证据）；`used_refs` 引用非空才计入指标（防记录膨胀）。
- **审计＝体系级结算**：与 `settlement_due` 同范式；审计产出**建议**、用户确认后生效——无 streak、无惩罚继承（弹性承诺纪律延续）。
- **门控**：REQ-146 真机验收总清（组级学习循环通过）为前提——引擎未验收不建上层（假燃料放大器死法）。
- **开关**：体系默认开（叙事层主枝）；交叉点派生提示默认关；AI 增强（卡→概念回填）默认关。
- **不做图可视化**：体系用树＋列表渲染；REQ-029（知识图谱可视化）维持 P3（Heptabase 已占"图谱"心智，且 P13 出局）。
- **无新北极星**：北极星＝组学习循环完成＋第二组启动率不变；新增观察指标：第一体系创建率/审计执行率/决策引用率/概念升格率。
- **AI 测量，人类见证**：ai 只做补缝与提示（三问回填建议、审计建议），**不做**自动写决策/自动建体系（假燃料）。

## 数据模型增量

（完整 SQL 见整合分析 §四.2；db_migrations.rs 惯例：建表幂等＋ensure_column；零破坏原则）

```
knowledge_systems(id, parent_system_id→self, name, kind global/domain, core_question, status, created_at, updated_at)
knowledge_nodes(id, system_id, parent_id, type question/scenario/domain_entry, text, order_idx, status, created_at)
knowledge_concepts(id, system_id, name UNIQUE(全局唯一→交叉点判定), essence, boundary, relation,
                   status core/watching/archived, last_applied_at, created_at, updated_at)
knowledge_models(id, system_id, name, disciplines JSON(≥1 学科), claim, valid_when, invalid_when,
                 cross_checks JSON(交叉验证记录), status, created_at, updated_at)
knowledge_decisions(id, kind decision/application, system_id?, question_id?, used_refs JSON(引用必填),
                    content, expectation, actual, reflection, decided_at, created_at)
knowledge_links(id, system_id, node_id?, concept_id?, model_id?, target_type note_group/note/flashcard/fragment,
                target_id, created_at)          -- 引用层；组仍是唯一容器
knowledge_audits(id, system_id, items_json(附录D 六项), stats_json(失效数等), created_at)
-- 既有结构不动：flashcards.kind 补值 'model'（REQ-199 预埋）；metrics_events.kind 新增 4 值
```

## 市场依据摘要（详见竞品调研）

- 五层竞品地图中"提取→记忆→应用→决策"完整闭环无人做；**整合型**「决策日志/审计＋概念引用」为**零竞品带**（孤立决策日志 App 存在，见[知识体系类软件调研](../Foresight/competitive-analysis-knowledge-system-software.md)）。
- 最像样对手：Ai好记（整理端，无 SRS/无组循环/云端）；NotebookLM（免费 AI 问答冲击，无 SRS/无本地/无应用闭环）；思源笔记（本地优先＋闪卡，无视频提取/无组循环）。
- 定价锚点：国内"免费核心＋年付会员 ¥100–300"；转写按量（本地优先的价值论据）；obsidian "免费核心＋增值"，Anki 免费开源——v0.13 只留定价桩不实现商业化。
- 应战定理：**不与之比"AI 问答多聪明"，比"被 AI 问"（成为隐喻）＋人类判断领地（体系层）**。

## 测试与验证

- 纯函数全 TDD（AAA＋golden）：`audit_due`（阈值/周期边界）、`concept_stale`（90/180 天边界）、`promote_rules`（卡→概念升格规则：同名合并/跨体系提示/幂等）、四行法字段校验、`used_refs` 引用校验。
- 数据层 `:memory:` 库；command 层仅参数校验与编排（AGENTS.md §6）；模型零依赖。
- 前端 vitest：三问一用卡片渲染（延迟揭示）、审计清单交互、决策日志表单（引用选择器）。
- 真机走查（REQ-146 批）：创建体系→挂组→概念升格→记一次使用→季度审计→交叉点提示 全链路。

## 边界（不做清单）

体系图谱可视化（力导向图）· 跨体系自由引用（图谱化入口）· 全局概念库收纳内容 · AI 自动生成决策/概念 · 决策质量评级 · 领域体系嵌套 · 承接 REQ-030（学习计划系统）· 承接 REQ-029（仅数据结构可视化补充，P3 维持）· 移动端 · 内容供给 · 社交/见证结构 · 商业化（会员/云同步）落地
