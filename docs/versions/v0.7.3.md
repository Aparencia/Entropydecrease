## 三、关键设计决策

1. **屏 = 派生视图而非新表**：屏 first/last_seen/成员块 = `GROUP BY screen_id` 聚合；旧数据（screen_id NULL）走 `cluster_blocks_into_screens` 聚类兜底——零冗余、可逆（ADR-006 派生视图传统，ADR-015 决策 2）。
2. **在线/离线共用纯函数**：`screen_merge.rs`（normalize/screen_similarity/cluster_blocks_into_screens/line_merge/classify_roles）——在线 ScreenTracker 与离线聚类同一套逻辑（单管线双出口，延续 REQ-081 原则）。
3. **屏边界**：版面指纹变化（layout_cache 现成）= 新屏；同屏内容相似 → 续屏（更新 last_seen 不新增行）；翻回旧页间隔>2 分钟 = 新屏。
   - **实现校准（2026-08-20）**：`CLUSTER_GAP_MS` 初版 3s 与 OCR 帧间隔（强制兜底 15s + 事件驱动，会话29 实测 5-58s）冲突导致同屏续帧误分屏——按实测校准为 **120s**；`TITLE_HEIGHT_RATIO` 初版 4% 把正文/标签（30px/626px 屏高 ≈4.8%）误判为标题——校准为 **6%**（只命中 PPT 大标题）。
4. **行合并保守阈值**：bbox y 中心差 ≤ 行高×0.6 且 x 间隔 ≤ 字高×0.5 → 同行拼接；跨帧同位置块先经 `dedupe_blocks` 去重（防多帧重复识别被 line_merge 误拼）；屏卡可展开块级明细复查（原料不动）。
5. **采集治理**：前台≠目标窗口期间画面要点不落库（复用 REQ-084 foreground_foreign）；平台 UI 黑名单扩充（LiveUi 类别：正在看/人在看/人看过/发送/下载/预约/回放/分享/直播）+ 持久元素自学习（第二波）。
6. **结构识别**：只补消费端接线（`refine_screen_structures` 纯函数匹配 artifact_blocks 精修产物），识别内核（SLANet/FormulaNet/refine 链路）零改动；**停止后自动精修**（stop_live_session 检测 table/formula 区域块 → 后台 run_refine，模型未就绪内部降级跳过）；失败降级徽标保留。
7. **降级四级链**：新数据全能力屏卡 → 旧数据聚类屏（无行合并/角色/结构）→ refine 失败徽标 → 现行文本列表兜底（零回归）。
8. **导入链路口径**（REQ-156 实现注记）：bbox 反算回帧坐标系落库（裁剪图坐标 + 等比缩放 + 顶部偏移，TD-046 同思路）；screen_id 不分配（None）——视图层聚类兜底与在线 ScreenTracker 共用同一套纯函数，结果等价。
