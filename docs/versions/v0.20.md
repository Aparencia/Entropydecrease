# v0.20：ASR 质量增强系列（自验证路线 · P0~P2）

> 状态：**系列文档（2026-09-03 用户裁决 C 立项，待实施）**
> 依据：repowiki（.qoder/repowiki）盘点 + 代码互证 + 最新技术对标（[asr-optimization-plan 决策稿](../Foresight/asr-optimization-plan.md)）；用户裁决：① 人工验证不可行 → **验证一律代码自验证** ② 立项范围 C（P0~P2）
> 关联：[ADR-030](../adr/ADR-030-asr-quality-batch.md)（已接受）· ADR-003/012 · REQ-263~270 · v0.19 检索层（同受转写质量影响）

## 一句话

给 ASR 链路装上"能自测的尺子 + 有数据的默认值 + 导入同级的离线质量档 + 自动发现术语错闭环"：新增 `bin/asr_eval` 自验证 harness（字幕信道做内置参考 → CER/混淆画像/A-B 矩阵/CI 回归门），随后用同一把尺子完成参数族定案（预处理默认/VAD/端点/融合/去重）、DTW 漂移校正接线、热词加固与注入扩展、实时会话全量离线精修（采纳/回退）、ASR 同音混淆画像→纠错/热词闭环，以及可选的 LLM 文本校对（建议制·默认关·语音不出本机）。

## 自验证路线（本系列主纲，ADR-030 决策 1/2）

- **参考信道**：外挂/内嵌字幕轨（~100%）> 字幕 OCR 多帧投票（~99%）> 会话内字幕段；无参考素材不进 CER（只做稳定性/画像/回归）。
- **harness** `bin/asr_eval`：批量样本 → 转写（流式/离线、参数矩阵、预处理开关）→ dtw_align 对齐 → cer.rs CER → 同音错对画像 → A/B 对比表 → 回归退出码（CI）。
- fixtures 固化首批有参考样本；**结论只作相对对比与回归**，不宣称绝对指标。

## 验收门槛（全部代码自验证）

- harness 回归退出码挂 CI；fixtures goldens 全绿（cargo test）；每批产出 A/B 结论页；
- 精修采纳流单测（原料不可变断言）；画像闭环单测（共现才替换/确认制）；content_gate 默认关路径测试；
- 全量回归：cargo test / clippy / vitest / tsc。

## 边界（红线延续）

原料层（session_segments 原文）永不可变；模型文件不入库/下载走既有镜像与本地归档；**语音不出本机**（文本级 AI 走 content_gate 双闸门默认关 + 审计）；跨运行时换芯（FunASR/FireRed/Qwen3 系）与语音上云需另行 ADR + 用户授权（ADR-030 决策 8）。

# 并行支线规划（2026-09-05 讨论定稿 · 未立项 · REQ 待登记）：后处理功能区——待办裁决 + SOP 执行

> 状态：**规划定稿（2026-09-05 用户裁决推进；未立项，REQ 编号待登记；排期在 v0.20 ASR 批之后候选或独立排期）**
> 依据：笔记全流程三阶段讨论（预处理→核心处理→后处理）· 后处理子域 A 首批；GitHub 参照（Obsidian Tasks / Joplin / Process Street / Atuin / runbook 系）与四路深研（任务方法论 / 清单科学 / SOP 软件全景 / 集成形态）；来源 URL 见文末
> 关联：核心处理（8 类标注/拆包）**未规划**——本支线输入契约先行；「复习到期」节奏本体属闪卡引擎轮次规划，本支线只留接口

## 一句话

给"学习产生的行动与程序"装上执行闭环：**Act（待办）**经裁决漏斗内建/迁出并统一沉淀完成史；**H（程序）**变成可执行、可复盘、可演进、**用户可自定义**的 SOP。

## 背景（三段管线语境）

- 预处理 = 采集/净化（课堂捕获 + [web 采集第三条进料管道](../Foresight/web-capture-ingestion-path.md) 规划）
- **后处理（本支线）**消费"带类型标注的原子块"——该契约由核心处理提供；v1 先用结构信号（`- [ ]` 任务行 / StepCard 步骤卡 / `- ☑️ 待办` 产物行），不阻塞
- 完成的产品语义承接既有哲学：组是唯一容器、产物进学习闭环即止；不做通用任务管理/工作区

## 行动底座与两区要点

**底座**：md 任务行为唯一真相（v1 不引入新符号）→ `task_index` 增量索引（保存钩子维护，聚合走 SQLite 不走全库扫描）→ 回写原子层（行解析→状态迁移纯函数→写回源行，全入口收敛）→ `completion_history`。

**① 待办功能区（Act）**：产物遗留行归一化（`- ☑️ 待办` → 可裁决条目，可「提炼为任务行」）→ 聚合视图（计划日/搁置）→ 周回顾裁决队列（含"转闪卡/放弃留因"——**不留死尸的机制是裁决不是自动清理**）→ 迁出适配器（保底三件套：复制 todo.txt 行/导出 `.todo.txt`/邮件说明；scheme 通道 Todoist `todoist://quickadd` + 滴答 x-callback 先探测注册；REST+token 二期进 keyring 复用 ADR-016 DPAPI；Google Tasks/MS To Do/Vikunja 自填 endpoint 后置）。

**② SOP 执行功能区（H）**：三源创建模板（课堂素材半自动提炼=复用截图/OCR/转写时间线，Scribe 映射但不做录屏识别）→ 双模式执行 + run 快照档案（`runs`/`run_steps`：轨迹/失败点/耗时，正文保持可复跑）→ 版本化演进 → 个人操作档案。

**③ 学习联动接口（预留，本体归闪卡/复习轮次）**：练习类 Act 节奏化（次数/时长/难度/熟练度=闪卡之外第二条复利曲线）；「该练了」按曲线浮出（不建待办，trane 范式）；失败点→练习卡——本支线只定义数据接口与完成史沉淀。
