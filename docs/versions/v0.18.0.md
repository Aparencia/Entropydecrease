## 范围（M1 做 / 不做）

**做**：goals/goal_milestones/goal_groups 三表（迁移幂等）+ metrics_events kind 扩展（goal_* + self_test_* 占位契约）；goal_interview（四步问题集 + 配方推导 + suggest_milestones + 宣言组装）；goal_progress（跨表聚合 → 档位）；goal_rules（四态状态机 + 毕业判据/守卫）；CRUD/绑定/progress 命令；GoalPage（单行卡列表）+ InterviewDialog（双展开）+ GoalDetail + 弱项块（FSRS 低稳定性卡占比）；组删除 CASCADE 影响面测试；埋点。

**不做**：毕业仪式/回顾流（M2）· AI 教练/预算分配器/影子缓存（M3）· 生成式复习（REQ-021 单独立项）· 概念低激活弱项（M3）· 采集端任何改动 · agent 框架/记忆模块 · 云同步。

## 设计要点摘要（完整见设计规格）

- **数据模型**：goals（name/domain_tag/status 四态/horizon_end 可空/success_criteria_json/intent_json/created_at 即开始时间）+ goal_milestones（criteria_type=manual|group_settled|self_test，ref_group_id 可空）+ goal_groups（N:M，UNIQUE(goal_id,group_id)）
- **访谈**：第 1/3 问必答、2/4 问折叠可选；答案落 intent_json（scenario/level/driver/criteria_statement/non_scope/weekly_commitment/obstacles）；第 5 步宣言 + 里程碑草案（基础→应用→项目，可删改）；快速模式＝同组件双展开（名称+期限）
- **判据配方**：能上手→里程碑+主组结算；能独立实例→+项目组结算+应用记录≥1；能教别人/证书→+自测≥80%（占位）；说不清→默认档
- **进度信号**：里程碑完成率 + settlements 历史计数（归档组仍计入）+ 周契约完成率（复用 week_contract_status）+ review_logs 近 90 天活跃度 + FSRS 低稳定性卡占比（弱项）
- **一致性契约**：信号现算 / 快照归档；目标层零双写；上卷路径为唯一交叉入口
