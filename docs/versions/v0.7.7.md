## 二、技术方案（要点，详见头脑风暴文档 §四）

### M1 数据层（REQ-183）

- `session_structure_images` 新表（ensure_table 幂等）；`struct/` 命名空间与 `crop/`（精修中间产物）语义分离；缩略图同步生成
- 独立预算 STRUCT_BUDGET_AUTO=80/会话；手动不设限；same_image 双指纹去重（REQ-067 复用）

### M2 自动捕获（REQ-182）

- `structure_capture.rs`：纯函数核心（pick_sharpest / diagram_likeness / 候选过滤）+ 命令胶水，单文件 ≤300 行
- 管线：屏 → 时间窗内归档帧采样（≤8 帧均匀）→ 选优 → 版面分析 → 区域过滤（结构三类直收、Image 过图结构判定、text/unknown 跳过）→ 白边裁剪 → 去重 → 预算 → 入库
- 触发：会话停止后自动 + 图库「重新捕获」按钮

### M3 手动截取 + 图库 + 修复（REQ-184/185/186/187）

- 前端：BoxSelectOverlay（拖框 + 确认浮层）、StructureImageSection、ImagePreviewOverlay（两区段共用）、SessionListPanel 全选框三态
- 后端命令：capture_structure_manual / list_session_structure_images / delete_structure_image / capture_session_structures

### M4 测试与验收

- 纯函数单测：diagram_likeness 四类合成网格 / pick_sharpest / 批量候选去重预算 / 手动钳制拒绝 / DB 幂等迁移
- 前端：框选归一化纯函数 + 真机手动清单（Vitest 基建维持现状裁决）
- 真机：会话重跑自动捕获 + 手动闭环 + 两修复项 + 旧会话回归

## 三、验收标准

- [ ] 自动捕获：真实会话停止后结构三类 + 流程图入图库；照片/装饰不误收；重跑幂等
- [ ] 手动：屏卡框选 → 预览确认 → 入库；无图屏禁用+提示；越界/过小拒绝
- [ ] 图库：徽标/时间/来源/删除/重新捕获生效；空态与降级提示正确
- [ ] 修复①：全选框三态正确（筛选视图口径），批量操作不受影响
- [ ] 修复②：参考图/结构图点击均可大图预览，删除/ESC 关闭正确
- [ ] 回归：旧会话零回归；`cargo test` + `cargo clippy` 全绿；前端构建通过
