## 2. 轮 1：用户侧深度定制（首轮，方向被用户转向，保留待议）

> **轮次说明**：首轮从"用户可定制"维度发散（7 层 18 项）。用户反馈转向平台深化（视频类型更丰富/机制更完善/平台深度适配），本轮**未裁决、保留待议**——定制面与平台深化不冲突，后续可并行评估。

## 3. 轮 2：平台深化三轴（视频类型 × 机制 × 平台适配）

> 用户指定的深化方向：**视频类型更丰富 + 机制更完善 + 平台深度适配**。

### 3.1 类型扩展：五档案之外的十类

| # | 新类型 | 与五档案的本质差异 | 现有覆盖 | 缺口机制 |
|---|--------|-------------------|---------|---------|
| T1 | **直播回放**（B站/YouTube 直播学编程/设计） | 时长 2h+；弹幕互动；画面杂（聊天窗/礼物/连麦）；口语密度低 | 弹幕过滤已有（REQ-037）；长会话内存已排（REQ-072） | 弹幕时段=群体关注信号；连麦多画面；2h+ 会话资源预算 |
| T2 | **白板/板书课**（数学/物理网课大量） | 知识在"书写过程"里，不在静态帧里；擦除=内容演进 | 版面+公式 OCR 已做（静态）；手写公式走 AI 补缝（V1.0） | **书写增量重建**：擦除检测+书写追加=推导过程重建（与 M4 同一机制） |
| T3 | **编程实战/录屏**（live coding） | 光标=注意力焦点；代码 diff=步骤；终端滚动=输出 | code 区版面识别已有；P5 代码结构化未排 | **光标/点击轨迹**（M2）；代码 diff 步骤卡（M5）；缩进恢复 |
| T4 | **跟练型**（健身/舞蹈/乐器示范） | 口令+节奏驱动；镜像画面；示范→练习交替 | 练习段识别已实施（REQ-070，长静音+画面静止） | 口令计数→步骤卡（M7）；**镜面反转检测**（M8 关联）；示范/跟练交替 |
| T5 | **语言学习/生肉** | 双语对照；跟读；无字幕（生肉） | 中英混说已排 P3（REQ-028） | 双语字幕时间轴对齐（M9）；跟读段识别；字幕翻译通道（云端可选） |
| T6 | 纪录片/科普旁白 | 旁白+密集字幕+画面切换快；无"教学结构" | 口播档案接近；字幕优先已覆盖 | 参数变体，低优先 |
| T7 | **圆桌/多画面**（直播连麦、多人连线） | 多画面布局；抢话/打断；观众提问 | 说话人变化检测已有（A3 弱化版）；访谈档案接近 | 多画面主画面选择；**抢话/打断检测**（M6）；提问↔回答绑定 |
| T8 | **纯音频**（播客/有声书） | 无画面 → 整条 OCR/画面管线可短路 | 文件导入已有（ffmpeg 音轨）；无图管线未测 | ASR-only 快速路径；封面/章节元数据直读 |
| T9 | 游戏/软件演示 | HUD/快捷键气泡；UI 文字变化快 | 实操档案接近；字幕 UI 垃圾过滤已实施（REQ-083） | 参数变体，低优先 |
| T10 | **无语音纯字幕**（剪辑向/ASMR/静音课） | 无 ASR 信号 → OCR-only 管线 | 字幕优先策略已有（L1→L2→ASR 三级降级） | 显式"无音频"档案：跳过 ASR 引擎初始化，省内存 |

### 3.2 机制完善（机制清单 A–G 之外的空白）

| # | 机制 | 原理 | 为什么是空白 | 差异化 |
|---|------|------|-------------|--------|
| M1 | **播放器行为信号**（本轮最高分） | 捕获窗口是播放器时，检测**倍速/暂停/反复拖动回看** → 用户自己放慢/重看的地方=难点 | 重点候选（REQ-045）只看内容信号（重复/音量/OCR 停留），**不看用户行为**；云端竞品拿到的是文件不是播放器，永远做不了 | 极高——本地捕获天然独有 |
| M2 | **光标/点击注意力锚点** | 光标停留时长+点击位置 → "当前焦点区域"，驱动 OCR 区域优先级与截图裁剪中心 | 实操/编程档案现在对所有区域平权 OCR | 高——"老师在看哪"变成信号 |
| M3 | **弹幕时段信号** | 弹幕密度骤增时刻=群体关注点（名场面/关键操作），反哺重点候选与章节边界 | 弹幕只做过滤（REQ-037），没做利用 | 中高——B站场景独有 |
| M4 | **书写增量重建**（白板） | 帧间 diff 检测"新增笔画/擦除" → 板书按书写顺序组织，推导过程可回放 | 静态版面 OCR 丢失书写时序；公式 OCR 只给结果不给过程 | 高——数学推导课核心价值在过程 |
| M5 | **代码 diff 步骤化** | 相邻帧 code 区文本 diff → "老师改了什么"=一步；多步聚合=步骤卡 | 缺口评估 P5 只排了缩进恢复，diff 未提 | 中高 |
| M6 | **抢话/打断检测** | 说话人切换间隙<阈值+语音重叠 → 打断事件（圆桌档案问答结构） | 说话人变化检测只标切换不标重叠 | 中 |
| M7 | **口令/节奏识别** | 周期性短语（"一二三/再来一遍"）+节拍 → 跟练步骤切分 | REQ-070 练习段是静音信号，口令是语音信号，互补 | 中——健身/舞蹈档案专属 |
| M8 | **示范/跟练段落交替** | 画面静止+口令 → "示范段"；画面动+无口令 → "跟练段"，产物交替呈现 | 现有机制不区分这两种段落 | 中 |
| M9 | **双语时间轴对齐** | 中英字幕流按时间轴对齐 → 对照笔记（"原句+译文"块） | REQ-028 只管识别不管对齐呈现 | 中——语言学习档案核心 |

## 4. 轮 3：持久化闭环深化五轴（输出侧/闭环侧）

> **结构性说明**：轮 1/2 均为"输入侧"（把课提取得更准）；轮 3 转向"输出侧/闭环侧"（提取物→掌握）。提取是手段，掌握是目的——闪卡顺延后，整个"学没学会"的度量层与验证层几乎空白。

### 4.1 持久化闭环（K）

## 9. 回顾

- **产出**：68 项（新 46 / 延 20 / 规 2），三轮发散
- **最高分**：M1 播放器行为信号（100）——本地捕获架构独占、竞品结构性做不到
- **过程**：首轮（用户侧定制）被用户转向平台深化，方向调整后发散充分；二轮三轴（类型/机制/平台）→ 三轮五轴（闭环/知识层/验证/主动助手/深加工/生态）
- **结构性结论**：输入侧（提取）已深挖至 v0.6.0；输出侧（持久化/验证/知识资产）是更大的空白区——提取是手段，掌握是目的
- **改进建议**：深化方向清单应在 M7 真机验收基线之上裁决，避免在未验证基线上盖楼
