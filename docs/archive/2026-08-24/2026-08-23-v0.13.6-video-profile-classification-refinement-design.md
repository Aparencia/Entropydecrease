## 二、M1 修复批

### 2.1 `add_knowledge_node` 契约错误（P0，用户实测）

- **根因**：Rust `add_knowledge_node(state, system_id, parent_id, node_type, text)`（commands_knowledge_systems.rs:75）Tauri camelCase 契约要求前端传 `nodeType`；前端 3 处传 `type` → "命令缺少必填键 nodeType"。
- **修改**：
  - `app/src/components/KnowledgeSystemWizard.tsx:105,109`：`type:` → `nodeType:`（`satisfies KnowledgeNodeType` 保留）
  - `app/src/components/KnowledgeTreeView.tsx:100`：`type:` → `nodeType:`
  - 测试断言同步：`KnowledgeSystemWizard.test.tsx:109-111`（含 `type: "domain_entry"` 断言）、`KnowledgeTreeView.test.tsx` 如有 invoke 参数断言一并修正
- **验收**：向导创建全局体系 → 领域入口/场景节点全部落库；`cargo test --test app_lib_tests knowledge` 全绿 + vitest 向导/树用例全绿。

### 2.2 笔记编辑完成后即时刷新（用户要求；含标题修改显示问题）

- **症状确认**（用户报告）：视频/图文会话转来的笔记，编辑标题后「完成」——右栏阅读视图仍显示旧标题。
- **根因**：
  1. `NoteEditView.handleDone`（NoteEditView.tsx:220）`if (dirty) void saveDraft(false); onCancel();`——**保存未 await**，退出编辑态后保存仍在途；
  2. `NotesPage.onCancel`（NotesPage.tsx:326）只 `setEditing(false); void load(列表)`——**`selected` 不重取**，右栏 `note={selected}` 恒旧值；
  3. 窗口级 ESC 路径（NotesPage.tsx:134）只 `setEditing(false)`——连列表都不刷新。
- **方案**：
  - `NoteEditView`：`handleDone` 改为 `await saveDraft(false)` 后调用 `onCancel()`（与 Ctrl+E 路径 `.finally` 语义对齐；保存失败仍需退出 + status 展示，不卡死编辑态）。
  - `NotesPage`：新增统一「编辑退出刷新」回调——`get_note(id)` → `setSelected(fresh)` + `void load(...)`（复用 `handleNoteChanged` 语义，见 NotesPage.tsx:207）；三出口（完成按钮 / Ctrl+E / ESC）全部走该回调。
  - 时序：`handleDone` await 了保存 → `get_note` 读到新数据，无竞态；ESC 路径保存由卸载自动保存兜底（dirty 快照，NoteEditView.tsx:227），刷新回调异步 `get_note`——与卸载保存并发时有极小窗口，接受（下一次交互即回正；不引入额外等待）。
  - 切笔记（`handleSelect`）卸载保存路径不变（防串写，NotesPage.tsx:238）。
- **验收**：编辑标题 → 完成 → 右栏标题/正文立即更新 + 列表行更新；ESC 退出后列表刷新；vitest 新用例（invoke 顺序断言：update_note → get_note）。

### 5.3 领域检测链（`detect_video_domain` / `video_profile_domain.rs`）

五源顺序升级（现：平台种子词匹配 > 用户 > 标题 > 开场白 > 术语）：

```
① 平台分区映射表 lookup_zone（命中 → coarse+细目预选，confidence 1.0，source="platform-map"）
② 用户确认（coarse + 细目多选）
③ 标题词（粗种子 + 细目种子 match_fine）
④ ASR 开场白（粗种子；口语弱信号仅 title 未命中时补位，现状不变）
⑤ 术语频率（coarse + 细目命中词）
```

- 平台标签输入：`platform_tags` + `ocr_tags` 合并（现状）；映射表未命中 → 回落 `ocr_tags_to_domain`（现状种子词通道，零回归）。

### 5.4 记忆扩展（`video_profile.rs` ProfileMemory）
