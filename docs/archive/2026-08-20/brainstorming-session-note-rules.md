**触发**: 会话31（B站"项目从立项到交付全流程"讲座，14.5min / 172 段 ASR / 215 块 OCR）经规则转化产出笔记，质量暴露规则链多处优化空间

## 一、问题实证（会话31：172 段转写 / 215 块 OCR / 笔记 215 行）

| 现象 | 数据证据 | 根因 |
|------|---------|------|
| **口头禅/口癖未净化** | 「对不对？」整段保留（段 id=1018，3.7s 独占一段）；「啊/呢/呃/就是/大家知道吗」遍布全文 | `verbal_normalize` 只在实时分析路径（analysis.rs）接线，**笔记路径（filter_note）未接入** |
| **口头禅短段规则层不敢删** | 段 1018「对不对？」、段 1038「如果是。」存活 | `FILLER` 分类已实现但只作 AI 候选（REQ-085 三态判定），纯本地路径无删除能力 |
| **ASR 结巴/错字无纠错** | 「甲甲甲方的项目」「可行行研究」「搭建项目班（子）」「利国利民立公司能」「项那个」 | 无叠字折叠规则；glossary 未接线笔记路径 |
| **段落机械切分语义断裂** | 「如果 是。」孤段；「那么以公司的项那个项目可行性研究」段内混杂两主题 | 切段仅按 120 字/60s 双阈值（concat.rs），无语义边界 |
| **讲述内容无时间锚点** | 全文无任何 [MM:SS] 引用，无法回跳原视频 | assemble_markdown 段落不带 start_ms |
| **视频页 UI 垃圾漏拦** | 「简介/评论7/清晖加油站/展开/178/48/1112/45/标签/若凡娃娃/1.3万0/项目经理PMP-100分钟串讲/qh202522(二维码)/谷歌：项目管理基础/原声译站/回行走」全部进笔记画面要点 | ui_junk 黑名单只有 Watermark/PlayerUi/EditorUi/AppUi/LiveUi 五类，**缺"视频页 UI"类**（点赞/收藏/投币/观看数/标签/作者/推荐卡片/二维码）；「宁漏勿误」保守原则 |
| **单字符碎片块过放** | `X`(0.97)/`？`(0.5)/`o`(0.63)/`不`(0.67)/`三`(0.91) 全部 ≥0.5 通过 | MIN_BLOCK_SCORE=0.5 过低；无单字符无上下文丢弃规则 |
| **OCR 错字无纠错** | 「項灣启动是艺术」「国录」「质灣交接」（目→灣） | OCR 无词汇纠错；glossary/共现校验未接线 |
| **屏时间零跨度** | 画面 1~5 均为 `[00:02–00:02]` 零区间 | 旧数据（无 screen_id）聚类兜底失效或首末见相同 |
| **重复图未去重** | 画面 6/7/8 全部引用同一张 `569515.webp`（09:29/09:46/10:01） | attach_images 按时间戳匹配不按图内容去重；屏聚类未吸收重复帧 |
| **失败会话静默转笔记** | 会话31 `status=failed`（172 段有内容但会话标记失败），笔记照常生成无警示 | convert_to_note 不检查会话状态异常 |
| **无规则版本可追溯** | 笔记无法回答"用哪版规则生成" | notes 表无规则版本/净化统计元数据 |

**核心洞察**: 会话→笔记的规则链已具备"净化的骨架"（note_filter 五步链 + screens 过滤），但存在三类系统性缺口：① **已建规则未接线**（verbal/symbol normalize 只服务实时路径）；② **黑名单/阈值覆盖面停在"课堂场景假设"**（视频网站页面 UI 是新污染源，会话29 直播 UI 是上一波）；③ **产物层无时间锚、无元数据、无回归语料**——笔记"不可回跳、不可追溯、不可回归"。

## 二、头脑风暴全景（五条主线 20 项）

### 主线 A：转写净化（讲述内容可读性）

| # | 思路 | 收益 | 代价/风险 | 裁决 |
|---|------|------|-----------|------|
| A1 | 口语净化接线：verbal_normalize + symbol_normalize 接入 filter_note | 口癖/语气词/符号乱码本地清理，零成本 | 需防过度删改（保守强度档） | ✅ REQ-162 |
| A2 | 口头禅短段规则级删除：≤8 字且全由口头禅词组成 → 规则层直接删（免 AI） | 段 1018「对不对？」类直接消失 | 误删风险低（短句+全口头禅双重条件） | ✅ REQ-163 |
| A3 | ASR 结巴/叠字折叠 + 术语替换（glossary 复用）：「甲甲甲」→「甲」、「项目班」→「项目班子」 | 错字率肉眼可见下降 | 叠字规则需防误伤合法叠词（"慢慢/常常"） | ✅ REQ-164 |
| A4 | 语义切段：问句/转折词/主题词边界切段（替代纯 120 字硬切） | 「如果 是。」孤段消失 | 与"结构组织"边界模糊——**用户裁决暂不实施** | ⏸ 后续批次 |
| A5 | 段落时间戳锚点：每段前缀 [MM:SS] | 笔记可回跳原视频位置 | 轻微视觉噪音（可开关） | ✅ REQ-165 |

## 三、裁决（2026-08-20）

1. **范围**：净化快赢批入 v0.7.5（A1/A2/A3/A5 + B1/B2/B3/B4 + D2/D3 + E1/E2/E3 = REQ-162~173 共 12 项）
2. **明确不实施**：主线 C 全部（章节/摘要/要点/术语）+ D1（时间对齐内联）——属"结构组织"，用户裁决暂不实施（与 v0.8.0 AI 精修 REQ-141 的结构化层级衔接）；A4 语义切段与标题优化 E4 留后续
3. **架构原则延续**：净化必须**可逆**（原料层不动，产物层过滤——REQ-081/082 单一管线双出口传统）；全部纯函数可单测；口语净化用保守强度档（防过度删改）
4. **接线优先于新建**：A1 复用 verbal_normalize/symbol_normalize（已有 100% 代码）、B1 扩充 ui_junk 黑名单（已有机制）、B3 复用 glossary——新代码量集中在 D2/E1/E2/E3

## 四、设计规格

### 4.1 转写净化链（filter_note 前置段，自底向上）

- **原子层**（纯函数，可单测）：
  - `fold_stutter(text)`：叠字折叠（连续 3+ 同字 → 1 个；白名单保护「慢慢/常常/好好」等合法叠词）
  - `is_filler_only(text)`：≤8 字且全部字符 ∈ FILLER_WORDS → true（REQ-163，替代"仅候选不删"）
  - `anchor_paragraphs(paragraphs, segments)`：段落 → `[MM:SS] 段落`（取段首 start_ms，REQ-165）
- **业务层**（note_filter.rs 改造）：
  - filter_note 段循环内新增：口语净化（verbal_normalize 保守档 + symbol_normalize）→ 结巴折叠 → Filler-only 删除
  - 净化顺序在 UI 垃圾/碎片/低置信之后、相邻重复合并之前（净化后文本才做精确去重）
  - 净化记录进 FilteredItem/统计（可逆可复查）
- **系统层**：`convert_to_note` 在 AI 三态判定前消费净化后 kept

### 4.2 OCR 净化链（screens/filter_usable_blocks 扩展）

- **原子层**：
  - `is_video_page_junk(text)`：命中 VideoPageUi 黑名单（简介/评论/点赞/收藏/投币/观看数/标签/作者名/推荐/二维码/展开 + 数字量词正则 `^[\d.]+万?$` 短串）
  - `is_single_char_noise(text, has_bbox)`：单字符且非公式/表格上下文 → true
  - `is_edge_region(bbox, frame_size)`：屏幕边缘条带（顶 8%/底 8%/左右 4%）→ true（新数据 bbox 可用时）
- **业务层**：`filter_usable_blocks` 追加上述三规则；MIN_BLOCK_SCORE 0.5→0.7（配回归验证）
- **配置**：VideoPageUi 词表入 ui_junk.json 可校准（沿用内置默认 + JSON 合并机制）

### 4.3 产物与元数据

- **E1**：`notes` 表加 `rule_version TEXT` + `purify_stats TEXT`（JSON：各过滤原因计数 + 净化计数）；`convert_to_note` 落库时写入；旧笔记 NULL 诚实降级（先例 ADR-014 SET NULL 原则）
- **D2**：屏构建后按图指纹去重（frame_cluster 复用：相同图只保留首个屏引用）；零跨度屏（first=last）并入相邻屏或标注
- **D3**：convert_to_note 读 session.status != 正常完成 → 笔记追加 `> ⚠️ 会话异常（status），内容可能不完整` 警示行（可手动删除）

### 4.4 黄金语料回归（E2）

- `note_filter_tests.rs` 扩展：会话31 样本段（含口头禅/结巴/垃圾块）→ 期望净化输出断言；会话29 样本（直播 UI 污染）→ 期望过滤断言
- 规则变更必须全量跑回归（cargo test），新增规则先写失败测试（TDD，AGENTS.md §3.5）

- **Rust 单测**：fold_stutter 白名单矩阵 · is_filler_only 边界 · 净化顺序回归（净化→去重）· VideoPageUi 词表命中/正文不误杀 · 单字符噪声/数字量词 · 边缘条带 bbox · 屏图去重 · 零跨度处理 · 警示行生成 · notes 迁移加列旧库兼容 · 黄金语料回归
