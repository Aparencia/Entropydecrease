## 一、一句话

目标层是学习循环的**意图层**：把已交付资产（组/闪卡/FSRS/周契约/组结算/概念库）串成「学会 Python」这样**可追踪、可毕业、可复盘**的学习目标；目标设定采用**访谈式向导**（逼问真需求，而非一句「我要学 xx」）；AI 只做教练（出内容、被问），不做规划——记忆由本地库承载，AI 永远是「临时读客」。

## 二、背景与定位

- 现状：提取管线（v0.1~0.9）、学习循环（v0.11：FSRS/周契约/组结算/指标）、知识体系层（v0.13：概念双面体/决策应用/审计）、AI 平台（v0.11.6）与 AI 对话（v0.16/0.17）均已交付——但**缺「意图轴」**：用户「我要学 Python」没有对象化，周契约/组结算/概念升格各自为政。
- 市场端：NotebookLM（免费 AI 问答）是冲击源但无 SRS/无本地/无应用闭环（v0.13 竞品分析）；应战定理＝**不与之比「AI 问答多聪明」，比「被 AI 问」（成为隐喻）＋人类判断领地（体系层）**。目标层让「被 AI 问」有了意图上下文。
- 智能体结论（本设计前置裁决）：**不接入 agent 记忆模块/自由规划/第三方框架**。理由：(a) 本地 SQLite 即是比任何 agent 记忆更可靠的长记忆（结构化/版本化/可审计/不出本机）；(b) agent 循环不可确定性 vs 项目可测试性与防御性降级两条铁律；(c) 桌面单用户无多代理编排需求。AI 在此产品中的唯一合理位置＝**教练**（M3：目标摘要注入/复盘/追问），且默认关。

| # | 优化 | 裁决 |
|---|---|---|
| 1 | 删 `summary_cache_json` 列 → L4.5 摘要**现算**（无状态读取） | 采纳：摘要 <1K token，缓存层是过度设计 |
| 2 | 删 `draft` 状态 → **四态状态机**（active/paused/graduated/abandoned） | 采纳：访谈中断不落库，draft 为死代码 |

| 5 | **GoalCard 单行折叠**（名称+状态徽标+一句话进度）；周契约/组徽标/回顾流/操作收进详情页 | 采纳：列表是导航不是仪表盘 |
| 6 | **M1 弱项信号 = FSRS 低稳定性卡占比**（flashcards.state_json 字段查询）；概念低激活 → M3 | 采纳：零 JOIN，M1 即有真实「最弱一块」 |

| 8 | **预算档位化**（轻量 4K/标准 10K/深度 30K，默认标准，设置页可选） | 采纳：交互复用精修四档阶梯范式 |

| 10 | 切分微调：**组删除影响面（CASCADE 行为）测试归 M1**，M2 只做提示 UI；`budget_allocator` **仅 M3** | 采纳：M1/M2 零 AI 代码铁律 |

## 四、总架构（自底向上，遵守七维度）

```
原子层（纯函数，TDD golden）
  goal_schema.rs         Goal/GoalMilestone/GoalStatus/SuccessCriteria（serde JSON 契约）
  goal_interview.rs      访谈问题集/跳转规则/答案→配方推导/里程碑建议/宣言组装
  goal_progress.rs       跨表信号聚合 → GoalProgressReport（档位判定）
  goal_rules.rs          状态机（active/paused/graduated/abandoned）+ 守卫 + 毕业判据
  goal_retro.rs          回顾流数据组装（结算历史/成果物清单/统计）→ 纯文本报告
  suggest_milestones.rs  现状×投入→里程碑草案（基础/应用/项目 通用节奏）【与 interview 同文件亦可】
  budget_allocator.rs    上下文预算分配（仅 M3；档位/排序截断/降级信号）
        ▼
数据层  db_goals.rs       三表 CRUD + 聚合查询（读现有表，不建派生表）
        ▼
命令层  commands_goals.rs CRUD/绑定/progress 上报/settle/pause/abandon/retro（校验+编排）
        ▼
UI 层   GoalPage（独立 Tab）/InterviewDialog（双展开）/GraduateDialog/RetroTimeline（复用现有组件）
```

**三根接线管**（记忆接入 AI 的全部机制，均为纯函数，M3 才接线）：
1. L1/L2 上下文组装（当前会话/当前笔记）
2. L3 检索注入（FTS5 top-K，K=8，每片段截断 ~300 token）
3. L4.5 目标摘要（goal → summary：进度/里程碑/弱项/原始意图——**每次现算，无缓存**；聚合皆毫秒级 SQLite 查询）

**记忆闭环**：库 → 检索 → 生成 → 回写（trajectory/对话消息/复盘报告）→ 库。连续性＝闭环在，不依赖任何 AI 外部状态。

## 五、数据模型（db_migrations.rs 新建三表 + 埋点 kind 扩展；迁移幂等）

```sql
-- v0.18.0（REQ-030 激活）：学习目标——意图层对象
CREATE TABLE IF NOT EXISTS goals (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    domain_tag TEXT,                                  -- 复用 15 类领域标签
    status TEXT NOT NULL DEFAULT 'active',            -- active/paused/graduated/abandoned（四态，无 draft）
    horizon_end INTEGER,                              -- 中周期锚点，非截止日 KPI；NULL=无期限（合法）
    success_criteria_json TEXT NOT NULL,              -- 判据配方（快照，毕业后冻结）
    intent_json TEXT NOT NULL DEFAULT '{}',           -- 访谈答案：scenario/level/driver/criteria_statement/non_scope/weekly_commitment/obstacles
    created_at INTEGER NOT NULL,                      -- 即开始时间（"第 6/12 周"进度由 created_at 推算）
    completed_at INTEGER,
    updated_at INTEGER NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_goals_status ON goals(status);

CREATE TABLE IF NOT EXISTS goal_milestones (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    goal_id INTEGER NOT NULL REFERENCES goals(id) ON DELETE CASCADE,
    title TEXT NOT NULL,
    due_at INTEGER,
    order_idx INTEGER NOT NULL DEFAULT 0,
    status TEXT NOT NULL DEFAULT 'pending',           -- pending/in_progress/done/skipped
    criteria_type TEXT NOT NULL DEFAULT 'manual',     -- manual | group_settled | self_test
    ref_group_id INTEGER REFERENCES note_groups(id) ON DELETE SET NULL,
    completed_at INTEGER,
    created_at INTEGER NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_milestones_goal ON goal_milestones(goal_id);

CREATE TABLE IF NOT EXISTS goal_groups (               -- N:M：一组可服务多目标
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    goal_id INTEGER NOT NULL REFERENCES goals(id) ON DELETE CASCADE,
    group_id INTEGER NOT NULL REFERENCES note_groups(id) ON DELETE CASCADE,
    added_at INTEGER NOT NULL,
    UNIQUE(goal_id, group_id)
);
CREATE INDEX IF NOT EXISTS idx_goal_groups_group ON goal_groups(group_id);

-- 埋点（metrics_events.kind 契约扩展，与既有 kind 同批同规）：
-- goal_created / goal_milestone_done / goal_graduated / goal_abandoned / goal_paused
-- 占位契约（M1 只登记不写代码）：self_test_passed / self_test_failed（M3 真实化）
```

## 六、目标访谈设计（Goal Interview）

**一套 InterviewDialog，两种默认展开**：

- **访谈模式（默认入口）**——四步向导 + 宣言确认；第 1/3 问**必答**，第 2/4 问**折叠可选**；chips 为主、填空兜底、每步可「跳过/以后想」。
- **快速模式**（副入口「只想简单记一下」）——同一组件，只展开名称 + 期限两个字段，判据走默认档。**访谈绝不允许变成负担**（防组沼泽化升级为目标沼泽化）；所有答案可后期回溯编辑（目标详情→重新访谈，配方重推）。

| 步 | 问题 | 必答 | 答案落库 | 用途 |
|---|---|---|---|---|
| 1 意图澄清 | 「学会以后想用它做什么？」（工作自动化/独立项目/考试通关/兴趣分享/还没想好） | ✔ | intent_json.scenario | 定义真目标（非学科名）；选材/里程碑依据 |
| 2 现状与驱动 | 「现在什么程度？」（零基础/会一点/系统学过一半）＋「为什么是现在？」（工作需要/转行/好奇/其他） | 折叠 | level / driver | 校准起点与建议时长；复盘对照驱动不变性（M3 用） |
| 3 边界与判据 | 「做到什么程度算会了？」（能上手/能独立完成实例/能教别人/证书通过/说不清）＋「时间怎么算？」（3 个月/半年/无期限/先试两周）＋「明确不学什么？」 | ✔ | criteria_statement / non_scope | 推判据配方（下表）；non_scope 防目标沼泽化 |
| 4 可行与素材 | 「每周能投多少时间？」（≥5h/2-5h/看情况）＋「现有素材？」（已有关联组多选）＋「已知障碍？」 | 折叠 | weekly_commitment / groups 预勾选 / obstacles | **预填第一份周契约**（复用 contracts）；组绑定在访谈内完成；复盘对照偏差（M3 用） |

**第 5 步 · 目标宣言确认**：回显一句话 + **里程碑草案**——「用 12 周学会 Python 基础，达成标准：独立完成爬虫实例并记录 ≥1 次应用；边界：不做 Web 框架」，并预填 `suggest_milestones` 产出的 3 个草案（如「第 4 周 基础语法 → 第 8 周 刷题 → 第 12 周 项目实战」，用户可删改标题/期限/绑组）。可改可退，确认后创建（status=active，一步到位，无 draft 仪式）。

### 答案 → 配方推导（goal_interview.rs 纯函数，TDD table-driven golden）

| 判据档位（第 3 步） | 自动配方（success_criteria_json） |
|---|---|
| 能上手 | 里程碑 ×N + 主组结算 ×1 |
| 能独立完成实例 | 里程碑 + 项目组结算 + 应用记录（knowledge_decisions）≥1 |
| 能教别人 / 证书 | 里程碑 + 组结算 + 自测通过率 ≥80%（M3 真实化；M1/M2 占位「访谈已记录」） |
| 说不清 | 默认档：里程碑 + ≥1 组结算 + 近 90 天复习活跃度 |

## 七、状态机与判据（goal_rules.rs）

```
active ⇄ paused
active → graduated（毕业仪式用户确认；见判据）
active/paused → abandoned（显式动作+可选原因，无惩罚文案）
```

- **毕业判据**（触发「可毕业」档位，非自动毕业）：① 里程碑全部 done（绑组结算的自动通过）② 组结算数 ≥ 配方值（读 settlements **历史计数**——归档组仍计入，防「结算后组被归档导致判据蒸发」）③ 复习活跃度达标（review_logs 近 90 天）④ 自测（M3）；⑤ 自评仅作毕业确认时的补位。
- **毕业＝用户确认仪式**（延续 v0.11.3「结算必须用户可见而非静默后台」）：报告快照（里程碑/子组结算/复习统计/成果物清单）→ `goal_settle` 写快照 + status=graduated + 埋点 goal_graduated。
- **调整/暂停/放弃**：显式动作，改期/改判据/换组随时可做（弹性承诺上延：断签不清零）；放弃记录原因（可选），不触发任何惩罚性状态。

## 八、记忆与预算架构（「库即记忆」硬约束）

- **记忆**：唯一事实源＝本地库（notes/notes_versions/sessions/flashcards/review_logs/settlements/contracts/knowledge_*/ai_chat_messages/ai_tasks(trajectory)/metrics_events/goals）。AI 无记忆模块、无状态、无缓存层；每次调用经三根接线管现取现拼（摘要与聚合皆毫秒级查询，缓存是过度设计）。
- **预算档位化**（budget_allocator 纯函数，仅 M3，TDD golden）：**轻量 ~4K / 标准 ~10K / 深度 ~30K**，默认标准，设置页可选（交互复用精修四档阶梯范式）。档位内部：系统+目标摘要 ~2K ｜ 信号注入（标量/枚举 ~0.3K，不随库增长）｜ 检索片段 ~2.4K ｜ 对话历史滑窗 12 轮+早期摘要 ~3K ｜ 输出预留 ~2K。预算不足→按相关性排序截断 + 诚实提示（「上下文超限，已按相关性精简」），绝不静默。
- **复杂度承诺**：库增长 O(N)，调用成本 O(1)（检索点查代替全量注入）。测试：任意大输入列表 → 恒定输出（简化夹具即可证明 O(1)）。
- **该涨就涨（用户知情）**：深读模式（单篇全文 ≤2 万 token）/跨片段综合（按深度档）——传前显示成本预估 + 确认（复用 ai_refine_estimate 范式）；周复盘报告天然轻量档。
- **图片域**：影子缓存（REQ-094 随 M3 引入，上传前置）：每图一次 VLM 描述落库，下游只传描述文本，base64 永不重复上行；无缓存图走「先预览授权」既有路径。
- **降级**：预算异常/检索失败 → 纯本地统计报告（goal_retro 无 AI 依赖）→ 永不失败；AI 教练整体默认关（content_gate 双闸门）。

## 九、模块联动矩阵与一致性契约

原则：**目标层是纯只读聚合 + 事件钩子，不侵入现有模块状态机；不做双向写入。**

| 模块 | 联动 | 机制 |
|---|---|---|
| 笔记组 | 绑定 N:M；组面板反向「加入目标」；组卡目标徽标 | goal_groups + 组菜单扩展 |
| 组结算 | 里程碑 criteria_type=group_settled 自动通过；进度信号 | 读 settlements 历史计数 |
| 周契约 | 目标卡「本周契约 N/M」跨组聚合 | 复用 week_contract_status 纯函数 |
| 复习/FSRS | 复习活跃度/待复习卡数；**M1 弱项信号 = 低稳定性卡占比**（state_json 字段查询）；目标→组→复习面深链 | 读 review_logs + flashcards |
| 会话/笔记 | 归属链上卷：笔记→组→目标（零写路径）；落库时「已计入目标 X」轻提示 | 展示层上卷 |
| 档案四维/领域 | domain_tag 对齐——命中目标领域的热词预热提示可归入 | 复用 domain_tag |
| 知识体系层 | 应用记录数（knowledge_decisions）＝判据信号；**概念低激活弱项 → M3**（AI 教练输入）；体系页「服务于目标 X」 | 读 knowledge_* |
| feed 碎片 | 碎片升级率（fragment_upgraded）→ feed 组质量信号 | 读 metrics_events |
| AI 对话 | L4.5 目标摘要注入；「/goal」命令（沿用 /refine 先例）；AI 复盘报告入任务段（trajectory）——均 M3 | 上下文组装纯函数 + gate |
| 设置 | 预算档位 + 判据配方默认 + AI 教练开关 | 设置页新增段 |
| 指标/北极星 | goal_* 埋点；目标毕业＝北极星强化信号（多组循环完成+跨组自测） | metrics_events 扩展 |

**一致性契约**：
1. 信号**现算**（进度页每次打开聚合，与库一致）；毕业/报告**写快照**（归档性质）。禁止双写——目标层不存进度副本，只存结果快照。
2. 组删除：goal_groups/ref_group_id 随既有 CASCADE/SET NULL 处理（**CASCADE 行为测试归 M1**，与 DDL 同批）；**提示 UI 归 M2**——目标卡提示「该组已删除，判据信号丢失」，绑定该组的里程碑降级为手动确认。
3. 目标删除：里程碑/绑定 CASCADE，**毕业报告与回顾流快照永久保留**（JSON 快照，同 notes_versions「回滚不破坏历史」哲学）。
4. 交叉入口＝上卷路径：笔记→组→目标；概念→体系→（可选）目标；目标不反向持有下钻总线。

**明确不联动**：采集端零侵入（课堂助手/捕获/ASR/OCR/浮窗，本设计不含任何采集改动）；精修/补充提示词不动（YAGNI）；系统级能力（窗口捕获/快捷键 ADR-025）不碰；商业化/云同步仍属远期。

## 十、UI 设计（独立「🎯 目标」Tab；零叙事元素——无活跃天数/排名/激励文案）

```
🎯 目标                                            [＋ 新建目标]
┌──────────────────────────────────────────────┐
│ 学会 Python     进行中 · 62% · 里程碑 2/4     │   ← 单行卡，点击进入详情
│ 写个爬虫       进行中 · 无期限 · 里程碑 0/1   │
│ 学乐理         已毕业 2026-07-21              │
│ 备考 CSP       已暂停 · 已停 23 天            │
└ (空态: 定一个学习目标——领域热词推荐: 学 Python / 练听力 / 画水彩)
```

- **GoalCard（单行折叠）**：名称 + 状态徽标（进行中/可毕业/已毕业/已暂停/已放弃）+ 一句话进度（百分比 · 里程碑 x/y）；`🎓 可毕业` 达标时亮起徽标。**周契约 / 组徽标 / 回顾流 / 操作全部收进目标详情**——列表是导航不是仪表盘。
- **目标详情**：进度 + 判据配方展示 + 里程碑清单（勾选/绑定徽标）+ 关联组（结算状态/卡片数/周契约）+ 弱项块（M1：低稳定性卡占比 Top 组）+ 动作区（+关联组/+里程碑/暂停/调整/🎓 毕业仪式）+ 回顾流入口
- **InterviewDialog**：一套组件双展开（快速=名称+期限；访谈=四步 + 宣言回显 + 里程碑草案预填，可跳过）
- **GraduateDialog**：报告预览（里程碑/子组结算/复习统计/成果物：组·笔记·闪卡·概念）+ 调整判据/再等等/确认毕业
- **RetroTimeline**：创建→里程碑→组结算→毕业 全时间线 + 毕业报告永久可读
- **组件清单**：GoalCard/GoalDetail/MilestoneRow/GoalProgressBar/GraduateDialog/RetroTimeline；组卡反向加「加入目标」；状态徽标 4 种；双主题 + B 视觉系统四级颜色（沿用）

## 十一、里程碑切分

| M | 内容 | 预估 | AI |
|---|---|---|---|
| M1 | 三表 DDL + goal_interview（含 suggest_milestones、table-driven golden）+ goal_progress/goal_rules 纯函数 + CRUD/绑定命令 + **组删除 CASCADE 影响面测试** + GoalPage/InterviewDialog（单组件双展开）+ 埋点 | ~2.5 天 | 无 |
| M2 | goal_settle（毕业仪式：报告生成+状态归档+成果物快照）+ RetroTimeline + pause/abandon + **组删除降级提示 UI** | ~1.5 天 | 无 |
| M3 | L4.5 目标摘要（现算）+ budget_allocator（档位化）+ AI 复盘报告（trajectory）+ AI 追问（intent_json）+ 概念低激活弱项 + 图片影子缓存——全部默认关 | ~2-3 天 | 增强 |

## 十二、测试策略

- **纯函数 TDD**：访谈答案→配方推导 **table-driven golden**（6 条端到端路径 + 参数矩阵，覆盖档位矩阵/跳过路径/折叠路径）；`suggest_milestones`（level×commitment 组合 → 草案模板）；goal_progress 聚合（0 结算/1 结算/周契约边界/归档组仍计数）；**四态状态机**转换守卫（重复毕业/放弃后毕业非法）；budget_allocator（任意大输入→恒定输出、档位切换、排序截断、降级信号）；goal_retro 报告组装；宣言组装。
- **数据层**：`:memory:` 库三表 CRUD + 级联——**M1 即测组删除 CASCADE 行为**（绑定消除/ref SET NULL）+ 目标删除快照保留（M2）。
- **命令层**：参数校验/编排，gate 路径（AI 相关命令，M3）。**前端 Vitest**：InterviewDialog 流程（双展开/跳过/返回/宣言确认/里程碑草案删改）、GoalCard 状态徽标、GraduateDialog 确认流（mock invoke）。
- **回归**：cargo test / clippy 零警告 / vitest / tsc（基线全绿）。

## 十三、验收标准

1. 新建目标：访谈四步 + 宣言确认（含里程碑草案预填，可删改）；快速模式两步可用（同一组件双展开）；每步可跳过，答案可回溯编辑
2. 目标卡单行折叠：名称/状态/一句话进度，达标亮「🎓 可毕业」；明细（周契约/组徽标/弱项/回顾流）全部在详情
3. 目标页聚合数据与组面板一致（同一来源）；弱项块显示低稳定性卡占比 Top 组（M1）
4. 绑定「组结算」型里程碑随组结算自动通过；组删除后该里程碑降级手动（M2 起有提示）
5. 毕业仪式：信号达标显示「可毕业」；报告含成果物清单；确认后状态=已毕业 + 回顾流时间线生成；毕业报告在目标删除后仍可读
6. 暂停/放弃显式可用；放弃无惩罚文案、记录原因（可选）
7. 目标卡零叙事元素（无 streak/无排名/无激励话术）
8. AI 教练默认关；开启后（M3）：问「Python 我学到哪了」→ 目标摘要现算注入；复盘报告入 AI 对话任务段（trajectory 可见）；预算档位在设置页可选；每次调用上报 token/成本；单次调用 ≤ 所选档位硬顶（任意大库实测）
9. 全量回归通过（cargo test / clippy / vitest / tsc）

## 十四、红线合规（AGENTS.md §4）

1. **本地优先**：目标层 0 云端依赖（M1/M2 全本地）；AI 仅 M3 增强且默认关
2. **数据不出本机**：目标/访谈/进度全本地 SQLite；AI 调用仅授权后上传最小检索片段（预算管线保证）
3. **授权/审计**：content_gate 双闸门复用；AI 复盘轨迹入 ai_tasks.trajectory_json；成本/用量落库可查
4. **降级**：AI 全部能力有纯本地兜底（goal_retro 统计报告）；失败不静默（六类错误归一复用）
5. **可测试性**：目标层核心逻辑全部纯函数化 + TDD；不引入 agent 框架/记忆模块（不可测黑盒）
