# 知识体系使用说明

> **状态**：活跃维护（v0.13.8：画布 / v0.13.7：上手路径 / v0.13.3：记一次使用与决策日志 / v0.13.2：概念升格 / v0.13.1：体系基建）——**仅覆盖已交付功能**；v0.13.4 审计、v0.13.5 书籍为规划中，见 FAQ。
> **定位**：知识体系层的端用户操作指南——回答"我为什么学、学了怎么用"。与《课堂助手使用说明》配合：课堂助手负责**提取**，本指南负责**沉淀与调用**。

## 〇、先懂三件事（30 秒）

1. **体系不是仓库**：它不收纳内容，只**引用**。内容（笔记/闪卡/碎片）先落「组」，再被体系引用。"组回答我在学什么，体系回答我为什么学、学了怎么用。"
2. **一句话主线**：问题树（🌳 为什么学）→ 概念（🧬 是什么）→ 模型（⚙ 怎么判断）→ 记一次使用（🛠 用了吗）→ 决策日志（🧭 判断对了吗）。
3. **三条纪律**：示例≠预填（输入框永远自己写）；概念名全库唯一（重名=同一概念）；升格单向（闪卡→概念，不反向）。

入口：底部导航「🧠 体系」。

## 一、快速上手（10 分钟走通全链路）

| 步 | 怎么做 | 效果 |
|----|--------|------|
| 1. 建全局体系 | 打开「🧠 体系」→ 点「✳ 创建你的第一个体系」→ 向导依次填：① 核心问题（必填）② 领域入口（3-5 行，可跳过）③ 本周第一个输出（可选）→「✓ 完成，创建体系」 | 左栏出现带「全局」徽标的体系卡；领域入口自动成为问题树 📂 节点；输出成为 🎯 场景节点 |
| 2. 复制示例（可选） | 空态页浏览「📷 示例：领域体系『摄影』」→ 点「📋 复制为我的体系」（尚无全局体系时会先弹创建向导） | 得到一棵「摄影」领域体系：问题树 + 3 概念 + 1 模型——只是**待改造的骨架**，可随意改名/增删 |
| 3. 建领域体系 | 左栏「＋ 新建领域体系」→ 输入名称 →「创建」 | 每个领域一棵独立体系树，挂在全局体系下 |
| 4. 内容挂进来 | 笔记页打开一条笔记 → 标题栏「🧭 挂到体系」→ 选体系 → 选问题节点 → 确认 | 笔记被引用；笔记组行出现体系徽标；问题节点引用数 +1 |
| 5. 升格一个概念 | 组内「＋ 概念卡」建 model 卡 → 复习面遇到它点「🧠 纳入体系」→ 选目标体系 → 确认 | 概念库多了带三问的概念；全库已有同名概念则"关联既有"，不重复建 |
| 6. 画布看全貌 | 问题树顶部「🎨 画布」浮钮 | 辐射布局展开；拖问题节点调位置（自动保存）；「✨ 自动排列」一键重排 |

## 二、创建体系

### 2.1 全局体系（创建向导）

**怎么做**：

- 入口：无任何体系时的空态按钮「✳ 创建你的第一个体系」，或左栏「＋ 新建体系」。
- 三步向导：
  1. **核心问题**（必填）：用一句话写下正在攻克的问题。示例行「例如：如何让化妆又快又自然？」只是**参照**——输入框从空白开始，不会被预填。
  2. **领域入口**：默认 3 个空行，填 3–5 个主干分支（如：底妆/眼妆/发型），可全部跳过；重复行会标红提示。
  3. **本周第一个输出**（可选）：一个具体可验证成果，落为「场景」节点。
- 中途关闭会弹确认（防误丢已写内容）。

**效果**：创建后自动选中新体系；左栏出现「全局」体系卡；领域入口 → 问题树 📂 节点；输出 → 🎯 场景节点。

> ⚠ 全局体系全库唯一（一个人一套体系）。已有全局体系后不要再点「＋ 新建体系」建第二个（会报错）；建新领域请用左栏「＋ 新建领域体系」。

### 2.2 领域体系

**怎么做**：左栏底部「＋ 新建领域体系」→ 输入名称 →「创建」。该入口仅在已有全局体系时显示。

**效果**：新体系卡出现在「领域体系」分组，挂在全局体系下；卡右上角 🗄 可**归档**（仅领域体系有）。归档后从列表消失，数据不删除。

### 2.3 摄影示例体系（一键复制，v0.13.7）

**怎么做**：无任何体系时的空态页，先浏览示例（问题树/概念/模型完整展示）→ 点「📋 复制为我的体系」。若还没有全局体系，点击会先弹全局创建向导（示例必须挂在全局体系下）。

**效果**：复制落库后自动选中新体系——完整骨架（问题树 + 3 概念 + 1 模型）。它处于**"待改造"**状态：改名、换核心问题、增删节点都行；不等于"已学完"。

**为什么不算"预填"**：示例=完整参照物（浏览是被动参照）；复制=主动拿骨架（真燃料）。向输入框塞示例内容才是被禁止的"假燃料"。

## 三、问题树（🌳）

### 三种节点

| 类型 | 徽标 | 含义 | 例子 |
|------|------|------|------|
| 问题 | ❓ | 待攻克的子问题 | 如何判断眼型？ |
| 领域入口 | 📂 | 体系主干分支（向导第②步产物） | 底妆 / 眼妆 |
| 场景 | 🎯 | 具体输出/应用场景（向导第③步产物） | 本周完成 5 分钟通勤妆 |

### 操作与效果

| 操作 | 怎么做 | 效果 |
|------|--------|------|
| 加子节点 | 节点行「＋」→ 输入文字 → 确认；顶部可加根节点 | 新节点入树（默认类型「问题」）；有子节点的节点默认展开 |
| 编辑文本 | 点节点文字 → 改 → 确认 | 节点文本更新 |
| 删除 | 节点删除按钮 → **二次确认**（明确告知删整棵子树） | 整棵子树删除；该子树上的**引用自动置空**——被引用的笔记/卡/组本体不受影响 |
| 选中查看 | 点节点行 | 右栏详情：类型徽标 + 父节点 + 「🔗 引用」区（见第六节） |
| 展开/折叠 | 点节点行箭头 | 折叠状态在画布切换后保持 |

**效果要点**：每个节点显示引用计数（如 `3`），随引用挂/撤实时增减；空树只提示「从子问题开始」，不预填任何示例节点。

## 四、概念库（🧬）

### 添加概念

**怎么做**：概念 tab →「＋ 添加概念」→ 弹窗填写：

- **名称** * —— 全库唯一（重名即报错，见 FAQ）
- **本质**（它"是"什么）/ **边界**（它"不是"什么）/ **联系**（它和什么相关）——三问骨架，可空、后补

**效果**：保存后概念卡出现在列表——名称 + 三问摘要一行 + 「从未应用」/「最近应用」标签 + 状态徽标。

### 详情编辑

**怎么做**：点概念卡 → 右栏面板：

- 三问编辑 + 状态（核心 / 关注 / 已归档）→「保存更改」
- 「最近应用」只读行：记一次使用后变时间戳
- 「📝 记一次使用」按钮（见第八节）
- 「🧭 决策日志」区（按当前概念过滤）
- 「🔗 引用」区（见第六节）

**效果**：概念是"思辨面"——全库唯一身份的知识单元。同名概念是同一个（这是交叉点判定的基础），所以重复创建会失败。

## 五、模型库（⚙）

### 添加模型

**怎么做**：模型 tab →「＋ 添加模型」→ 填写：

- **名称** *、**学科** *（≥1 个，逗号分隔）、**主张**（claim）、**成立条件**、**失效条件**

**效果**：保存后列表行显示 名称 + 学科标签 + 主张省略行。

### 详情编辑

**怎么做**：点模型行 → 右栏编辑五项 + 状态（active / watching / archived）→「保存更改」；下方「🔗 引用」区。

> 说明：模型状态下拉当前显示英文值（active/watching/archived），与概念状态的中文徽标（核心/关注/已归档）不同——按交付代码如实呈现。

**效果**：模型=可验证断言，「主张/成立/失效」三件套是它的记忆骨架。

## 六、引用——内容进入体系的唯一通道

**纪律**：体系只引用、不收纳。内容先落组（笔记/闪卡/碎片），再被体系引用。

**四种目标**：笔记组 / 笔记 / 闪卡 / 碎片。

### 入口 A：详情面板「🔗 引用」区（任意节点/概念/模型）

**怎么做**：选中实体 → 右栏「🔗 引用（N）」→ 下拉选目标类型 → 笔记组走组下拉（选择即带 id）；笔记/闪卡/碎片手输目标 id →「挂引用」。

**效果**：引用计数 +1（树节点、画布徽标同步）；重复目标会提示「该目标已存在引用」；每条引用可「撤销」。

### 入口 B：笔记详情「🧭 挂到体系」（推荐，免记 id）

**怎么做**：笔记页打开笔记 → 标题栏「🧭 挂到体系」→ 选体系 → 选问题节点（**必须选**，不能只挂体系根）→ 确认。

**效果**：笔记被引用；按钮变「🧭 已挂 · 体系名」；再点可换节点或取消挂接。无任何体系时提示先到「🧠 体系」页创建。

### 入口 C：组行体系徽标

**怎么做**：笔记组列表行小字区显示「🧭 体系名（n）」——该组被引用了 n 处；点击徽标直达体系页并自动选中该体系（不触发组过滤）。

**效果**：从"内容侧"一眼看到"谁在用我"；三个入口的引用数据完全同源。

## 七、概念升格（记忆面 → 思辨面，v0.13.2）

**前提**：组内创建「＋ 概念卡」（kind=model 的闪卡，记忆面）。

**怎么做**：复习面/卡片遇到 model 卡 → 「🧠 纳入体系」按钮 → 选目标体系（默认全局体系，可切换领域体系）→ 确认。

**四种结果**：

| 结果 | 含义 |
|------|------|
| 🆕 新建概念 | 卡片三问回填为新概念（卡面含三问时） |
| 🔗 关联既有 | 全库已有同名概念 → 只建立关联，不重复建 |
| ⚠ 跨体系提示 | 概念属于其他体系 → 不落库，提示手动处理 |
| ❌ 失败 | 如无全局体系 → "请先创建全局体系" |

**单向升格**：闪卡（记忆面）→ 概念（思辨面）单向；概念不会反向生成卡——避免两处重复记账。

**提醒（结算体系简报，v0.13.7）**：组结算弹层显示两行只读提示——

- 「本组有 N 张 model 卡可纳入体系」→ 去复习面处理
- 「体系『X』有 N 个概念 90 天未引用」→ 只提醒，不删除

## 八、记一次使用（应用闭环，v0.13.3）

**入口**：概念详情面板「📝 记一次使用」。

**四行表单**（占位=指南语义，不预填内容）：

| 行 | 字段 | 说明 |
|----|------|------|
| 1 | 内容 * | 我用了什么 / 做了什么（必填） |
| 2 | 预期 | 我预期发生什么 |
| 3 | 实际 | 实际发生了什么（负面也如实写，不评质量） |
| 4 | 反思 | 重来一次我会改什么 |

**引用必填**：体系实体（节点/概念/模型多选，application 模式默认带着当前概念）＋ 证据（组下拉 → 组内笔记/闪卡/碎片）。无引用无法保存（防记录膨胀）。

**效果**：保存后——

- 概念「最近应用」变为时间戳（概念卡 + 详情只读行同步）
- 「决策日志」→「应用」tab 出现该记录（含引用计数标签）
- 记录可删除（🗑 二次确认）

**决策日志**：概念详情面板底部「🧭 决策日志」，按当前概念过滤；「决策」tab 当前为只读占位——思辨面「记一个决策」的新建入口为规划中（命令已就绪，UI 待接线）。

## 九、画布（v0.13.8）

**入口**：问题树视图顶部「🎨 画布」浮钮 / 中栏「🗺 画布」标签（两者互通；树视图折叠展开状态保持）。

**首次打开**：自动辐射布局——核心问题虚拟卡在圆心（不可拖/不可选，仅展示）；问题节点按父子关系铺开；未布局节点批量初始化落库（失败下次打开重试）。

### 操作与效果

| 操作 | 效果 |
|------|------|
| 拖拽问题节点 | 防抖自动保存；切走/重开不丢——**位置只由你的手决定** |
| 画布 ↔ 树切换 | 视口持久化：下次回画布恢复上次视角；无记录则 fitView 兜底 |
| 「✨ 自动排列」 | 全量重算并**覆盖已存位置**——想保留手摆布局就别点 |
| 「⛶ 适配视图」 | 内容适屏（fitView） |
| 缩放 | >0.7 显示全文 / 0.4~0.7 仅标题 / <0.4 缩略卡 |
| MiniMap / 控件 | 常规画布导航 |

### 已知限制（如实告知）

- **概念/模型节点禁拖**：位置不落库——防"拖了没反应"的困惑；只有问题节点的位置会保存。
- 画布不做新建/编辑/连边（在树/概念/模型视图操作）。
- 切换体系时画布状态重置（视口按体系分开存放）。

**选中联动**：画布点节点/概念/模型 → 右栏详情面板（与树视图同一选中态）。

## 十一、常见问题（FAQ）

| 问题 | 说明 |
|------|------|
| 为什么体系里不能直接写笔记/建卡？ | 体系只引用不收纳：内容先落组（课堂助手/笔记/闪卡都在组里），再被引用。 |
| 笔记/闪卡的 id 在哪里找？ | 首选「挂到体系」选择器（免 id）；组引用走组下拉；手输 id 用于笔记/闪卡/碎片，可在其详情页/列表查看。 |
| 概念名保存报"已存在"？ | 名字全库唯一：重名=同一概念（交叉点判定依据）；用升格的"关联既有"，不要新建。 |
| 删问题节点会把内容删掉吗？ | 不会：级联删除的是子树节点，引用自动置空；笔记/卡/组本体安全。 |
| 复制摄影示例算偷懒吗？ | 不算：示例=完整参照物，复制=主动拿"待改造"骨架，之后怎么长由你决定。 |
| 概念 90 天未引用会被清理吗？ | 不会自动删；结算简报只提示。规划中的季度审计（v0.13.4）也走"建议+确认"而非强删。 |
| 画布上概念/模型为什么拖不动？ | 位置不落库，禁拖防"拖了没反应"；只有问题节点位置会保存。 |
| 领域体系能再嵌套吗？ | 不支持嵌套（v0.13 边界）；新领域建平级领域体系。 |
| 能建多个全局体系吗？ | 不能：全局体系全库唯一（一个人一套体系）。 |
| 「记一个决策」入口在哪？ | 规划中（v0.13.3 命令就绪、应用记录已可用，思辨面新建入口待接线）。 |
| 「自动排列」会打乱我的布局吗？ | 会覆盖已存位置——手摆好的节点请用「⛶ 适配视图」，别点「✨ 自动排列」。 |
| AI 会自动帮我建体系/记决策吗？ | 不会（AI 测量、人类见证：AI 只做补缝建议且默认关闭；体系与决策必须由你写）。 |
| 审计与书籍功能什么时候有？ | 规划中：v0.13.4 季度审计、v0.13.5 书籍笔记组尚未上线，上线后本指南同步更新。 |

## 十二、术语表

| 术语 | 含义 |
|------|------|
| 全局体系 | 唯一的"根"：核心问题 + 各领域入口（kind=global） |
| 领域体系 | 一棵领域树，挂全局体系下（kind=domain） |
| 问题树 | 领域体系的结构骨架：问题/场景/领域入口三类节点 |
| 概念 | 全库唯一的知识单元：本质/边界/联系三问（思辨面） |
| 模型 | 可验证断言：主张 + 成立/失效条件 |
| 引用 | 体系 ↔ 内容（组/笔记/闪卡/碎片）的联系；内容进入体系的唯一通道 |
| 升格 | model 闪卡（记忆面）→ 概念（思辨面）的单向升级 |
| 决策日志 | 一表两面：决策（思辨面 🧭）/ 应用（学习面 🛠），四行法记账 |
| 示例 ≠ 预填 | 示例=可复制的完整参照物；预填=向输入框塞内容（假燃料，禁止） |
