# 熵减收入方案（无工商户版）

> **约束条件**：个人开发者、无个人工商户/企业资质、不使用爱发电
> **核心原则**：核心学习功能（番茄钟/笔记/闪卡/费曼）永不收费；收费仅围绕 AI 增强与数字内容
> **最后更新**：2026-08

---

## 一、收款通道选型

个人无工商户可合规收款的渠道对比：

| 渠道 | 是否需要工商户 | 抽成 | 适合场景 | 自动化程度 |
|------|:-:|:-:|------|:-:|
| **面包多 (mianbaoduo.com)** | ❌ 不需要 | ~5% | 数字商品（激活码/内容包）| ⭐⭐⭐ 自动发卡 |
| **知识星球** | ❌ 不需要 | ~5%（苹果端更高）| 社群+内容订阅 | ⭐⭐ |
| **Gumroad** | ❌ 不需要（海外平台） | 10% + 支付手续费 | 面向海外用户/数字商品 | ⭐⭐⭐ 自动发卡 |
| **个人微信/支付宝收款码** | ❌ 不需要 | 0% | 小额打赏/早鸟预售 | ⭐ 手动发卡 |
| **GitHub Sponsors** | ❌ 不需要 | 0%（GitHub 不抽成）| 开源赞助 | ⭐⭐ |
| **Buy Me a Coffee / Ko-fi** | ❌ 不需要 | ~5% | 国际打赏 | ⭐⭐ |

### 推荐组合

- **主通道**：面包多（国内用户数字商品交付，自动发卡，无需客服值守）
- **辅助通道**：个人微信收款码（内测期小额验证、早鸟预售）
- **国际通道**：Gumroad 或 Ko-fi（若后续有海外用户）
- **开源赞助**：GitHub Sponsors（长线品牌建设，不设门槛）

### 合规说明

- 个人通过平台（面包多/Gumroad）销售数字商品，平台代扣代缴个税，无需自行注册工商户
- 年收入 ≤ 12 万元属个人所得税"劳务报酬/经营所得"免征增值税区间（2026 年政策，具体以当年税法为准）
- 如年收入持续增长超过免征额，再考虑注册个体工商户（届时可迁移至自有支付体系）

## 二、收入结构设计（三层模型）

```
┌─────────────────────────────────────────────────┐
│  第三层：数字内容包（一次性购买）                    │
│  音效包 / 主题皮肤 / 课程预设模板                   │
├─────────────────────────────────────────────────┤
│  第二层：AI Pro 订阅（月/季/年）                    │
│  高级模型 / 更高配额 / 多模态课堂助手               │
├─────────────────────────────────────────────────┤
│  第一层：免费层（永久免费）                         │
│  全部核心学习功能 + 基础 AI（本地推理/低配额）      │
└─────────────────────────────────────────────────┘
```

### 2.1 免费层（Free）— 永不收费

| 包含内容 | 说明 |
|----------|------|
| 番茄钟（含自定义预设） | 核心学习工具 |
| 笔记系统（结礁） | 核心学习工具 |
| 闪卡 + 间隔重复（反衰减呼吸） | 核心学习工具 |
| 费曼输出（浮出水面） | 核心学习工具 |
| 学习启动仪式 / 成就系统 | 体验层 |
| 基础 AI 功能（本地推理为主 + 低价档付费模型兜底） | 每日 15 次 AI 调用，覆盖摘要/闪卡生成/基础提问；**不依赖供应商免费额度**（智谱《服务协议》3.4 条禁止转供他人使用） |
| BYOK（自带 API Key） | 用户自行接入任意模型，不受平台配额限制 |

**设计意图**：免费层已构成完整学习闭环，付费不是"解锁功能"而是"提升 AI 体验上限"。

### 2.2 AI Pro 订阅

| 维度 | Free | Pro（¥12/月 或 ¥99/年） |
|------|------|--------------------------|
| AI 模型 | 本地模型（Ollama）/ 低价档付费模型（轻量） | Qwen-Plus / DeepSeek-Chat / GLM-4（高级，付费档） |
| 每日 AI 调用次数 | 15 次 | 80 次 |
| 每日费用上限 | ¥0.5（平台承担） | ¥2.0（平台承担） |
| 多模态课堂助手 | ❌ | ✅（Qwen-VL 视觉提取） |
| AI 苏格拉底深度追问 | 3 轮/次 | 无限轮次 |
| AI 学习规划师 | ❌ | ✅ |
| 优先响应队列 | ❌ | ✅ |

**定价依据**：
- 当前 `budget.py` 日费用上限 ¥2.0/用户，月成本约 ¥60（重度）/ ¥15（轻度均值）
- ¥12/月定价覆盖轻度用户成本 + 30% 毛利；重度用户通过日配额硬顶控制亏损
- 年付 ¥99（≈¥8.25/月）提升 LTV 并降低流失

**技术落地（已有基础设施）**：
- `rate_limit.py`：已支持 per-feature + global 每日限额，只需按 user_tier 读取不同阈值
- `budget.py`：已支持每日费用/token 硬顶，按 tier 分级即可
- `providers.py`：已有 feature→provider 路由表，按 tier 路由不同模型槽位
- 新增：用户表 `tier` 字段 + 激活码验证接口

### 2.3 数字内容包（一次性购买）

| 商品 | 定价 | 内容 | 交付方式 |
|------|------|------|----------|
| 深海声景音效包 Vol.1 | ¥6 | 8 个高品质自然声景音轨（雨声/森林/深海/篝火等） | 面包多自动发卡 → 应用内激活 |
| 主题皮肤包 | ¥3~6/个 | 界面主题（色板+动效参数） | 同上 |
| 课程预设模板包 | ¥3 | 考研/考公/语言学习等场景预设组合 | 同上 |

**设计意图**：低单价数字商品降低首次付费心理门槛，培养付费习惯。

## 三、分阶段执行路线

### Phase 0：零开发验证（当前 ~ 2 周）

**目标**：验证付费意愿，不写一行收费代码

| 动作 | 工具 | 预期产出 |
|------|------|----------|
| 内测用户 1v1 访谈（5~10 人） | 微信语音 | 付费意愿/价格敏感度/最想要的付费功能 |
| 早鸟预售：¥199 终身 Pro（限 100 名） | 个人微信收款 + 手动记录 | ≥10 人付款 = 验证通过 |
| 面包多店铺搭建 + 首个商品上架（早鸟许可证） | mianbaoduo.com | 自动化发卡通道就绪 |
| GitHub Sponsors 页面开通 | github.com/sponsors | 开源社区曝光 |

**验证通过标准**：早鸟预售 ≥ 10 人付费，或访谈中 ≥ 60% 表达"愿意为 AI Pro 付费"。

### Phase 1：最小收费系统（2~4 周开发）

**前置条件**：Phase 0 验证通过

开发清单：

| 任务 | 涉及文件 | 工作量 |
|------|----------|--------|
| 用户表新增 `tier` 字段（free/pro） | `client/electron/db/schema.ts` | 0.5d |
| 激活码生成脚本（离线生成，前缀区分类型） | `scripts/license-gen.mjs`（新建） | 1d |
| 激活码验证接口 | `server/ai-gateway/routes/license.py`（新建） | 1d |
| 客户端激活码输入 UI（设置页） | `client/src/pages/settings/` | 1d |
| `rate_limit.py` 按 tier 分级配额 | `server/ai-gateway/middleware/rate_limit.py` | 0.5d |
| `budget.py` 按 tier 分级费用上限 | `server/ai-gateway/cost/budget.py` | 0.5d |
| `providers.py` 按 tier 路由模型 | `server/ai-gateway/config/providers.py` | 0.5d |
| 面包多 webhook → 自动发放激活码 | 轻量云函数/手动 | 1d |

**总计**：~6 个工作日

### Phase 2：内容包 + 订阅自动化（4~8 周）

| 任务 | 说明 |
|------|------|
| 音效包/主题包打包与分发机制 | 应用内下载 + 本地激活 |
| 订阅到期/续费逻辑 | 激活码带有效期，到期降级为 Free |
| 面包多/Gumroad 多商品上架 | 音效包、主题包、月/季/年订阅码 |
| 付费转化引导 UI | 免费配额耗尽时的温和升级提示（非阻断） |

### Phase 3：增长与合规（收入稳定后）

- 月收入稳定 > ¥3000 → 评估是否注册个体工商户（可开对公账户、接入微信支付商户）
- 用户规模 > 500 付费 → 考虑迁移至自有支付系统（Stripe/微信支付商户）
- 持续优化 AI 成本：缓存命中率提升、本地 Ollama 分流、模型降级策略

## 四、成本与盈亏平衡分析

### 固定成本（月）

| 项目 | 费用 |
|------|------|
| 服务器（AI 网关 + 同步服务） | ~¥50（轻量云） |
| 域名 + CDN | ~¥10 |
| 面包多抽成（5%） | 按收入浮动 |
| **合计固定成本** | **~¥60/月** |

### 变动成本（AI 调用）

| 用户类型 | 月均 AI 成本 | 说明 |
|----------|:---:|------|
| Free 用户 | ¥0.5~1.5 | 本地推理为主 + 低价档付费模型兜底（约 300 次/月 × ¥0.003）；免费额度仅限开发/内测，不可服务公众用户 |
| Pro 轻度（日均 10 次） | ~¥8 | Qwen-Plus 为主 |
| Pro 重度（日均 50 次） | ~¥35 | 含多模态调用 |

### 盈亏平衡

- 月固定成本 ¥60 + AI 成本（10 个 Pro × ¥15 + 200 个 Free × ¥1 ≈ ¥350）= ¥410
- 10 个 Pro 用户收入 = ¥120（月付）或 ¥82（年付均摊）
- **盈亏平衡点 ≈ 35 个 Pro 月付用户**（含早鸟预售收入则更快；若 Free 层 AI 成本经 BYOK 转嫁用户，回落至 ≈ 25）

## 五、定价心理学与转化策略

| 策略 | 实现 |
|------|------|
| **锚定效应** | 早鸟 ¥199 终身 → 正式 ¥12/月（显得便宜） |
| **损失厌恶** | 免费配额耗尽提示"今日 AI 次数已用完，明天恢复"而非"请付费" |
| **禀赋效应** | 用户数据（笔记/闪卡/学习记录）积累越多，迁移成本越高 |
| **社会证明** | GitHub Sponsors 公开致谢列表 + 应用内"感谢 N 位支持者" |
| **互惠原则** | 免费版已足够好用 → 用户自发想支持开发者 |

## 六、明确不做的事

| 不做 | 原因 |
|------|------|
| ❌ 核心学习功能付费墙 | 违背本地优先承诺，摧毁用户信任 |
| ❌ 广告变现 | 与"深海静谧"产品哲学冲突 |
| ❌ 数据变现/上传训练 | 隐私承诺不可妥协 |
| ❌ 爱发电 | 用户明确要求排除 |
| ❌ 需要工商户的支付通道 | 当前阶段约束 |
| ❌ 强制联网验证 | 离线可用是底线；激活码本地缓存验证，7 天离线宽限 |
| ❌ 供应商免费额度转供用户 | 智谱等《服务协议》3.4 条禁止"复制、转让、出售、出租、出借、许可、提供他人使用"；免费额度仅限开发/内测（非商业运营） |

## 七、风险与应对

| 风险 | 概率 | 应对 |
|------|:---:|------|
| 付费意愿不足（< 10 人早鸟） | 中 | 转向纯赞助模式（GitHub Sponsors + 打赏码），AI 成本由 BYOK 转嫁用户 |
| 供应商免费额度收紧/条款变动 | 中 | 免费层不依赖免费额度（本地推理 + BYOK + 付费低价档）；每季度复审各 Provider 服务协议 |
| AI 成本失控（重度用户） | 低 | 日配额硬顶已就绪（budget.py）；极端用户单独沟通 |
| 激活码被分享 | 中 | 一码一设备绑定（machineId）；超限自动冻结 |
| 平台政策变动（面包多） | 低 | 多通道备份（Gumroad + 个人收款码） |
| 税务合规风险 | 低 | 年收入 < 12 万免征增值税；超出后注册工商户 |

## 附录：激活码设计

```
格式：ENTROPY-{TYPE}-{XXXX}-{XXXX}
TYPE：PRO（订阅）/ LIFE（终身）/ SND1（音效包）/ THM1（主题包）
示例：ENTROPY-PRO-8K2M-Q7XN

验证逻辑：
1. 客户端输入激活码 → 调 /api/v1/license/activate
2. 服务端校验签名 + 类型 + 有效期 + 设备绑定
3. 写入本地 SQLite（离线缓存，7 天宽限）
4. 到期前 3 天应用内温和提醒续费
```
