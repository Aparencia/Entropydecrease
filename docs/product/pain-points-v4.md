## 第二部分：底层哲学
### 2.1 学习隐喻的分岔：获取 vs 成为
认知科学中"学习作为获取"与"学习作为参与"两个隐喻长期并存，在AI时代从视角之差变为生死分岔：
- **获取隐喻**（v1.0 隐含）：记住更多、掌握更多、对抗遗忘——围绕此设计的产品，**AI是逆风**（知识可即取即用，问AI就行）
- **成为隐喻**（v2.0 起采用）：成为会化妆的人、能写出程序的人、群里那个懂乐理的人——围绕此设计的产品，**AI是顺风**（AI能替你回答乐理问题，不能替你成为懂乐理的人）
用户"为什么不直接问AI"的隐性疑问（N20），只有"成为"隐喻能够回答。feed 地形的最锐利版本（v2 下卷 §20）：**问AI得到的是答案，被AI问得到的才是能力**——答案可以外包，品味不能外包，因为品味就是"你"。
### 2.2 熵减方向的修正：叙事熵高于知识熵
v1.0 的"熵减"指向**知识系统的熵**（遗忘、混乱、碎片）。但对撞后的图景是：还有一个更高熵、衰减更快的系统——**"我是一个在学X的人"这个自我叙事**。
关键的不对称性：**知识衰减了可以重建（笔记还在、卡片还在），叙事断裂了人就真的走了**。而且顺序是反的——人是先"不再觉得自己是学习者"，然后才停止复习的。
### 2.3 产品为稳态设计，用户活在瞬态
"稳定地持续学习"只是学习生命周期曲线上的一小段。但所有学习产品的核心界面都是为那一小段的稳态居民建造的；瞬态中的人（将要开始的、正在放弃的、已经离开的、想要回来的）占据生命周期的大部分时间，却住在城市之外。这解释了行业之谜：功能越来越科学，弃用率纹丝不动——**所有新功能都在优化稳态体验，而流失全部发生在瞬态。**
### 2.4 否定的三个 v1.0 前提
| v1.0 前提 | 修正 | 证据 |
|-----------|------|------|
| 学习失败的单位是"一次课" | 学习失败的单位是"整个生命周期"，课与课之间发生的事贡献远大于课内 | 遗忘研究：无强化新信息一周内可丢失高达90%；间隔效应的力量在跨天跨周的时间安排 |
| 学习者是同质人群 | 学习者至少分化为四类（探索者/启动者/平台期者/回归者），同一痛点对不同人群严重性不同 | Dreyfus 技能获得模型 |
| 动机是可以"解决"的静态痛点 | 动机是随时间起伏、可动态内化的变量；问题从"如何让人有动机"变为"用户在动机周期哪个阶段，此阶段需要什么" | 自我决定理论：外在动机可内化为自主性动机 |

## 第三部分：地形定义——学习结构住在哪里
### 3.1 判据裁决
| 候选判据 | 排除理由 |
|----------|----------|
| 平台（抖音/B站/YouTube） | 同一平台内并存 15 秒口播、长视频合集、付费专栏——形态差异大于平台差异；桌面端主要捕获面是网页播放器与本地文件，平台 API 不可达 |
| 时长（长/短） | 边缘案例切错：90 秒的完整公式推导有结构，30 分钟的闲聊切片无结构。时长只能作启发式信号 |
| 学习声明（用户是否选择采集） | 任何内容都可通过采集获得声明，判据失去判别力——声明改变流向，不改变地形 |
| **结构承载性（采用）** | 学习结构住在内容里（作者预制的章节/进阶/论证）→ **容器地形**；学习结构住在行为里（单条无结构，消费模式有结构）→ **feed 地形** |
### 3.2 声明的正确定位：路由开关
| | 采集一段网课 | 采集一条短视频 |
|---|---|---|
| 产物 | 有章节、前置依赖、论证链的**课程笔记** | 三五句话 + 几张示范画面的**碎片** |
| 能否支撑"我在学X" | 能——构成知识实体 | 不能——300 条碎片相加不等于一门课 |
**采集/声明改变内容的归属，不改变内容的性质。**碎片可以资产化（可搜索、可复习），但不能冒充课程——产品必须如实呈现碎片的身份（"假燃料"死法的微观形态）。
### 3.3 边缘案例验证
| 案例 | 路由结果 | 自洽性 |
|------|----------|--------|
| 抖音付费专栏（有章节） | 容器地形 | ✓ 入口在抖音，地形属容器——边界与平台无关 |
| 单条 20 分钟系统教程 / 90 秒公式推导 | 结构密度高 → 自成一组（容器化处理） | ✓ 长短判据失效处的正确路由 |
| 半年刷的 300 条穿搭视频 | feed 地形，按主题归组 | ✓ 单条无结构、模式有结构 |
| 用户收藏 50 条同主题短视频 | 归组（feed）；主动"收藏→大纲"时升级为容器 | ✓ 地形可迁移（"容器交接"） |
### 3.4 多端协调的推论
锚定结构承载性后，跨端同步的资产是平台无关的：**学习声明 + 消费账本 + 能力测量 + 笔记组**。任何端产生的内容都按同一判据路由进同一产物模型——平台只是适配器（代码中 `PlatformAdapter` 已按此设计）。

## 第四部分：统一理论——同步器与飞轮
### 4.1 广义模型：学习死亡＝叙事与能力失同步
**学习死亡的广义形式，是叙事与能力的失同步——而两地形的失同步方向相反。**
| | 容器地形（课程） | feed 地形（短视频） |
|---|---|---|
| 失同步方向 | **叙事超前于能力**（报名即宣告"我正在成为"，能力还没跟上） | **能力超前于叙事**（隐性能力真实累积，自我认知滞后三年） |
| 死亡形态 | 崩塌——假燃料烧尽，叙事摔死在能力面前 | 埋没——真金沉在河底，叙事从未点火 |
| 产品职责 | 防止叙事透支（"动机App化"警戒） | **把叙事拖上来追赶能力** |
### 4.2 飞轮模型（容器地形的特例展开）
"学习失败的原因是忘了还是不再觉得自己是学习者"——不是二选一，是一个耦合系统：
```
叙事（我正在成为会X的人）
  ↓ 支撑
行为（练习、复习、动手）
  ↓ 产生
真实能力增长
  ↓ 转化为
可见之物（进展、产物、见证）
  ↓ 反哺
叙事
```
**学习死亡的正确描述是：遗忘是尸检报告上的死因，叙事断裂才是原始病因——但叙事只以真实能力为食。**
飞轮辐条与骨折点：蜜月末期断"行为"（剂量超过动机，第1–2周）；低谷断"可见性"（努力但无可感知进步，第3–6周）；平台期断"可见性"（能力在长但不可见，第2–4月）；中断断"行为"（静默停止→叙事衰减）；回归时刻断"叙事"（羞耻直接攻击身份）；毕业断"叙事的下一环"（身份无处可去）。
### 4.3 同步器的离合器比喻（feed 地形的特例展开）
**能力轴在转（消费三年，判断力真实增长），叙事轴在空转（假身份由算法供油，永不熄火也永不传力）。产品是离合器——把两根转速不同的轴咬合。**
咬合的瞬间叫**觉察**，咬合后的传动叫**学期**，咬合失败的两种形式是**打滑**（觉察了但没行为，N23）和**假咬合**（安慰剂显影）。
### 4.4 双时钟与边界条件
- **知识熵**：以**天**为半衰期（遗忘曲线）；**叙事熵**：以**周**为半衰期（身份衰减）——产品必须在两只时钟上同时工作
- 维护律：容器地形靠**习惯**维护（天时钟），feed 地形靠**节奏**维护（季时钟）
- 点火律：飞轮至少有两种点火序列——容器的宣言式点火，feed 的考古式点火；辐条不变，点火位置因地而异
- **边界条件**：本理论只适用于"成为型"学习者（化妆、编程、乐理、绘画，恰好是目标用户的全部）。"过桥型"学习者（考证、应试、速成）不需要叙事层，引擎层就够——边界不写清，模型会被应试场景的反例轻易证伪

## 第五部分：五个镜头与痛点假设全景（N1–N25 统一清单）
### 5.1 五个镜头（容器卷产出，对两地形同真）
1. **跨周期时间**：学习失败的主战场不在课内，在课与课之间（N1–N3）
2. **人群分化**：不存在"网课学习者"这个单一物种——探索者/启动者/平台期者/回归者，回归者几乎被所有产品忽视但规模最大（N4–N7）
3. **动机的动态演化**：动机不是开关，是一条有形状的曲线——蜜月（1–2周）→低谷（3–6周）→平台（2–4月）→突破（N8–N11）
4. **内容异质性**：学化妆和学乐理不是同一种学习——陈述性知识可卡片化，程序性知识必须动手练，心智模型必须重建（N12–N15）
5. **学习的社会性**：独自学习是历史例外；维果茨基"最近发展区"只能通过与"更有知识的他者"的互动跨越（N16–N19）

| 编号 | 痛点假设 | 一句话 | 地形 |
|------|----------|--------|------|

### 5.3 三个结构洞察
1. **产品为稳态设计，用户活在瞬态**（见 §2.3）
2. **熵减可能减错了系统**：叙事熵高于知识熵（见 §2.2）
3. **两种学习隐喻在AI时代分道扬镳**（见 §2.1）
### 5.4 用户语言测试（痛点筛选标准）
一个痛点是真实的，当且仅当用户能用自己的话抱怨它。"看完只记得开头和结尾"能通过；"我的提取路径太单一了"不能通过——没人这么说话。穷举式头脑风暴的系统性缺陷是会产出**"文献里真实、体验里沉默"**的痛点。

## 第六部分：生命周期状态坐标系（两地形对照）
| 容器状态 | feed 对应 | 性质 | 时钟 | 情绪载荷 | 主断裂风险 | 设计原则 |
|----------|-----------|------|------|----------|-----------|----------|
| 探索 | 漂移／囤积 | 稳态（可滞留数月） | 月/周 | 好奇＋承诺焦虑／虚假满足 | 永不开始（N4）／沼泽化 | 降低承诺门槛；收藏＝意图信号，不清理只升级 |
| 启动/蜜月 | 觉察→验证 | 瞬态（决定性瞬间） | 天/分钟 | 兴奋／惊讶→怀疑 | 过度承诺（N8）／证据被当彩虹屁划走 | 降温仪式、剂量设定；一次只给一个证据＋附微行动 |
| 常规期 | 学期 | **稳态（理想主场）** | 天/季 | 平静／投入 | 单调耗尽／学期结束即蒸发（N24） | 队列＋习惯，低情绪摩擦；结算仪式＋下学期预告 |
| 低谷 | （验证失败退回） | 瞬态（3–6周窗口） | 天 | 羞耻、自我怀疑 | 提醒暴力、流失峰值 | 生存模式：最小可行日＋静默 |
| 平台期 | （校准前夜） | 稳态 | 周 | 无聊、怀疑 | 努力–回报断裂 | 显影看不见的进步 |
| 中断 | 学期间歇 | 瞬态 | 事件 | 无感（危险正在于此） | 静默熵增 | 宽限设计，不追债 |
| **失联** | （漂移回归态） | **稳态（住在产品之外）** | 周 | 愧疚累积 | 回归门槛随时间升高 | 唯一触点：不指责的通知 |
| 回归 | 回流 | 瞬态（决定性瞬间） | 分钟/季节 | 愧疚＋希望／惯性＋期待 | 第一屏羞辱／下学期不回归 | 无羞耻回归之门；学期邀请，不追债 |
| **毕业** | 迁移 | 瞬态 | 事件 | 骄傲或空虚／决心＋不舍 | 身份蒸发／交接即失联 | 结算＋下一课桥梁；迁移＝成功不是流失 |
| （无对应） | **校准** | **稳态（滞留者终点）** | 季 | 平静的自信 | 自满／测试疲劳 | 低频复测；永不push迁移 |
**关键发现**：容器卷骨折层的全部智慧在 feed 地形逐条升格——回归之门→觉察之门；毕业结算→换季结算；中断宽限→学期间歇；最小可行日→最小练习。**课程世界把事件当急诊（L3 是应急科室），feed 世界把事件当地基（时机层是主建筑）。**同一批设计资产，换了地基级别。

## 第七部分：产品架构——公共底座、分叉管线、统一产物层
### 7.1 技术架构总图
```
公共底座（地形无关，已建成）
├── sherpa-onnx ASR / PaddleOCR / 视频解码 / 常驻引擎池
├── 四维解耦（ContentForm × VisualTier × DomainTag）——结构密度的可计算代理
└── PlatformAdapter（平台壳适配）
        ↓ 地形分叉（terrain 标记路由）
地形管线（地形强相关）
├── 容器：实时捕获 → 流式转写 → 会话级归档 → 笔记产物（天时钟）
└── feed：导入/账本 → 异步批处理 → 主题组聚合 → 组产物（季/阈值时钟）
        ↓
统一产物层（融合点）
└── 笔记组：两种来源的归宿，同一学习循环的入口
```
**成本裁决**：共享引擎 + 独立管线（增量约 20–30%：terrain 标记 + 管线分叉 + 组模型；引擎单例复用）；否决完全隔离进程（模型双份加载、IPC 复杂度翻倍，零收益）；feed 管线是异步批处理，与容器实时捕获时序零竞争。
**为什么"都是视频分类"却曾需要两套理论**：四维解耦回答"**这段内容是什么**"（内容本体）；飞轮/同步器回答"**这个人如何与内容共处**"（生命周期本体）。同一分类结果在两个地形语义不同：一段"教程"视频，在容器是一个会话（被提取、被复习），在 feed 是半年 300 条中的一条（测量材料）。**分类是管线的公共输入，生命周期是地形的分叉输出。**

### 7.3 feed 管线消费的学习层：一基座三柱子
**基座：测量层（用户永不见）**：技能地图（分品类可测能力清单，吸收 P13＋S8）· 盲测仪器（自适应判断题组，F2＋N25）· 常模库（分品类×分消费时长的能力分布，N25）。
**柱一：显影层——让隐性能力变成证据**：盲测显影（季末判断测试 vs 季初／常模对照）· 考古报告（AI 读收藏史，投影成"你无意识修完的课程"）· 换季结算（N24）· 最便宜记录（时间戳前后对比，私域非表演）· 见证结构（人类见证；**AI 只测量，不见证**）。
**柱二：时机层——把觉察转化为行为**：焦虑窗口截获（"三天后的场合"预案）· 学期邀请（换季＝开学通知，不追债）· 显影-时机绑定（N23：显影必附微行动，永不裸奔）· 分型路由（穿搭→显影优先；化妆→练习路由；思维模型→输出重定向或劝退）。
**柱三：容器层——迁移者轨道**：收藏→大纲（沼泽排涝为课程结构）· 容器交接（送入课程/书/系统练习，交接即毕业）· 创作者作业（供给侧，远期）。
**四条架构纪律**：①不许骚扰滞留者——校准态是正当终点，不是漏斗漏水；②显影必须可证伪——测量，不是计数（安慰剂防线）；③AI 测量，人类见证——AI 永远扮演考官而非神喻（N20 的正式应战）；④产品出击，永不被打开——feed 侧没有每日视图，只有送达与截获。
**双轨分诊机制**：分诊台就是第一次显影本身——接受并休息＝滞留者（低频复测轨道）；接受并发痒＝迁移者（容器轨道）。不问问卷，让第一反应做分诊；误判可逆。
### 7.4 统一产物层：笔记组（融合点）
不在管线层融合（代价高、语义混），不做物理隔离（客群重叠、漏斗相连）——**在产物层融合：一切采集产物归入"笔记组"，组是唯一容器，两种来源只是组的两种形成方式**。
```
结构密度高 → 自成一组（无论长短）
结构密度低 → 归入主题组（按 DomainTag 领域粒度）
```
**组的三条设计契约**：
- **契约一：分组粒度对齐领域，拒绝大类。**"人生成长"式的大类会把化妆/编程/乐理装进一个组，退化为杂物抽屉。判据：**一个组能否回答"关于X，我学到了什么"——答不上来的粒度就是太粗。**支持 DomainTag 自动归组 + 用户自建主题组。
- **契约二：组是学习单元，不是档案盒。**这是融合成败的分叉点：**闪卡/复习的绑定粒度提升到"组"**——组内碎片生成闪卡、主题自测、进度对账；短视频碎片也能被间隔复习、被主题测试。两种来源共享同一学习循环，才是真正融合。
- **契约三：组有结算机制（防沼泽）。**短视频组天然膨胀。组内碎片达到阈值或周期时触发对账：提炼核心概念、合并重复碎片、归档低价值项（"换季结算"设计资产的组级实现，时钟从"季"缩短为"组阈值/周期"）。
**融合后的残留差异**仅剩一处，且对用户心智不可见：**容器管线是实时提取（流式 ASR/OCR），feed 管线是导入式批处理**。产物形态、学习循环、界面语义全部统一。
### 7.5 三层界面架构（按钟分域）
把三层混进每日视图是所有学习产品的通病——低谷期用户打开应用＝打开自己的羞耻陈列馆。
| 层 | 时钟 | 内容 | 原则 |
|----|------|------|------|
| 每日视图 | 天 | 任务队列、复习、容器管线（会话面） | 小、安静、机械、办完即走，不出现任何叙事元素 |
| 周报/月报 | 周/月 | 进展叙事、产物、见证 | 回答"你变了吗"，不罗列统计 |
| 事件触发视图 | 事件 | 回归、毕业、平台期、低谷干预 | 只在事件发生时现身，平时不可见 |
v3 导航层裁决并入此架构：**容器管线出现在每日视图/会话面；feed 产物只出现在组与结算面**——防止心智污染。认知卸载（P34）的最佳实现不是某个功能，而是这个分层架构本身。
### 7.6 降级与出局名单（历史裁决）
- **降级为后台传感器/工艺**：P29情绪锚点、P28认知负荷自评（探测低谷的输入信号）；P39节律、P23睡前复习（引擎参数）；P26悬念结课（工艺技巧，撤销科学背书）。**科学原理是设计者的约束条件，不是用户界面的功能清单。**
- **出局**：P37学习风格（VAK 已证伪）· P32心流追踪（回溯性体验不可实时追踪）· P22/P45/P41（稳态精致化，瓶颈在瞬态）· P12/P24/P1（别人已做得更好）· P13知识图谱（失败发生在人没回来的地方，不在知识没连成网的地方——feed 卷以"技能地图"形式部分越狱。**2026-08-23 修订（ADR-024）**：自由双链/图谱出局不变；**有界体系**——体系树＋概念/模型库＋决策日志，引用限体系内及对证据的单向引用——**通过**，作为 L2 飞轮层"体系枝"（为什么学→怎么用→审计），不承担增长机制、无内容收纳权、不做图可视化）。

## 第九部分：护城河（统一）
**传统壁垒全部否定**：科学密度（Google Scholar 人人可查可抄）、数据闭环（可抄）、功能（更可抄）。
**真正的壁垒：指标异端**——
1. **骨折层是无主之地**：失联用户不产生DAU、不产生收入、在增长会议上根本不存在。靠连续打卡驱动的公司无法诚实地发布"无羞耻回归"设计，那等于自断现金牛。**竞品要抄回归之门，得先放弃自己的北极星。护城河不是功能，是一个组织敢用什么考核自己。**
2. **feed 版指标异端**：本产品的成功＝用户地形迁移（离开 feed 进入容器）＝平台的流失。feed 原生产品结构上无法庆祝这件事。年度报告（"你听了999小时"）就是安慰剂显影——**它计数，从不测量**。其病毒式传播证明学习结算的需求真实、巨大、已被市场用安慰剂版本验证；平台结构性无法升级到测量版（测量带来坏消息伤时长、打断消费、奉承最大化）。
3. **常模资产**：业余能力常模全球无人拥有，先动者独占累积（ETS 之于 SAT）。
4. **创作者作业生态**（若成立）：供给侧锁定。

| 版本线 | **不拆分**：同一 dev 主线、同一 SemVer、同一发布 | 同一产品、同一品牌、同一数据主权 |

| 交付层 | feed 相关能力以功能开关引入，默认关闭 | 符合项目"增强能力默认关闭"传统；Phase 2 验证前不默认启用组级循环 |
| 导航层 | 界面按钟分域（见 §7.5） | 防止心智污染 |

## 第十二部分：元理论与一句话
### 12.1 元结构同构
两卷的元结构本就同构：稳态/瞬态区分、事件驱动干预、身份指标（第二门课启动率 ≈ 下一学期回归率 ≈ 第二组启动率）、指标异端护城河。差异只在失同步方向与主时钟。**v4 的融合不消灭这个差异，只是让差异止步于管线与节奏，不再侵入产物与循环。**
同步器模型（失同步双向性）作为元理论保留：容器防叙事透支、feed 把叙事拖上来追赶能力——仍是两地形设计的依据。
### 12.2 一句话
v1 问：学习有哪些环节会失败。v2 问：学习在两种地形里各以什么方式失败。v3 裁决：两种地形如何共存。v4 的回答是：
**两种地形，一个容器——结构在内容里的成为课程，结构在行为里的成为组，都被同一个学习循环接住。**
产品不是同时做两件事，而是用两种进料方式，养同一个"我正在学会X"的叙事。

## 附录A：术语速查
| 术语 | 定义 |
|------|------|
| 稳态／瞬态 | 生命周期中可长期滞留的状态／过渡时刻 |
| 三只时钟 | 天（引擎层）、周/月（飞轮层）、事件（骨折层） |
| 骨折 | 生命周期中的断裂时刻，每根骨折断掉飞轮的特定辐条 |
| 获取隐喻／成为隐喻 | 学习=记住更多（已放弃）／学习=成为会做某事的人（采用） |
| 叙事熵／知识熵 | "我是学习者"自我叙事的衰减速率（半衰期：周）／知识的遗忘速率（半衰期：天） |
| 过桥型／成为型学习者 | 考证应试速成者（只要引擎）／技能自学者（需要完整飞轮） |
| 容器地形／feed 地形 | 学习结构住在内容里（课程/书/系统练习）／住在行为里（短视频信息流） |
| 结构承载性 | 地形边界判据；结构密度（四维解耦代理）是组路由信号 |
| 同步器／离合器 | 产品广义职责：把转速不同的能力轴与叙事轴咬合 |
| 飞轮 | 叙事→行为→能力→可见之物→叙事的耦合循环（容器地形特例展开） |
| 显影 | 让隐性能力变成可证伪证据的过程（测量，不是计数） |
| 觉察滑差 | 觉察后行为转化窗口约72小时，错过即衰减（N23） |
| 常模 | 分品类×分消费时长的能力分布基准（N25） |
| 滞留者／迁移者 | feed 双轨人群：终校准态者／转容器地形者 |
| 笔记组 | 统一产物层唯一容器；组的三种形成方式：课程组/主题组/独立组 |
## 附录B：判据速查
| 判据 | 定位 |
|------|------|
| 平台 | 适配器（PlatformAdapter），不是边界 |
