# 熵减 · AI 时代生存定位

> **状态**: 已裁决（2026-08-03，三项决策全部通过）
> **地位**: 所有产品叙事的上位文档，`docs/Foresight/` 全部立项的前置过滤器。
> **一句话**: 不做"更好的学习 AI"，做"唯一一个属于你的、记住你的、能被你的 AI 读取的学习世界"。

## 一、核心判断：功能分层，资产立命

本文是 `docs/Foresight/ai-era-competitiveness-strategy.md`（2026-07-30）的**后继与互补**：前文回答「为什么不会被淘汰」（防守分析，A/B/C 三档分级 + 三大结构性护城河），本文回答「以什么姿态进攻」（第一叙事 + 资产形态升级 + Agent 时代入口）。两文结论一致：通用 AI 吞得掉问答，吞不掉学习过程。

沿用前文分级：**C 档功能（摘要/卡生成等 prompt 包装）是耗材也是数据采集器；A/B 档（本地过程数据闭环、反效率教学法）是护城河**。本文在此基础上补充：护城河需要「形态」——数据引力必须以世界而非报表呈现，否则用户感知不到它的不可迁移性。

生存资产五类（前文三护城河 + 本文两补充），对照现状：

| 资产 | 原理 | 熵减现状 |
|------|------|---------|
| 记忆（数据引力） | 裸 AI 没有你的细粒度历史，无法复刻 | 本地 SQLite 全量过程数据，从未被当核心资产渲染 |
| 教学法（角色反转） | AI 提问、用户输出——通用 AI 不会自我阉割去做 | 苏格拉底/费曼/三级救援已落地（前文 B 档） |
| 地方（世界） | 工具可替换，地方积累意义无法迁移 | 3D 双世界已存在，尚未被当作资产经营 |
| 关系（共同记忆） | 陪伴两年的存在 vs 初次见面的聊天框 | CreatureAvatar/AI 助手存在，但无共同记忆 |
| 接口（Agent 入口） | Agent 时代，能被个人 AI 读取的软件才不被绕过 | mcpBridge/mcpManager 已存在（现为客户端方向） |

**结论**：方向不缺，缺的是让五个半成品互相认识。

## 二、第一叙事：记忆主权与本地世界（决策 1 落地）

产品对外叙事升级为：

> **「万物趋于无序，而你在此造序。这个世界只存在于你的机器上——
> 它记得你的每一次深潜，断网依然生长，永远属于你。」**

- **记忆主权**：你的全部求知史保存在本地，你是唯一的所有者（本地优先从工程原则升格为品牌承诺）。
- **本地世界**：学习数据不是报表，是一个持续生长的世界；用得越久，越舍不得迁移。
- AI 的角色从"服务者"改写为"记忆的仆人"：它因读过你的历史而不同，而非因模型更强而不同。

落地触点（分期）：官网首屏、开机仪式文案（接 StartupRitual）、首潜创世时刻（接 First Dive）、关于页。

## 四、Foresight 立项过滤器（决策 3 落地）

自本文档生效起，任何进入立项评审的 Foresight 提案必须书面回答三问，任一为否则拒绝：

1. **资产问**：它沉淀为地方/记忆/关系/接口中的哪一种资产？（纯功能增强不予立项）
2. **复刻问**：裸大模型 + 一句 prompt 能复刻它几成？（≥8 成不予立项）
3. **主权问**：它是否要求用户数据离开本地或引入外部依赖？（是则需单独安全裁决）

## 六、风险备忘

1. 世界化若无工具性支撑会滑向"游戏化壳子"——功能骨架（效率面）永远保留双轨制。
2. 本地优先放弃网络效应，获客只能靠可转述性与口碑，外层审美纪律因此是生死线。
3. MCP 开放接口必须默认关闭、本地 stdio only、只读先行（详见草案安全章节）。
