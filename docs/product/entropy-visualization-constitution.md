> **上位文档**: `docs/product/ai-era-survival-positioning.md`（本宪法是其外层防御的落地规范）
> **地位**: 熵减产品的最高视觉与体验宪法。与 `ui-ux-system.md`（执行层规范）的关系：本文定「为什么与是什么」，ui-ux-system 定「怎么做」。冲突时以本文为准。
> **核心命题**: 形式即概念——热力学第二定律是本产品唯一的视觉主角。

## 第〇条 · 单一范式纪律

1. 本产品在同一时期只奉行**一个**叙事范式：「万物趋于无序，而你在此造序」。
2. **已落地现状勘误**：留存引擎并非愿景而是存量——珊瑚生态/连击气泡/深海发现/学习画像/深度计 5 大组件已随 v0.34.0 上线 Dashboard（`features/retention/`）；启动仪式重塑已立项 v0.26.0。Foresight 中**其余**未立项愿景冻结为参考资料，不得并行立项，直至本范式 P1 验收通过。
3. 任何新增视觉提案必须先回答：它映射哪个学习变量？映射不了的，一律拒绝（见第二条）。
4. 本宪法的留存机制依据：`docs/knowledge/learning-mechanisms-analysis.md` 第四章（即时反馈 > 可变奖励 > 身份认同 > 损失规避，自主感为底线）。

## 第一条 · 核心映射表（唯一性约束）

场景中每个视觉元素必须映射且只映射一个学习变量。此表是设计评审的一票否决工具。

| 学习变量 | 深海世界（dark） | 穹顶世界（light） | 说明 |
|---------|-----------------|------------------|------|
| 概念掌握度 | 发光体的亮度与清澈度 | 星体亮度 | 牢固=清冽明亮；薄弱=朦胧 |
| 遗忘（熵增） | 混沌雾（缓慢渗透的半透明噪雾） | 星云尘埃遮蔽 | **可见但不刺眼**，见第四条防线 |
| 复习行为 | 秩序波纹（从操作点扩散的光圈） | 星风吹散尘埃 | 每次复习的即时正反馈 |
| 累计专注时长 | 珊瑚/海床地形高度 | 星座连线的密度 | 地质层——变化慢而厚重 |
| 今日状态 | 海面光色与洋流速度 | 晨光角度与云层 | 实时层——每次打开都不同 |
| 灵感数 | 萤火数量 | 流星余迹数量 | 微小、闪烁、可收集 |
| 待复习优先级 | 雾的浓度排序 | 尘埃厚度排序 | **取代红点与数字角标** |
| 概念关联 | 洋流线连接 | 星座连线 | 知识图谱的空间化 |

**禁止项**：任何无映射的纯装饰动画；任何直接展示"遗忘数量/衰退百分比"的数字。

---

## 第二条 · 焦虑防线（觉察原则的硬边界）

遗忘可视化天然滑向焦虑制造。以下边界为**硬约束**，任何实现违反即视为缺陷：

1. **雾永远朦胧可拨开**：混沌雾的最大不透明度 ≤ 40%，被遮蔽的元素始终可见轮廓——"它在等你"，不是"它没了"。
2. **零负向语言**：不出现"已遗忘/衰退/过期/落后"等词。待复习区域的文案范式："朦胧的知识，等待一次唤醒"。
3. **零倒计时与零赤字**：界面任何位置不展示"距遗忘还有 X 天"类倒计时；不使用红色表达知识状态。
4. **无他人参照**：永不展示与其他用户的比较（远期"远方光点"功能仅存在性提示，无量级）。
5. **可关闭性**：混沌雾渲染提供全局开关（设置项），关闭后世界退化为纯净亮度映射。觉察是镜子，用户有权移开视线。
6. **回归奖赏**：久别返回时，世界的第一反馈永远是"欢迎回来"性质的（洋流变暖、一颗星主动亮起），禁止任何形式的冷遇。

## 第三条 · 签名时刻脚本（全产品唯一一级时刻）

**挂载点**：掌握一个概念（费曼评估通过 / 卡片标记「牢固」）。依据：learning-mechanisms-analysis §4.1 将「即时反馈缺口」列为最高优先级——深潜/费曼/闪卡完成时均缺乏可视化正反馈。

**三幕结构**（总时长 ≤ 10s）：
- **第一幕 · 静默（1-2s）**：环境音淡出，场景光照聚焦于操作点，世界为之安静。
- **第二幕 · 事件（4-6s）**：一颗星亮起（穹顶）/ 一簇珊瑚绽放发光（深海），秩序波纹扩散，与邻近知识连出新的线段。
- **第三幕 · 余韵（2s）**：动画结束，但**痕迹永久保留**在场景中。下次打开应用，这一刻的证据仍在。

**约束**：
1. **可变重奏**：同一成就不重播同一演出（3 套以上变体随机），对抗多巴胺适应。
2. **可打断**：Esc / 任意操作立即终止演出，直达结果状态。
3. **reduced-motion**：提供静帧版（星直接亮起 + 一次柔和闪烁）。
4. **声音占一半**：专属单音音效（候选：声呐泛音/单音钢琴），与现有音效库风格统一（见第六条）。
5. **首潜加长版**：First Dive 完成时播放「创世版」——世界从混沌中点亮第一颗星，onboarding 即创世（见第七条）。

## 第四条 · 性能预算（三级降级表）

基座现实：3D 层刚偿还过稳定性债务（frameloop 冻结、相机飞行、计时停摆），且目标用户含大量学生笔记本（核显/集显）。**先有预算，再有特效。**

| 资源 | high（澎湃） | medium（从容） | low（静谧） |
|------|------------|--------------|------------|
| 混沌雾 | Shader 体积雾 | 2 层径向渐变叠加 | 静态纹理 |
| 秩序波纹 | 全屏后处理涟漪 | CSS/SVG 圆环动画 | 一次透明度闪烁 |
| 粒子（萤火/星尘） | ≤ 1500 | ≤ 500 | ≤ 100（静态） |
| 星座连线 | 发光 shader 线 | LineBasicMaterial | 直连细线 |
| 知识星座（阶段 B） | 3D 轨（R3F 星节点+连线）节点 ≤150 / 连线 ≤300，独立 Canvas，dpr≤1.5 | DOM/SVG 轨（L1 每档 ≤15 节点） | 不渲染（保留冷启动引导文字） |
| 知识星座（阶段 B） | 3D 轨（R3F 星节点 + 连线）节点 ≤150 / 连线 ≤300，独立 Canvas，dpr≤1.5 | DOM/SVG 轨（L1 每档 ≤15 节点，SVG line/circle） | 不渲染（保留冷启动文字说明） |
| 签名时刻后处理 | Bloom+DoF | 仅 Bloom | 关闭，亮度补偿 |

1. 任何新增 GPU 元素必须先在此表登记预算并修改本条，方可实现。
2. low 档**不删视觉语义**（雾仍在、星仍亮），只降精度——与既有降级哲学一致。知识星座例外：low 档不渲染节点/连线（避免核显 SVG 卡顿），仅保留「世界未点亮」文字与冷启动引导。
3. frameloop 冻结教训：所有新增动画必须验证 `never → always` 切换路径（LoopResumer 机制）。知识星座 3D 轨为独立 Canvas，不受全局 frameloop 影响；朦胧节点雾色滤镜视觉强度 ≤40%（第二条 §1：雾永远可拨开）。

## 第五条 · 排印与构图（叙事面规范）

1. **跳率 ≥ 4x**：叙事面字号体系为 64-96px 衬线大字 + 10-12px 注文，取消中间档。
2. **文字即场景**：大字直接悬浮于 3D 空间（电影字幕式），不进面板。
3. **留白纪律**：叙事面内容占屏 ≤ 40%。
4. **东方签名**：竖排注文 + 印章式标记（如「潜」字圆章）为品牌专属元素，仅出现于叙事面。
5. **双轨制**：功能面（设置/卡管理/列表）不适用本节，保持效率密度，共享色彩令牌。

## 第七条 · 冷启动与空状态

1. 新用户的世界是**未点亮的混沌**（非空白）——雾中隐约有待亮的轮廓，暗示可能性。
2. 第一次学习动作即创世（第一颗星/第一株珊瑚），由 First Dive 保证当天发生。
3. 零数据界面禁止出现空洞感：用叙事文案填充（"这片海还没有名字，从今天的第一次深潜开始"）。

---

## 第八条 · 验收标准

1. **陌生人测试**：未接触过产品的测试者看首页截图，第一反应描述为"风景/世界"而非"面板/工具"。
2. **装裱测试**：叙事面任意一屏去掉所有交互元素后仍可独立成立为画面。
3. **焦虑审计**：按第二条逐项走查，任何违反即阻断发版。
4. **低配测试**：核显设备上 medium 档帧率 ≥ 45fps，low 档 ≥ 30fps。
5. **转述测试**：内测用户能自发用一句话复述签名时刻。

## 第十条 · 叙事层叠加（A+B/C/D 落地条款）

单范式是骨架（A：熵可视化）；以下三个叙事层允许作为血肉叠加，但每层的一切元素必须先过第一条映射表与第二条焦虑防线。

| 叙事层 | 机制 | 映射挂点 | 排期 |
|--------|------|---------|------|
| **C 潮汐节律** | 实时层的投递机制：专注活跃期=涨潮（世界收拢变深）；复习候选以「退潮冲上岸的贝壳」形态出现，取代传统提醒推送 | 「今日状态」行 + review_candidates | **P1**（低成本，优先纳入） |
| **D 沉积层与钻探** | 深海模式累计变量呈现：专注史沉积为地层（最早学的在最深处）；复习流程=「钻探取芯」抵达特定地层 | 「累计专注」行（珊瑚地质层扩展为地层）；复习入口 | P1 深海先行 / P2 全量 |
| **B 纪录片旁白** | 关系层声音：日终/启动仪式时 AI 生成第二人称自然纪录片腔旁白（「今天，你下潜了 47 分钟……」） | StartupRitual 接线点 + 日终摘要 | **P2**（先纯文案内测，AI 味重则废） |

**叠加纪律：**

1. 三层不得新增任何「视觉主角」——主角永远只有熵：潮汐是它的呼吸，地层是它的记录，旁白是它的观察者。
2. B 层是唯一有内容风险的层（AI 文案质量）：P2 先跑纯文案内测，通过「可转述测试」后才允许进入世界；否则永久封存。
3. 立项过滤器自查：三层均以用户过程数据为输入（记忆资产）、裸 LLM 无数据不可复刻、全部本地实现——三问通过。
4. 潮汐与沉积层的动效预算必须先登记第四条性能表方可实现。
