# v0.14 子项目 B：视觉系统设计规格（四级颜色）

> 状态：✅ 已批准（2026-08-28，逐节确认）
> 所属版本：v0.14
> 范围：子项目 B（视觉系统）——四级颜色 / 正文荧光笔；Word 对齐由用户裁决跳过

## 1. 背景与目标

### 1.1 痛点（用户反馈，2026-08-27）

| # | 痛点 | 现状根因 |
|---|------|----------|
| B1 | 笔记没有颜色能力 | `Note.properties` JSON 字段存在但无颜色使用；标签/组/正文均无色彩表达 |
| B2 | 正文重点无标记手段 | 阅读视图无荧光笔；编辑无 `==文本==` 语法 |

### 1.2 目标

1. **四级颜色体系**：笔记级 / 标签级 / 组级 / 正文级，覆盖从"分类识别"到"重点标记"的全链路色彩表达
2. **单色荧光笔**：Obsidian 式 `==文本==` 正文高亮（黄色），零自研解析（现成 remark 插件）
3. **双主题安全**：固定 12 色语义色板，浅/深主题下均可读
4. **渲染优先级明确**：笔记显式 > 组色继承 > 标签色 > 默认灰

## 3. 架构设计

### 3.1 四级颜色数据流

```
┌─ 笔记级：Note.properties.color（显式覆盖，最高优先级）
├─ 组级：note_groups 表加 color 列（继承色——笔记未显式定义时用组色）
├─ 标签级：tag_colors 新表（tag_id → color）（组色未命中时用标签色）
└─ 正文级：==文本== 荧光笔（Markdown 语法，渲染层处理，与数据层无关）

渲染优先级：笔记显式 > 组色继承 > 标签色 > 默认灰
```

## 4. 详细设计

### 4.1 12 色语义色板（双主题安全）

固定 12 色，每色定义浅/深主题两个可读变体（CSS 变量，`--color-note-N-light/dark`）：

| 色 | 语义 | 浅主题 | 深主题 |
|---|---|---|---|
| 红 | 重要/紧急 | #E5484D | #FF6369 |
| 橙 | 行动/待办 | #F76B15 | #FF8B3D |
| 黄 | 注意/高亮 | #F5D90A | #FFE45C |
| 绿 | 完成/正确 | #30A46C | #3DD68C |
| 青 | 信息 | #12A594 | #29E0CB |
| 蓝 | 常规 | #0091FF | #5EB1FF |
| 紫 | 深度/概念 | #8E4EC6 | #C59BFF |
| 粉 | 情感/创意 | #D6409F | #FF8AD8 |
| 棕 | 背景/语境 | #8D6E63 | #B89B8A |
| 灰 | 默认/中性 | #8E8E93 | #9E9EA3 |
| 黑 | 强调（仅浅主题语义）| #1C1C1E | #F2F2F7（反转）|
| 白 | 留白（仅深主题语义）| #FFFFFF | #1C1C1E（反转）|

校验纯函数 `isThemeSafe(colorId, theme)`：计算前景/背景对比度 ≥ 4.5:1（WCAG AA），不达标配色在定义期拦截。

### 4.2 四级颜色落点

**笔记级**：`Note.properties.color: string`（色板 id），笔记卡/标题栏色条；显式设置后覆盖组色。

**组级**：`note_groups.color` 列（色板 id），组侧栏色点 + 组内笔记未显式定义时的继承色。

**标签级**：`tag_colors` 表（`tag_id INTEGER PRIMARY KEY, color TEXT`），标签徽标底色；组色未命中时的次选。

**正文级**：`==文本==` → `<mark>` 渲染（黄色，CSS 变量控制深浅主题），编辑/阅读双向一致。

### 4.3 渲染优先级实现

```ts
resolveNoteColor(note, group, tags): ColorId | null {
  if (note.properties?.color) return note.properties.color;   // 笔记显式
  if (group?.color) return group.color;                        // 组继承
  const tagColor = tags.find(t => tagColors[t.id]);            // 标签
  return tagColor ?? null;                                     // 默认灰（null）
}
```

纯函数，可单测；卡片/列表/侧栏统一调用。

## 5. 错误处理

- **未知色板 id**（数据损坏/旧版本）：回退默认灰，不崩溃
- **标签删除**：级联清理 tag_colors 行（外键 ON DELETE CASCADE）
- **对比度不达标**：定义期校验拦截（开发期测试失败），运行期不校验

## 6. 测试计划

| 层 | 用例 |
|---|---|
| 纯函数 | `isThemeSafe` 全 12 色 × 双主题对比度 ≥ 4.5:1；`resolveNoteColor` 四档优先级（显式/继承/标签/默认）|
| 命令 | tag_colors set/reset/list 往返；未知色回退 |
| 组件 | 颜色选择器选中态；==文本== 渲染为 `<mark>`；双主题截图对比 |
| 回归 | 无颜色数据时全链路显示默认灰（零崩溃）|

## 7. 范围外

- Word 对齐（用户裁决跳过）
- 多色正文高亮（伪需求否决）
- 颜色自定义（固定色板，不开放 hex 输入）

## 8. 决策记录

| 决策 | 结论 | 理由 |
|---|---|---|
| 高亮语法 | `==文本==` 单色黄 | Obsidian 心智、remark 现成插件、多色是伪需求 |
| 色板 | 固定 12 色语义 + 双主题变体 | 一致性 + 可读性，拒绝自由取色 |
| Word 对齐 | 跳过 | 用户裁决（2026-08-28）|
| 存储 | properties.color（笔记）/ 列（组）/ 新表（标签）| 最小侵入，无新表结构风险（仅 tag_colors）|
