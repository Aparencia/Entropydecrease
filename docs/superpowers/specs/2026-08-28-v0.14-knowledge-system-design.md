# v0.14 子项目 C：知识体系架构设计规格（Obsidian 对齐 + 深度联动）

> 状态：✅ 已批准（2026-08-28，逐节确认）
> 所属版本：v0.14
> 范围：子项目 C——C1 组侧栏 Obsidian 式改造 / C2 多关系分层图谱 / C3 深度联动 v2

## 1. 背景与目标

### 1.1 痛点（用户反馈，2026-08-27~28）

| # | 痛点 | 现状根因 |
|---|------|----------|
| C1 | 分组分类方式有问题（确认：**展示混乱**）| `GroupSidebar` 240px 平铺无分区，行内堆叠 5 类信息（类别/feed/体系/路由/ⓘ），快速记录/收件箱/全部笔记/复习 5 种职责混排 |
| C2 | 知识体系对齐 Obsidian（选定：图谱视图）| 现有画布为知识体系内部视图，无"笔记 ↔ 体系"关系图谱 |
| C3 | 笔记挂体系后体系页不显示（**使用体验断裂**）| NoteLinkToSystem 只支持挂 node；体系页按 entityType 过滤，挂载实体与查看实体不一致时引用"消失" |

### 1.2 目标

1. 组侧栏 **Obsidian 式**：按 kind 分区 + 折叠记忆 + 过滤 + 拖拽归组 + 最近使用
2. 图谱 **A' 多关系分层**：🔗 引用 / 🧬 溯源 / 📁 归属三类边可开关图层，局部聚焦，避免毛线球
3. 深度联动 **v2 体验闭环**：挂接即见、跨页即时同步、反查聚合

## 2. 方案选型记录

### 2.1 组侧栏：Obsidian 式（已裁决）

| 变体 | 结论 |
|---|---|
| 纯分区（按 kind 分组展示）| 中间态——只解决"混排"，未解决"找组慢" |
| **分区 + 过滤 + 拖拽 + 最近使用** | ✅ 采纳——Obsidian 心智：文件树分区、折叠记忆、拖拽移动、最近文件 |

三条设计契约（v0.11 系列延续）：**粒度对齐 DomainTag 拒绝大类聚合；组是学习单元；组结算防沼泽（禁止父子组）**——分区是展示层组织，不改变组模型。

### 2.2 图谱：A' 多关系分层（已裁决）

| 变体 | 结论 |
|---|---|
| A. Obsidian 同款全库图谱 | 毛线球风险——全库节点 + 单类型边必然乱 |
| **A'. 多关系分层图谱** | ✅ 采纳——React Flow（已有依赖）实现，三类边分图层可开关，默认只开引用层 |
| B. 体系内图谱 | 否决——覆盖不了"笔记 ↔ 体系"跨层关系 |

### 2.3 深度联动：v2 体验闭环（已裁决，用户澄清"不是性能卡，是使用体验"）

初诊误判为性能问题（N 次全量拉取），用户澄清后确诊**体验断裂**：跨页操作不闭环、反馈不及时。修复目标=操作原地反馈 + 跨页即时同步 + 减少步骤。

## 3. 架构设计

### 3.1 C1 组侧栏（GroupSidebar 重构）

```
GroupSidebar（重构）
├── 最近使用区（最近 5 个访问组/笔记，点击直达）
├── 收件箱 / 全部笔记 / 复习（保留，移出"组"概念区）
├── 组分区（按 kind）：
│   ├── 课程（course）
│   ├── 主题（topic）
│   ├── 独立（standalone）
│   └── feed（feed）
├── 每个分区：折叠记忆（localStorage）+ 组行（色点/徽标收敛为 1-2 个）
├── 组过滤（关键词过滤组名）
└── 拖拽归组（拖笔记到组行 → move_note_to_group 命令）
```

### 3.2 C2 多关系分层图谱

```
知识图谱页（新/改造）
├── React Flow 画布（已有 @xyflow/react ^12.11.3）
├── 边图层开关：🔗 引用 / 🧬 溯源 / 📁 归属（默认仅引用）
├── 局部聚焦：选中节点 → 1~2 度邻居展开，其余淡出
├── 节点：笔记 / 概念 / 模型 / 组（按类型着色，用 B 子项目色板）
└── 点击节点 → 跳转笔记页/体系页
```

后端：`graph_snapshot()` 命令——聚合 note_links（引用）、session_artifacts（溯源）、note_groups（归属）三类边，单次拉取返回完整图谱数据。

### 3.3 C3 深度联动 v2

```
笔记页（NoteLinkToSystem 增强）
├── 挂接目标：node（问题）+ concept（概念）+ model（模型）三选一
├── 挂接后可切换目标（不改实体，先改链接）
└── 挂接成功原地反馈（不跳页）

体系页（KnowledgeLinkSection 增强）
├── 反查：list_links_by_target(体系, 实体) —— 挂载实体与查看实体不一致时仍显示
├── 聚合视图：该体系全部引用（按实体分组）
└── 跨页同步：refreshToken 机制（挂接/删除后体系页即时刷新）
```

## 4. 详细设计

### 4.1 C1 数据与交互

- **分区依据**：`NoteGroup.kind`（已有字段：course/topic/standalone/feed）
- **折叠记忆**：localStorage `group-sidebar-folded:{kind}`（布尔）
- **过滤**：纯函数 `filterGroups(groups, query)`（组名 contains，可单测）
- **拖拽**：HTML5 DnD（组行为 drop target，笔记卡片为 drag source）；复用 `move_note_to_group` 命令，失败 toast
- **最近使用**：`recent_groups` 表或 localStorage（访问组时写入，上限 5，LRU）

### 4.2 C2 图谱数据契约

```ts
interface GraphSnapshot {
  nodes: GraphNode[];   // { id, kind: note|concept|model|group, label, color }
  edges: GraphEdge[];   // { id, source, target, type: link|trace|belong }
}
// graph_snapshot() 返回；边类型三选一，前端按图层开关过滤
```

- **局部聚焦纯函数**：`focusSubgraph(nodes, edges, centerId, degree=2)`（可单测）
- **边图层过滤纯函数**：`filterEdges(edges, enabledLayers)`（可单测）

### 4.3 C3 命令与同步

- **新增命令**：`list_links_by_target(system_id, entity_id) -> Vec<KnowledgeLink>`（反查，现有 list_knowledge_links 是正查）
- **增强命令**：`link_knowledge_target` 扩展 entity_type 参数（node/concept/model，兼容旧值）
- **refreshToken**：挂接/删除命令成功后 `refresh_links_ts` 自增；体系页监听变化即刷新（轻量轮询或事件）

## 5. 错误处理

- 拖拽归组失败：toast 提示 + 组列表回滚（乐观更新回退）
- graph_snapshot 超时/失败：图谱页显示空态 + 重试按钮（不阻塞其他功能）
- 反查无结果：显示"无引用"空态（区别于加载失败）
- 旧版本挂接数据（仅 node）：自动兼容，UI 显示"问题"徽标

## 6. 测试计划

| 层 | 用例 |
|---|---|
| 纯函数 | `filterGroups` 关键词过滤；`focusSubgraph` 1/2 度邻居正确性；`filterEdges` 图层开关 |
| 命令 | `graph_snapshot` 三类边聚合正确；`list_links_by_target` 反查命中/空；link_knowledge_target 三实体类型兼容 |
| 组件 | 拖拽归组交互（happy path + 失败回滚）；折叠记忆持久化；图谱图层切换 |
| 联动 | 笔记挂 concept → 体系页即时可见（refreshToken 生效）；切换目标后引用更新 |

## 7. 范围外

- Obsidian 双向链接语法 `[[...]]` 全量对齐（仅保留图谱视图对齐，用户裁决）
- 图谱拖拽编辑（仅浏览/导航，编辑走体系页）
- 组模型变更（父子组等——设计契约禁止）

## 8. 决策记录

| 决策 | 结论 | 理由 |
|---|---|---|
| 组侧栏 | 分区 + 过滤 + 拖拽 + 最近使用 | Obsidian 心智；纯分区不够 |
| 图谱 | A' 多关系分层（三类边图层）| 避免毛线球；覆盖跨层关系 |
| Obsidian 对齐范围 | 仅图谱视图 | 用户裁决（2026-08-28）|
| 联动修复 | 体验闭环（反查 + 聚合 + refreshToken）| 用户澄清：非性能问题，是体验断裂 |
| 图谱后端 | graph_snapshot() 单次聚合 | 避免 N 次全量拉取（初诊根因）|
