# v0.14 子项目 A：编辑器基础体验改造设计规格（CodeMirror 6）

> 状态：✅ 已批准（2026-08-27，7 节逐节确认）
> 所属版本：v0.14
> 范围：子项目 A（编辑器基础体验）——图片可视 / H2-H3 / 撤销；B/C/D 另设 spec

## 1. 背景与目标

### 1.1 痛点（用户反馈，2026-08-27）

| # | 痛点 | 现状根因 |
|---|------|----------|
| A1 | 编辑状态下图片位置不可视 | `NoteEditView` 用纯 textarea，`![alt](path)` 以源码文本呈现 |
| A2 | H2/H3 添加有问题 | textarea 失焦/滚动后光标重定位靠 `scrollTop` 比例估算（v0.13.9 hack），选区不权威；且无即时视觉反馈 |
| A3 | 没有撤销能力 | 无 Ctrl+Z；版本链只在显式保存建快照，粒度不解决编辑中误操作 |

### 1.2 目标

1. 编辑状态图片**内联可视**（可点击放大，复用阅读视图 `NoteImage`）
2. H2/H3 **输入即生效**（`## ` 自然输入 + 语法高亮 + 折叠 + 快捷键 + 按钮态同步）
3. 编辑会话内 **Ctrl+Z / Ctrl+Y 全量撤销**（含工具栏操作）
4. **崩溃不丢字**：自动保存 + localStorage 草稿恢复层
5. **存储格式零变更**：`notes.content` 保持 Markdown 字符串——版本链/diff/FTS5/导出全不动

## 2. 方案选型记录

### 2.1 编辑器引擎：CodeMirror 6 取代 TipTap（已裁决）

| 维度 | TipTap（WYSIWYG） | **CodeMirror 6（增强 Markdown 源码编辑）** |
|---|---|---|
| 编辑对象 | ProseMirror 结构化文档 | Markdown 源码 |
| 存储格式 | 需 Markdown ↔ PM JSON 桥接 | **Markdown 不变** |
| 版本系统影响 | 桥接风险 | **零影响** |
| 依赖重量 | ProseMirror 全家桶 | ~200KB gzipped |
| 图片可视 | WYSIWYG | decoration widget 内联渲染 |
| 撤销 | 内建 | 内建 |

裁决理由：版本链稳定性优先，无转换风险，依赖更轻。WYSIWYG 非刚需——语法高亮 + 图片内联已覆盖核心诉求。

### 2.2 图片渲染变体：widget + React 挂载（已裁决）

| 变体 | 结论 |
|---|---|
| A. widget + React createRoot 挂载 NoteImage | ✅ 采纳——保留点击放大，`destroy()` 统一清理 root 防泄漏 |
| B. widget + 原生 `<img>` | 备选——无放大，实现更简单 |
| C. 语法高亮 + hover 预览 | 否决——编辑区不可见本体 |

### 2.3 标题方案：输入驱动 + 工具栏辅助（已裁决）

输入 `# `/`## `/`### ` 即生效（语法高亮 + 折叠箭头即时反馈），工具栏按钮降级为补充通道，快捷键 Ctrl+1/2/3 对齐 Obsidian 习惯。

### 2.4 保存方案：双计时器 + 草稿恢复层（已裁决）

自动保存（idle 2s / maxWait 30s，与现有一致）之上增加 localStorage 草稿层：崩溃/强杀后重开可恢复零丢失。

## 4. 详细设计

### 4.1 图片内联渲染（A1）

**机制**：`ViewPlugin.fromClass` 扫描 doc，用 `Decoration.replace(from, to, { widget })` 将 `![alt](src)` 替换为真实图片。

- 支持行内与独立行两种形态；嵌套括号 URL 正确处理；非图片链接不误匹配
- `NoteImageWidget.toDOM()` 返回容器 → `createRoot(container).render(<NoteImage …>)`
- **destroy() 必须 `root.unmount()`**——防 React root 泄漏（CM 滚动/重绘重建 widget 时反复挂载）
- 图片加载失败 / 路径解析失败 → 灰底占位 + 原语法文本（不吞语法，可点击定位编辑）
- `ignoreEvent` 返回 true（点击不进入编辑）；删除 = 选中 widget 按 Delete（CM 原生支持）
- `loading="lazy"` 惰性加载；仅 `docChanged` 时重算 decorations
- `resolveNoteImageSrc` 从 `NoteImage` 提取为共享纯函数——编辑/阅读同一解析逻辑

### 4.2 撤销/重做（A3）

- CM 内建 history（`@codemirror/commands`）：Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z
- 撤销栈为**编辑会话内内存态**：切换笔记/退出编辑即清空
- 自动保存只读 `doc.toString()` 不产生 transaction——与 history 无干扰
- 工具栏操作（标题/图片等）经 `view.dispatch` 产生 transaction → **天然进撤销栈**（textarea 版做不到）

### 4.3 H2/H3 标题（A2）

- 输入驱动：行首 `# `、`## `、`### ` 即时高亮 + 折叠箭头（lang-markdown 自带）
- `headingCommand(level): Command`——工具栏/快捷键共用；单行/多行选区逐行转换，已是标题的行跳过，光标落末行标记后
- **不复用 `markdownEdit.ts` 的 `headingLines`**（字符串+offset 模型）——改用 CM 原生 `Text.lines` + `lineAt(pos)`，原生支持 CRLF 边界；`markdownEdit.ts` 保留（textarea 降级路径仍消费）
- 快捷键：Ctrl+1/2/3 设置级别；Ctrl+Shift+↑↓ 层级升降（CM 选区语义，天然精确）
- 折叠：`foldGutter` + 标题折叠，长图文笔记可折叠到只看标题
- 工具栏按钮显示当前行标题级别高亮态（UI 反馈）

### 4.4 保存与草稿恢复（A5）

**自动保存**（保留现有机制，改驱动源）：

```
updateListener（每次 transaction）
  ↓ doc.toString() 与快照比较
  ↓ 有变化 → dirty=true → 重启双计时器（idle 2s debounce / maxWait 30s）
  ↓ 到点 → invoke("update_note", { id, title, content, createVersion: false })
```

**草稿恢复层**（新增）：

```
每次 doc 变化（节流 1s）
  ↓ localStorage["note-draft:{noteId}"] = { title, content, updatedAt }

保存成功 / 正常退出编辑 → 清除草稿

下次打开同一笔记（编辑模式挂载时）
  ↓ 存在草稿 && 草稿.updatedAt > DB.updatedAt
  ↓ 提示"检测到未保存的编辑草稿，是否恢复？" → [恢复] [丢弃]
```

- title 与 content 统一为一个 dirty 标记（任一变化触发），保存时合并调用
- 草稿损坏（JSON parse 失败）→ 丢弃 + status 提示，不阻塞编辑
- 草稿与版本链正交——恢复后走正常保存，不污染版本历史

### 4.5 降级护栏

```
RichEditorView
  ├── try 挂载 CodeMirror → 成功 → 富编辑（图片/高亮/撤销/折叠）
  └── catch → setFallback(true) → 渲染原 NoteEditView（textarea 全功能保留）
```

编辑器是核心资产，绝不因渲染层失败而不可用（与"AI 能力本地兜底"同构）。

### 4.6 退出编辑竞态防护（延续 v0.13.6 教训）

ESC/完成/Ctrl+E 三出口：先 `await` 读取 doc + 落库，再刷新列表——避免"读旧值"竞态重演。

## 5. 错误处理与降级

| 失败场景 | 处理策略 | 出口 |
|---|---|---|
| 图片路径解析失败 | 灰底占位 + 原语法文本（不吞语法） | 编辑区可见、可修复 |
| 图片加载失败 | 同左，"图片加载失败"占位 | 编辑区可见 |
| `update_note` 保存失败 | status 展示；草稿层已兜底；不卡编辑态 | 状态栏 + 下次打开可恢复 |
| 草稿 localStorage 损坏 | 丢弃 + status 提示，不阻塞 | 状态栏 |
| CM 初始化失败（极端） | 降级 textarea（NoteEditView 保底） | 编辑可用性不丢 |
| `import_note_image` 失败 | 沿用现有：status 提示，不落脏数据 | 状态栏 |

## 8. 决策记录

| 决策 | 结论 | 理由 |
|---|---|---|
| 编辑器引擎 | CodeMirror 6 | 存储零变更、版本链零风险、依赖轻 |
| 图片渲染 | widget + React 挂载 | 保留点击放大；destroy 清理防泄漏 |
| 标题交互 | 输入驱动 + 辅助 | 符合 Markdown 心智，折叠获导航质变 |
| 保存 | 双计时器 + 草稿层 | 崩溃零丢失，与本地优先一致 |
| 降级 | CM 失败回退 textarea | 编辑永不失效 |
