## 1. 背景与目标

宣传方案识别出官网转化断点：宣传内容（小红书/B站）把用户带到官网，但官网无深潜详情、无 Chronos 视觉演示，用户看不到"时间生物"本身，信任与欲望均无法建立。

**本次目标**：建立可扩展的官网功能页体系，以「深潜（/features/dive）」为首个实例交付，同步修复下载页 UX 缺陷，为后续 5 大功能页铺好模板。

**核心原则**：完整性（一次体系设计而非单页补丁）、系统性（模板复用 + 内容配置化）、以用户为核心（用户旅程倒推页面结构）。

### 4.2 可玩 Chronos 演示（ChronosDemo.tsx）— 页面灵魂

- **默认沉睡态**：暗红余烬脉动，浮层提示「点它两下，感受它苏醒」
- **点第一下** → 呼吸（60bpm 心跳红光）；**点第二下** → 专注（粒子随倒计时消散 + 色温渐变）
- **「看它的一生」按钮**：自动快进六态循环（每态 3-5 秒）：沉睡→呼吸→专注→短休→长休→划时代点
- **点击下方六态卡片** → 中央演示直接切换对应形态
- 与产品内两步式交互（沉睡→呼吸→专注）完全同构，是下载前的"养育"预演

**技术要点**：
- 自研轻量 Canvas 2D 粒子引擎（~300 粒子），独立实现于 `components/dive/`，**不引 three.js**（保首屏）
- 六态参数化状态机：颜色 / 运动模式 / 消散比例 / 粒子数（复用客户端"伪3D"思路：球面分布+透视投影）
- `prefers-reduced-motion` → 静态渐变球（无障碍降级）
- 纯客户端组件，兼容 `output: "export"` 静态导出
- SEO：title「深潜 · 会呼吸的番茄钟」，meta 含"番茄钟/专注/学习"关键词

## 8. 下载页首屏 CTA 修复（用户反馈缺陷）

**现状问题**：标题区占首屏 → Mockup → 下载 CTA 在第三屏；用户打开页面第一眼看不到下载按钮，且无任何滚动提示。

**修复方案**：
- **重排布局**：标题区 → **下载 CTA 上移首屏** → 应用 Mockup → 版本轨迹 → 开源信息
- **加滚动提示**：首屏底部加缓慢下移的「向下滚动」引导（globals.css 新增 `scroll-hint` 关键帧，复用现有动画体系）
