## 1. 一句话总览

> **一节课只有 4 站：提取（课堂助手）→ 沉淀（笔记）→ 派送（cut）→ 使用（各卡片区）。笔记是唯一重工作台；cut 是把笔记内容"提炼派送"到各使用区的枢纽；记忆不是第 9 类标签，而是叠加在部分内容上的加工程序。**

- **内容居所判定**：依赖上下文的内容留在笔记；执行件拆去执行台；复用件派入体系；反应速度资产进记忆池。
- **联动语义**：cut = 单向派生 + 回链（不是剪切搬家、不是双向同步）。
- **人机分工**：用户发起并拍板（认知动作本身是内化），机器预判去向并起草（分类负担趋零）。
- **对照共享对话的修订**：共享对话主张"物理拆包 + 原文删除"；本项目因**证据链承诺**（每段可回溯原始来源）改为"派生副本 + 原文折叠引用行"——封箱 = 折叠，不是焚毁。

## 2. 内容八类图谱（外部输入提炼）

八类按**认知加工深度**递进，回答：是什么 → 为什么 → 怎么做 → 背后规律 → 我想到什么 → 我要做什么；SE/AI 属感性存在层，不参与认知加工。

### 2.1 八类定义表

| 代号 | 类别 | 回答 | 特征 | 课堂示例 | 使用时机 | 后处理动作 |
|---|---|---|---|---|---|---|
| **W** | 事实/数据 | 是什么 | 名词、年份、数字、定义 | 「粉底液氧化后颜色变深」 | 只检索不复习（搜） | 关键词加粗+标签，入库备查 |
| **Y** | 因果/逻辑 | 为什么 | 因果链、推导、机制 | 「油脂接触空气氧化→色号加深→试色要等 5 分钟」 | 卡壳/推不下去时翻 | 强制转译成自己的话，扔掉原文 |
| **H** | 程序/操作 | 怎么做 | 步骤、流程、话术 | 「1 保湿 2 控油 3 分区上粉 4 定妆」 | 动手执行前看 | 改成可勾选 SOP，标注关键失败点 |
| **M** | 原则/模型 | 规律 | 普适判断基准 | 「选型要在真实使用环境测试，而非展示环境」 | 遇冲突/意外时照镜子 | 绑定一个真实案例/反例，半年瘦身 |
| **Me** | 个人洞见 | 我想到什么 | 质疑、联想、批注 | 「补色原理是不是也能解释我穿搭总出错？」 | 输出/创作前翻 | 转化为问句，入问题清单 |
| **Act** | 行动/待办 | 我要做什么 | 下一步动作、时间钉子 | 「周五前把腮红手法拍成对比视频」 | 不看笔记看待办 | 物理迁出笔记系统，设截止时间 |
| **SE** | 状态/情绪流 | — | 纯情绪、意识流 | 深夜焦虑小作文 | 写完即封，半年只看标题 | 心理体检式浏览，阅后即清 |
| **AI** | 审美/灵感种子 | — | 纯审美、氛围、触动 | 「落日像融化的铜汁」 | 创作前随机偶遇 30 秒 | 氛围标签（#冷冽感），禁止逻辑标签 |

### 2.2 边界判据（Y 最难，单列）

- **W vs Y**：W 是结论本身，Y 是结论为什么成立（定义 → W；推导 → Y）。
- **Y vs H**：H 是怎么做，Y 是为什么这么做有效。
- **Y vs M**：Y 是单例因果（只解释眼前这件事），M 是普适规律（可迁移到所有场景）。

### 2.3 书写/整理固定流程

- **书写固定顺序**（认知消化时间线）：W → Y → M → Me → Act；SE/AI 平行记录、不插入主线。此顺序是"自我编辑"路径的理想书写形态——用顺序代替打标签动作。
- **整理固定流程 = 核心处理**：拆解（含分类判定）→ 按类型转化 → 分库搬运 → 封存。

### 2.4 回顾哲学（后处理的底层逻辑）

- "翻看"本身几乎无意义，**使用场景才是触发器**：搜（W）、卡壳（Y）、动手前（H）、冲突（M）、输出前（Me）、时间线（Act）。
- 情绪/审美靠"碰"和"感"（代谢/偶遇），理性内容靠"搜"和"查"。
- **记忆 ≠ 复习所有内容**：查阅型内容（延迟测试不过关）永远不值得背诵。

## 3. 三段式流水线定义

```
预处理（原料变半成品）→ 核心处理（拆+化+搬+封）→ 后处理（挂机后的使用经营）
```

### 3.1 预处理

**定义**：把原始输入变成"可进入分类与派送的最小形态"。产出三样：①干净原子内容 ②来源留痕（时间/位置/出处）③机器粗线索（候选去向提示，非最终标签）。

**两条来源（策略相反）**：

| 维度 | 外来内容（课堂捕获/剪藏） | 自我编辑（用户书写） |
|---|---|---|
| 特征 | 量大、噪声高、非本人所写 | 量小、价值密度高、写入即认知 |
| 处理策略 | 可"重"：净化（去口语/去重/分段）→ 机器切块 → 留痕 → 粗分类线索 | 必须"轻"：原样捕获 + 时间戳 + 可选模式标记（摘抄/思考/倒情绪） |
| 自动化上限 | 高（可逆、无情感成本，坏了不心疼） | 近零（热分类失真：写下即判会高估/低估自己） |
| 产物形态 | 整篇初稿 + 机器切块建议 + 粗标签 | 整篇原样笔记（不做任何处理） |
| 分类时机 | 机器即时给候选，人稍后确认 | 冷却/发酵期后（如隔日），分类权移交核心处理 |

**自我编辑内部子模式**（留待细分）：转述摘抄（靠近外来内容）vs 原创思考（纯个人资产）。

### 3.2 核心处理 = 拆 + 化 + 搬 + 封

| 动作 | 内容 | 归属 |
|---|---|---|
| ① 拆解 Cut | 把混合内容切成原子段；切的动作即分类判定的动作 | 核心处理主体 |
| ② 转化 | Y 转译成自己的话；H 改 SOP 清单（标关键失败点）；M 绑定案例/反例（无案例则该条作废）；Me 转成问句；W 只加标签；Act 不做转化直接迁出 | 核心处理（搬家前完成） |
| ③ 搬运 Move | 按去向分库：术语表/流程图库/模型卡/问题清单/待办 | 核心处理收尾 |
| ④ 封箱 Seal | 原文标记已拆解、折叠归档（本项目修订为折叠，不删除——证据链承诺） | 核心处理终点 |

### 3.3 后处理

**定义**：内容挂机（Idle）之后的一切——场景触发式回顾（搜/卡壳时翻/动手前看/冲突时查）、记忆调度（SRS）、周期检视（周复盘、季度交叉日、半年清单瘦身、SE 心理体检）、执行与清仓。

## 4. 总体架构构想（构想甲：中心工作台式）

### 4.1 分区草案（按"使用动词"组织，不按标签分区）

| 大区 | 动词 | 收什么 | 对应标签 |
|---|---|---|---|
| **提取区**：课堂助手（会话合并入内，档案=证据层） | 提 | 录制/初稿/原始证据（会话档案只读） | 预处理入口 |
| **沉淀区**：笔记（含"待整理"队列入口） | 沉 | 理解发生地：W 证据 + Y 转译 + Me 批注共生 | W/Y/Me |
| **执行台**：SOP + 待办（单区双 tab：重复流程清单 / 一次性任务时间线） | 做 | 可勾选清单与时间线钉子 | H/Act |
| **体系**：问题树/概念/模型（沿用现有） | 判 | 学习地图、判断工具箱 | M / Me-问题 |
| **记忆池**：闪卡复习（沿用现有复习面） | 练 | 反应速度资产，SRS 调度 | W-反应层/H-骨架/M-调用 |
| **灵感库**：碎片（沿用现有碎片；SE 树洞暂缓） | 碰 | 审美种子随机漫步 | AI |

**居所判定原则**：看这个标签的使用是否依赖原始上下文——依赖 → 留在笔记（W/Y/Me 与"这一课"绑定，拆出去成孤魂）；独立 → 拆出去（H/Act 是执行件、M 跨课复用、Me 问题化后进问题树）。

### 4.2 已否决方向（记录理由）

- **原子块统一仓库（构想乙）**：底层统一"块"，各分区只是视图。否决理由：与"Markdown 为本"存储冲突（有损转换，见笔记设计理念），认知与工程成本高。
- **"物流中心"命名与独立仓库型功能区**：物流隐喻与"活沉淀/结晶/发酵"产品叙事冲突（去向都是活的：模型被调用、问题被回答、卡片被复习）；且目的地现有模块已能承载，不新增功能区（遵守克制哲学：不做通用工作区）。
- **双向实时同步**：卡片独立演化（模型卡绑定案例、改写主张）会被原文反向覆盖；MVP 只做单向派生 + 回链。

### 4.3 与"体系只引用不收纳"纪律的对齐

体系收纳的是**自有实体**（问题节点/概念/模型卡，模型卡含主张/成立/失效三件套），引用的是外部内容（笔记/闪卡/碎片）。cut 派生成体系实体 = 新建实体 + 实体侧回链原文，不违背纪律；**缺口**：现有引用目标是整件（整条笔记），段落级回链需扩展（见 §8）。

## 5. Cut 派送枢纽设计

### 5.1 人机协作（手动发起 + 机器预判 + 用户盖章）

| 用户动作（认知动作=内化，不可自动化） | 机器动作（分类负担趋零） |
|---|---|
| 划选段落 / 一键提炼（或对系统预选区点头） | 去向预判（段落线索 → 去向） |
| 确认 / 改派 | 切分建议（划选区间的候选框） |
| 微调草稿后放行 | 生成草稿：卡片骨架 / SOP 初稿（按段落类型） |

### 5.2 去向预判规则（段落线索 → 去向 → 草稿形态）

| 段落线索 | 预判去向 | 草稿形态 |
|---|---|---|
| 编号列表、步骤动词 | 执行台 SOP | 可勾选清单（标注关键失败点） |
| 明确动作、时间词 | 执行台待办 | 带截止时间的时间线钉子 |
| 格言式短句、规律性表述 | 体系模型卡 | 主张/成立/失效骨架 |
| 问句、质疑、联想 | 体系问题树 | 问题节点（自答式） |
| 术语、参数、映射、序列 | 记忆池 | 卡面草稿（见 §6） |
| 触动句、氛围描写 | 灵感库 | 碎片 + 氛围标签建议 |
| 其余（含因果推导段） | 留在笔记 | 无（Y 转译提示） |

判错无害：一键改派，去向面板可撤销。

### 5.3 两条来源的 cut 形态

- **外来内容初稿 → 批量整理会话（审稿式）**：机器已在预处理期切块+粗标签，cut 呈现为整篇拆解建议清单，用户逐条过目（"这条归 SOP 对吗？那条是 Y 别拆"）、改几条、批量放行。目标：一节课初稿 ~10 分钟收完。
- **自我编辑 → 随手提炼**：用户阅读/批注时对某段落即时发起提炼，单条瞬时完成。

### 5.4 单向派生 + 回链语义（本项目对"拆包"的修订）

- cut 出去的是**派生副本**，目的地卡片独立演化（可绑定案例、改写主张）。
- 原文段落折叠成引用行：`📎 已提炼 → 模型库「…」`，点击跳转派生卡；派生卡保留到原文的证据回链。
- 长文章主体"死"了（阅读时只见可用卡片），但证据链永不破——**封箱 = 折叠**。

### 5.5 可选自动化挡位（未来）

目的地草稿态：高置信度拆解自动落成**草稿卡**（不占正式位、不参与复习/展示），用户有空进草稿区批量审——懒人全自动、勤人全手动，信任阈值自调。

### 5.6 复用面

划选/选区落点能力、段落级操作（A1）、引用与回链机制、体系「挂到」入口 —— cut 面板是这些能力的组合延伸，不新增底层范式。

## 6. 记忆增强设计

### 6.1 判据（是否值得进记忆管线）

> **延迟测试：如果这条要 5 秒内反应过来才算合格 → 值得练；如果允许查 → 不练（留笔记等触发）。**

技能自学存在"操作时不许查"的反应速度资产（听音程秒答、色号脱口、高频 API 手到擒来）。记忆不是内容属性问题，而是**使用方式**问题。

### 6.2 标签 × 记忆层/查阅层

| 标签 | 记忆层（进卡片管线） | 查阅层（不进） |
|---|---|---|
| W | 高频反应资产：术语↔含义、参数、色号/和弦映射 | 低频词典、引文定义（只检索） |
| Y | 不背原文；做"用自己的话解释"的自由回忆卡 | 转译稿留笔记，卡壳时翻 |
| H | 顺序骨架卡（下一步是什么），明示以练代背 | 完整步骤归执行台 SOP |
| M | 不考定义；考情境→模型名的调用卡 | 主张/边界留模型卡，遇事对照 |
| Me | 不建卡；问题树周自答 = 天然回忆测验 | — |
| Act / SE / AI | 不进记忆管线 | — |

### 6.3 卡片形态 × 认知机制

| 机制 | 做法 | 卡型 |
|---|---|---|
| 主动回忆 | 先想后看，不重读 | 全部卡型 |
| 线索化 | 卡面给情境开头，不给术语名（考"遇到什么想到什么"） | 情境调用卡（M） |
| 双向 | 名称↔含义双向出题 | 双向卡（W 反应层） |
| 生成式 | 要求自述因果链，考"讲得出来" | 自由复述卡（Y） |
| 证据回链（本项目独有） | 每张卡带课堂时间戳/OCR 截图；答错一键回看原课片段 30 秒——记忆失败时刻 = 重新编码最佳时刻 | 全部卡型（卡面附证据） |
| 间隔调度 | SM-2 管节奏；未来技能类加"间隔练习"日程（程序性记忆靠做不靠背） | — |

### 6.4 流程位置

cut 面板的第 5 个去向 = **记忆池**：划选段落 → 系统按类型给卡面骨架（步骤段→挖空"下一步"卡；术语段→双向卡；格言段→情境调用卡）→ 人确认/微调 → 进复习队列 → 答错回看证据 → 重新排队。用户不需要先判断"值不值得记"，系统默认判、人改派。

## 7. 端到端走查示例（修容课）

| 原文段落（课堂笔记） | 机器预判 | 人 | 产物 | 落点 | 使用时刻 |
|---|---|---|---|---|---|
| 「1 保湿 2 控油 3 分区上粉 4 定妆」 | SOP | ✅ | 可勾选清单 | 执行台 | 周二练习时打勾 |
| 「阴影要打在颧骨下方 45°」 | SOP | ✅ | 步骤 + 证据回链 | 执行台 | 练习时对照 |
| 「阴影色温要跟肤色同调」 | 模型 | 改派→模型 | 模型卡（主张/成立/失效） | 体系 | 挑错色号时翻开对照 + 记一次使用 |
| 「我分不清修容和腮红的边界」 | 问题 | ✅ | 问题节点 | 体系问题树 | 周末复盘自问自答 |
| 「阴影 45°、颧骨位置术语」 | 记忆 | ✅ | 双向卡 | 记忆池 | 复习面答错 → 回看原课片段 |
| 「周五前拍腮红对比视频」 | 待办 | ✅ | 时间线钉子 | 执行台 | 周五前系统提醒 |

全程用户动作 = 划选 + 盖章；体系/执行台/记忆池的内容是**用出来的**，不是填出来的。

## 8. 与现有产品对齐与缺口清单

| 构想能力 | 现有基础（据交付文档） | 缺口/需新增 |
|---|---|---|
| cut 面板（提炼为…） | 划选/选区落点、段落级操作 A1、笔记→闪卡联动规划 | cut 面板 UI + 去向面板 + 草稿生成 |
| 去向预判 | 无 | 段落线索 → 去向规则引擎（纯本地规则起步） |
| 批量整理会话 | 课堂助手初稿落笔记 | 整理会话 UI（建议清单逐条过目/批量放行） |
| 待整理队列 | 无 | 笔记区"待整理"聚合视图（计数+筛选） |
| 执行台（SOP+待办） | 无（笔记内任务列表可勾选） | 新区域（或先做笔记内 SOP 段落原型验证） |
| 体系接收派生 | 问题树/概念/模型实体、模型三件套、记一次使用、决策日志 | 段落级引用（目标粒度从整件降到段落） |
| 记忆池进卡 | 闪卡、复习面（调度已存在） | 卡面自动草稿生成、证据回链、段落→卡提取 |
| 折叠引用行（封箱） | 版本链（编辑=叠加层） | 段落级"已提炼"状态与跳转 |
| 草稿态（可选挡位） | 无 | 目的地草稿/正式双态 |

**不破的纪律**：不做块编辑器（Markdown 为本）；不新增仓库型功能区；体系只引用不收纳；证据链不因拆解而断；AI 能力纯本地规则起步（分类负担兜底），云端增强遵循默认关 + 授权。

## 10. 遗留问题与待验证假设
