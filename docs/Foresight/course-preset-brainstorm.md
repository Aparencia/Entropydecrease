# 课程预设（Course Preset）头脑风暴

> **状态**: 前瞻构想（Foresight，未排期）
> **日期**: 2026-07-30
> **模块**: 回声定位（classroom / 网课提取）
> **来源**: 回声定位页面布局优化讨论的延伸头脑风暴
> **关联代码**: `client/src/features/classroom/`、`client/src/lib/capture/captureTypes.ts`（CourseMeta）

---

## 背景

回声定位页面当前每次采集需重复做 4 个决策：目标窗口、采集路径（智能/精细/录制）、采集模式（视觉/音频/混合）、截图间隔等设置。**课程预设的本质是"把重复决策一次性固化"**——根据不同课程内容，自动决定不同采集方式。

本文档记录三个方向的发散：① 课程预设概念的扩展启发；② 采集方式的其他方案；③ 课程信息（CourseMeta）的补充评估。

---

## ① 课程预设概念的扩展启发

| 方向 | 内涵 | 价值 | 优先级 |
|---|---|---|---|
| **A. 课程档案（Course Profile）** | 每门课一份档案：绑定惯用窗口关键词 + 采集路径 + 模式 + 语言 + 学科术语表。再次上这门课时一键恢复全部配置 | 把"配置页"变成"选课页"，交互从 4 步降为 1 步 | ⭐ 一期 |
| **B. 场景模板（Scene Template）** | 与具体课程解耦的通用模板：📊 PPT 直播课（智能+混合）/ ✍️ 板书推导课（精细+视觉+短间隔）/ 🗣️ 讨论研讨课（音频为主）/ 🎬 录播回看（录制） | 新用户零配置起步；与"回声定位"声呐档位隐喻天然契合（浅扫/深扫/全谱） | ⭐ 一期 |
| **C. 自适应预设（AI 推荐）** | 选定窗口后，AI 用首帧截图 + 窗口标题判断内容类型（PPT/板书/视频/会议），主动推荐："检测到腾讯会议 PPT 分享，建议智能路径+混合模式，采用？" | 静态预设升级为动态推荐，最贴合"AI 如声呐"品牌叙事 | 二期 |
| **D. 课表联动** | 结合周课表：周三 10:00 打开应用自动提示"该上《高等数学》了，按上次配置开始？" | 从工具跃迁为学习伴侣 | 远期（依赖课表数据） |

**推荐路线**：A + B 组合先落地（纯本地数据，符合本地优先原则），C 作为二期增强，D 放需求池。

### 预设匹配维度（供 C 参考）

- **课程类型**：理论课 / 实验课 / 讨论课
- **教学平台**：腾讯会议 / 钉钉 / Zoom / B 站 / MOOC（可复用 `windowScorer` 关键词库）
- **内容特征**：纯 PPT / 板书 / 视频播放 / 屏幕演示

## ② 采集方式的其他方案

现有三条路径：`fine`（逐帧截图）/ `smart`（AI 关键帧）/ `full_record`（全程录像）。以下为候选扩展策略：

| 方案 | 机制 | 优势 | 成本/风险 |
|---|---|---|---|
| **动态换挡（最有潜力）** | 智能路径升级：采集中 AI 持续判断画面类型——PPT 静止期自动降频、板书书写期自动提频、纯视频播放段自动切录制缓存。用户只选"自动挡" | 消灭"选路径"这个决策本身 | 现有 `SmartCaptureController` 是天然宿主，改动可控 |
| **标记驱动采集** | 反转逻辑：平时仅低功耗录音，用户按 M 标记时回溯截取前后 30s 画面+语音做精细处理 | "我说重要才重要"，资源占用最低 | 需环形缓冲区；漏标风险由用户承担 |
| **双窗口协同** | 主窗口（老师画面）+ 副窗口（自己的笔记/IDE）同时采集，AI 关联"老师讲到 X 时我在写 Y" | 实验课/编程课刚需 | 采集管线需支持多源，改动大 |
| **课后补扫** | 录制路径轻量变体：课中只存关键帧缩略图+音频，课后用户圈选时间段再高清重采/深度分析 | 算力花在刀刃上 | 需时间轴圈选 UI |
| **音频优先 + 视觉按需** | 以 ASR 转写为主干，语音出现"大家看这个图/这页 PPT"等指示词时才触发截图 | 语言课/文科课契合 | 依赖指示词识别准确率 |

## ③ CourseMeta 补充字段评估

现有字段：`courseName / subject / customTerms / detectedBy`。

**判断原则：每加一个字段都要回答"AI 分析或自动配置会消费它吗"，否则就是给用户加表单负担。**

### 值得加（提升 AI 分析质量）

```typescript
teacherName?: string   // 教师姓名 → ASR 人名纠错、笔记署名
contentType?: 'ppt' | 'board' | 'video' | 'discussion'  // 内容形态 → 驱动 ①C 的推荐
chapterHint?: string   // 本节章节/主题 → 缩小 AI 分析上下文，显著提升笔记结构质量
```

### 配合课程档案加（支撑 ①A）

```typescript
presetId?: string          // 关联课程预设
windowKeywords?: string[]  // 该课惯用窗口关键词 → 自动锁定窗口
```

### 暂不建议加

- ✗ 课程难度等级、学期信息、完整课程大纲 —— 采集环节消费不到，填写负担 > 收益；学期/大纲属于笔记组织层，放 notes 模块更合适。
