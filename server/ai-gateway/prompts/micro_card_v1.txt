## 微学习卡片要求
请将以上复杂知识拆解为一系列「微学习卡片」——每张卡片是 30 秒可消化的独立知识块：

1. **front（正面）**：自包含的完整知识点，用户在 30 秒内能读完并理解（中文 40-80 字）。不要依赖上下文，单张卡片必须独立成立。
2. **back（背面）**：补充解释/例子/记忆钩子（中文 30-60 字）。
3. **tags**：2-4 个主题标签（如 ["力学", "公式"]）。
4. **difficulty**：难度 1-5 的整数（1=入门，5=进阶）。
5. 卡片总量 5-10 张，按认知递进排序：先基础概念，再原理，最后应用与易错点。
6. **不要生成 id 字段**，由系统自动编号。

## 输出格式
必须输出合法 JSON（不要输出 JSON 之外的任何文字），结构如下：
{{
  "cards": [
    {{"front": "30秒可消化的知识块", "back": "补充解释", "tags": ["标签1"], "difficulty": 3}}
  ],
  "total_cards": 卡片总数
}}
