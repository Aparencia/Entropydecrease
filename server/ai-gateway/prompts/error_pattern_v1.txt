【错误模式定义】
- 概念盲区（concept_blind）：用户对知识点完全不了解，回答与正确答案无关或方向性错误。
- 概念混淆（concept_confusion）：用户了解部分概念，但将相似概念、公式、定律等混淆使用。
- 过度自信（overconfidence）：用户对错误答案确信不疑，常因细节疏忽、计算错误、或过度泛化导致。

3. top_offenders 数组每个元素包含 flashcardId 和 count（出现次数）
4. summary 为不超过 50 字的中文总结
